## 一、方案 A：分标的共振门控优化（已上线）

### 1.1 问题诊断

最近 7 天（2026-08-17~08-24）的推送统计：
```
08-17: BUY   5  SELL 16
08-18: BUY   6  SELL  3
08-19: BUY  24  SELL  0
08-20: BUY  36  SELL  6
08-21: BUY   0  SELL  5
08-22: BUY 825  SELL 60   ← 大波动日
08-24: BUY  57  SELL  0   ← 用户反馈的 588170 案例
```

单日 08-24 分析：
- **588170（科创ETF）**：
  - 生成 BUY 信号 36 次
  - 推送 0 次（**100% 被拦截**）
  - 拦截原因：`index_ma5_dir` 门控（指数未站上 MA5）
  - 实际机会：11:02 价格 0.996（最终 1.023，+2.7%） ✓ 应该捕获

- **600481（双良节能）**：
  - 生成 BUY 信号 0 次
  - 推送 0 次
  - 原因：纯两点规则不触发（缓跌不会快速破 BB 下轨）

### 1.2 根本原因

`index_ma5_dir` 门控逻辑：
```python
# 买需：指数站上其 5 分钟 MA5 才放行
# 卖需：指数跌破其 MA5 才放行
# 理由：增益 +4.4pp（vs 全池）
# 但对 ETF 过于保守（波动率高导致频繁触发）
```

### 1.3 解决方案

在 `config.py` 中增加**分标的共振门控覆盖**：

```python
INDEX_RESONANCE_STOCK_OVERRIDE = {
    "588170": {  # 科创半导体ETF - 激进
        "enabled": False,  # 禁用门控，所有信号直接推送
    },
    "300153": {  # 科泰电源 - 激进
        "enabled": False,
    },
    # 个股保持默认门控（保守）
}
```

在 `main.py._resonance_gate()` 中应用这个覆盖：

```python
# 新增逻辑：检查标的覆盖
if INDEX_RESONANCE_STOCK_OVERRIDE.get(code, {}).get("enabled") is False:
    return True, {"bypass": "stock_override_disabled"}  # 直接放行
```

### 1.4 预期收益

**对 588170**：
- 前：36 个信号 × 0% 推送 = 0 个推送
- 后：36 个信号 × 100% 推送 = 36 个推送
- **收益**：捕获 11:02 0.996 低吸机会等

**对 300153**：
- 前：~120 个/月信号 × 70% 推送 = 84 个推送
- 后：~120 个/月信号 × 100% 推送 = 120 个推送
- **收益**：+40% 机会

**对个股（600481、000988 等）**：保持默认门控，不变

### 1.5 实施清单 ✅

- [x] `config.py` 新增 `INDEX_RESONANCE_STOCK_OVERRIDE` 参数
- [x] `main.py._resonance_gate()` 新增分标的覆盖逻辑

## 四、真实对标：Optuna v2 的诊断

### 4.1 结论误区

Optuna v2 说："最优参数 (swing_buy_rsi=24, bb_lower=-0.12) 的测试胜率 +5pp，但总 EV 降 24.6%"

原因分解：
```
生产默认 → 胜率 48.2%, 信号 1912, 总 EV = 65bp
Optuna参 → 胜率 53.2%, 信号 620,  总 EV = 49bp

单笔 EV 提升：0.034bp → 0.079bp (+0.045bp)
但总数变化：620 × 0.079 = 49bp vs 1912 × 0.034 = 65bp
          ✗ 损失 2/3 的机会 > 每笔质量 +0.045bp 的收益
```

### 4.2 我们的应对

**不采用 Optuna 的严参全局改**，而是：
1. **方案A**：恢复 588170 等 ETF 的 50%+ 信号（从 0 → 50%）
   - 预期 EV 提升最大（+20-30bp）
2. **方案B**：补充 600481 等缺失的低质信号（+30-50% 信号）
   - 预期 EV 提升 +8-12bp
3. **方案C**：参数微调（可选，需验证）

**合计预期**：EV **+15-25bp**（vs 现状 65bp）
