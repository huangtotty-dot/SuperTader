## 4. X4 切换滞后与反转日正确性（首次实测）

**拐点标注规则（文档化）**：5 分钟收盘价序列上运行 zigzag，阈值 ±0.8%；上行段收盘自运行最高点回落 ≥0.8% → 在最高点 bar 标"顶"（期望转 BEAR），下行段对称标"底"（期望转 BULL）；每日独立标注。**滞后** = 拐点确认时刻之后 trend_timeline 首个与期望方向一致的条目时刻 − 拐点时刻，按 5 分钟根数计。反转日 = 当日存在 ≥1 个拐点前期望方向与活跃 trend_state 相反的已确认拐点。

| 指标 | 数值 |
|---|---|
| 全样本拐点（450 stock-day） | 1994 个 |
| 最终切换到期望方向 | 785（39.4%） |
| 收盘前未切换（missed） | 1209（60.6%） |
| **切换滞后均值** | **24.1 根（≈2 小时）** |
| 滞后 P90 / max | 48 根 / 64 根 |
| 反转日（450 中） | **398 个 stock-day（88%）** |
| 反转日拐点切换正确（≤3 根） | **4 / 840（0.5%）** |
| late / missed | 361 / 475 |

**P1②（切换滞后 ≤3 根）首次实测即大幅不过**：均值 24 根、P90 48 根；反转日场景下趋势层几乎从不在 3 根内跟上（0.5%）。
**口径警示**：0.8% zigzag 颗粒度细于趋势层设计意图（滞后确认机制本就牺牲速度换稳定），该结果更多说明"趋势层不是日内反转检测器"，而非其趋势识别本身错误；但闸门按字面即不过。
