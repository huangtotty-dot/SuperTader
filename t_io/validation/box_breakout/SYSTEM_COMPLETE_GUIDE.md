## 修复内容详解

### Phase 1: P0修复（已完成）— check_box_breakout 分级体系

**位置**：t_gui.py 第887-945行

#### 改进前
```python
# 硬阈值，二值判定
if 0.3 <= pct_above <= 8:
    return {"broken": True, "box": {...}, "price": cur, "pct_above": pct_above}
return {"broken": False, ...}
```

#### 改进后
```python
# 分级体系，质量评估
突破等级判定：
  - pct_above <= 0.5%        → level = None（未达阈值）
  - 0.5% < pct_above <= 1%   → level = "signal"（信号级）
  - 1% < pct_above <= 3%     → level = "reliable"（可靠级）
  - 3% < pct_above <= 8%     → level = "strong"（强势级）
  - pct_above > 8%           → level = "far_away"（已远离）

返回值新增：
  - level: 突破等级
  - confidence: 置信度（基于箱体宽度 width_pct）
```

#### 加仓条件更新
```python
# 旧：任何broken=True的突破都触发
right_breakout = bool(bx.get("broken"))

# 新：仅reliable和strong级触发，过滤signal级误报
right_breakout = bx.get("level") in ("reliable", "strong")
```

**效果**：加仓条件变严格，预计触发频率↓50-70%

### Phase 2: P1修复（已完成）— _detect_boxes 算法升级

**位置**：t_gui.py 第1330-1534行

#### 核心算法对比

| 改进项 | 旧版 | 新版 | 说明 |
|--------|------|------|------|
| **触及容差** | ±0.8-8.8% | ±0.5% | 更精确地判定真实触及 |
| **触及计算** | `wh >= ups*0.992` | `wh >= ups*0.995` | 从99.2% → 99.5% |
| **横盘阈值** | 0.5%/天 | 0.3%/天 | 30日内涨跌幅 15% → 9% |
| **置信分权重** | 触及次×1.5 + 横盘×3 | 触及×2.0 + 横盘×2.0 + 宽度×1.5 | 质量优先 |
| **宽度分类** | 统一权重 | 微/正常/宽分化 | 5-15%最优 |
| **刚突破判定** | 固定20天+15% | 动态5-15天+10-15% | 宽度自适应 |
| **合并条件** | 50%重叠 | 80%重叠+≥5天 | 保留历史分阶段 |

#### 具体实现

**触及标准改进**（第1368-1369行）
```python
# 旧
_up_touches = np.sum(wh >= (ups * 0.992)[:, None], axis=1)  # ±0.8%
_dn_touches = np.sum(wl <= (dns * 1.008)[:, None], axis=1)  # ±0.8%

# 新
_up_touches = np.sum(wh >= (ups * 0.995)[:, None], axis=1)  # ±0.5%
_dn_touches = np.sum(wl <= (dns * 1.005)[:, None], axis=1)  # ±0.5%
```

**置信分计算改进**（第1381-1393行）
```python
# 旧：触及次数权重最高，但质量不严格
conf = (up_touch + dn_touch) * 1.5 + flatness_bonus * 3 + width_bonus

# 新：质量优先
touch_quality = (up_touch + dn_touch) * 2.0
flatness = max(0, (0.003 - rel_slope) / 0.003) * 2.0
width_score = {5-15%: 1.5, 微/宽: 0.5, 其他: 0}
conf = touch_quality + flatness + width_score
```

**刚突破判定改进**（第1410-1422行）
```python
# 旧：固定参数
if days_since <= 20 and pct_above < 15%:
    b["rel"] = 1  # 刚突破

# 新：宽度自适应
if width < 5:
    recently_broke = days_since <= 5 and pct_above < 10%    # 微箱体敏感
elif width < 15:
    recently_broke = days_since <= 10 and pct_above < 12%   # 正常箱体
else:
    recently_broke = days_since <= 15 and pct_above < 15%   # 宽幅箱体
```

**合并条件改进**（第1456-1472行）
```python
# 旧：50%价格重叠 + 简单时间交集
price_overlap > price_span * 0.5 and t_overlap

# 新：80%价格重叠 + 至少5天时间重叠
price_overlap_pct > 0.8 and overlap_days >= 5
```

### Phase 3: K线图质量评分体系（已完成）

**位置**：t_gui.py 第1502-1534行

#### 新增返回字段

```python
# 每个箱体（box）现在包含：
{
    # 原有字段（保留）
    "start": "2026-08-01",
    "end": "2026-08-30",
    "low": 15.23,
    "high": 18.56,
    "touches": (3, 4),
    "conf": 8.5,
    "rel": 0,
    "center": 16.89,
    "days": 29,
    "days_since_end": 5,
    
    # 新增字段（P1改进）
    "width_grade": "优",              # 微(<5%) / 优(5-15%) / 宽(>15%)
    "touch_grade": "强",              # 极强(4+) / 强(2-3) / 弱(1)
    "quality_score": 7.8,            # 1-10分综合评分
    "display": "优箱(8.5%) 触及强(7次) 质量7.8/10"  # 完整标签
}
```

#### 质量评分逻辑

```python
# 三维评分
touch_quality = (up_touch + dn_touch) * 1.5
flatness_bonus = (15 - width) * 0.3      # 越窄越好
freshness_bonus = (30 - days) * 0.1      # 越近越好

quality_score = min(10, max(1, round(touch_quality + flatness_bonus + freshness_bonus, 1)))
```

#### K线图显示示例

```
宽箱(20.0%) 触及极强(10次) 质量10/10    ← 非常可靠
优箱(8.5%) 触及强(4次) 质量7.8/10      ← 推荐关注
微箱(3.2%) 触及弱(2次) 质量3.2/10      ← 信号级谨慎
```
