## 一、流通股本（float_share_daily.parquet）

**字段**

| 列 | 含义 | 单位 |
|---|---|---|
| `symbol` | 面板代码（SHSE.600000 格式） | — |
| `trade_date` | 交易日（面板交易日历，datetime64[ns]，2023-09-01 起，与 F3 窗口对齐） | — |
| `float_share` | 流通股本 | **万股**（对齐 tushare `daily_basic.float_share` 习惯） |
| `float_share_shares` | 流通股本 | 股（换手率=面板 volume / 本列） |
| `float_field` | 取值字段：`float_a`=已上市流通A股（5650 只）；`float_all_bshare`=已流通股份（24 只 B 股回退，B 股「已上市流通A股」恒为 0） | — |

**来源 API**：akshare `stock_zh_a_gbjg_em`（东方财富 datacenter「股本结构」事件型全历史：变更日期/总股本/已流通股份/已上市流通A股/变动原因）。

**为何不用 tushare**：项目内置 token（`analysis/index_regime_intraday.py` 的 `TUSHARE_TOKEN` 环境变量/回落值）实测仅有 `stk_mins` 权限；`daily_basic`、`bak_basic`、`bak_daily`、`share_float`、`stock_basic`、`index_member` 等 10+ 接口全部返回「没有接口访问权限」。故 P2 两数据集整体改走 akshare。

**PIT 处理方式**：事件表按 `变更日期 <= trade_date` 向后匹配（`merge_asof(direction="backward")`）前向填充成日频——每个交易日只能看到当日及之前已生效的股本变更，无未来函数。送转/增发/限售解禁/债转股等事件逐条生效。`变更日期` 为东财口径的股本变动生效日（与公告日可能有 1–数日差，换手率量级下影响可忽略，如需严格公告日口径需另拉 `share_float` 类数据，当前 token 无权限）。

**覆盖率**

| 口径 | 覆盖 |
|---|---|
| symbol 级 | **5674 / 5674（100%）** 有事件数据（5650 只 A 股字段 + 24 只 B 股回退字段） |
| bar 级（窗口内 3,844,512 根 panel bar） | **3,844,512 / 3,844,512（100.00%）** 非空 |
| symbol 内时间序列 | 均值 98.0% 非空；缺口全部在「首个股本事件日（≈上市日）之前」——彼时无 panel 行情，不影响因子计算。最低 1.1% 为窗口末期新上市股（如 2025-10 上市），其上市后的 bar 100% 覆盖 |

**冒烟验证**：600000 浦发银行 2023-09 流通股本 293.52 亿股 → 2026-09 333.06 亿股（期间债转股/增发逐事件生效，与公开披露一致）；据此算的日换手率 0.04%–0.66%、均值 0.20%，符合大盘银行量级。退市股 300799 左江退事件覆盖至 2024-12-31，末值 4080 万股（小盘量级合理）。588170（科创 50 ETF）不在面板宇宙（面板为纯股票宇宙，5674 只无 ETF），东财股本结构接口对 ETF 返回空表——预期行为，如实记录。

## 二、行业映射（industry_map.parquet）

**字段**：`symbol`、`code6`、`sec_name`、`industry_sw1`（申万一级行业名）、`sw1_index_code`（如 801010）、`industry_source`（`SW2021_L1` / `UNCOVERED`）、`sw_entry_date`（计入申万指数日期）。

**来源 API**：akshare `sw_index_first_info` + `index_component_sw`（申万宏源官网经乐咕乐股代理），**口径 = 申万一级（2021 版，31 个行业），当前成分快照**。不是同花顺口径，不是证监会门类。

**PIT 处理方式**：静态当前映射，未拉历史行业变更。申万一级行业调整频率极低（年度评审+IPO 纳入），且 `sw_entry_date` 已保留供需要时精化；对 2023-09 起的窗口，行业动量/行业槽位约束用静态映射的偏差可忽略（申万 2021 版自 2021-12 启用，窗口内无版本切换）。**行业映射视为时点不变的已知局限已如实标注。**

**覆盖率**

| 口径 | 覆盖 | 缺口构成 |
|---|---|---|
| symbol 级 | 5219 / 5674（92.0%） | 455 只 UNCOVERED = 266 只 2023-09 前退市（窗口内无行情，无关）+ **108 只窗口内退市** + 81 只活跃非 A 股（80 B 股 + 1 CDR 九号公司） |
| bar 级（窗口内 panel bar） | 3,750,371 / 3,844,512（**97.55%**） | 188 只有窗口内行情但无行业：84 B 股（申万一级不含 B 股）+ 101 窗口内退市股 + 九号公司(CDR)、招港B、*ST元道 |

**退市股兜底尝试（如实记录）**：巨潮 `stock_profile_cninfo` 对退市股实测返回空表（600001/300799 均为空），且其依赖的 py_mini_racer 非线程安全（并发即 native crash）——兜底无实际收益，放弃。东财个股信息/雪球接口在本机网络被拒（RemoteDisconnected）。**窗口内退市的 ~101 只在 IND_MOM 计算与「单行业≤2 槽」约束中将无行业归属，建议按独立桶处理或剔除，实现时在因子库侧决策。**

**冒烟验证**：600000 → 银行（SW2021_L1）✓；300799 左江退 → UNCOVERED（退市股预期缺口）✓；588170 → 不在 universe，申万一级本身不含 ETF ✓。

## 三、对 P2 因子族的解锁确认

| 因子/约束 | 依赖 | 状态 |
|---|---|---|
| TURN20 / PCT_TURN20 / STR（真换手率版，东吴 ICIR≈−2） | turnover = volume / float_share_shares | **解锁**，bar 级 100% 覆盖 |
| GAP_cond_turn（换手率条件隔夜） | 同上 | **解锁** |
| IND_MOM20（行业动量，成分等权） | industry_sw1 + panel close | **解锁**，97.55% bar 覆盖（缺口：B 股/窗口内退市/3 只零星） |
| IND_BREADTH（行业广度） | 同上 | **解锁**，同上 |
| F4「单行业 ≤ 2 槽」约束 | industry_sw1 | **解锁**，约束作用于选股宇宙时可按 SW2021_L1 分组；UNCOVERED 标的需定策略（建议独立桶或剔除） |

## 已知局限汇总

1. 行业映射为当前快照，非 PIT 历史映射（申万一级变动极少，窗口内影响可忽略）。
2. 108 只窗口内退市股无行业（占窗口内 bar 约 2.45% 含 B 股）。
3. 流通股本 PIT 以「变动生效日」计，非公告日。
4. B 股（84 只）换手率用「已流通股份」口径、无行业归属，建议因子库侧对 B 股统一剔除或单列。
5. 面板宇宙不含 ETF，588170 冒烟为负例验证（接口对 ETF 返回空，符合预期）。
