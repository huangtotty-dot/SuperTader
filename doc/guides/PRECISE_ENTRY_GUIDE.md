- **判据：**
  - 最近首次大幅放量？→ +40分
  - 单日涨幅>8%？→ +30分

  - 成交量>2倍？→ +15分

#### L2: `check_l2_pullback_consolidation(date_str)`
- **输入：** 日期
- **输出：** 是否巩固、支撑位、缩量比、趋势判定
- **三项条件：**
  1. 支撑位站稳（容错1%）
  2. 成交量 < 0.8倍前期平均 ✅
  3. 近期成交量逐步递减 ✅

#### L3: `check_l3_intraday_resonance(date_str, vol_min=1.2)`
- **输入：** 日期，最小成交量倍数
- **输出：** 是否共振，三项具体判定

A: 框架会标记为"insufficient"。你可以在实际交易时用 TradingView/通达信 的分钟线图手工确认。

**Q: 能否在L2未完全通过时提前埋伏？**

**Q: 预计多久能走到买入点？**
