# K线图箱体显示改进说明（2026-08-24）

## 概述

K线图中的箱体检测现已应用全新的改进逻辑，与加仓条件判定**保持完全一致**。

## 改进内容

### 1. 箱体检测算法升级
K线中显示的每个箱体都经过以下改进：

#### 触及标准更严格
- **旧**：±0.8-8.8%（宽松的容差）
- **新**：±0.5%（精确的边界触及）
- **效果**：过滤掉"接近但未真实触及"的虚假箱体

#### 置信分计算改进
- **旧**：触及次数 × 1.5 + 横盘度 × 3（触及数优先）
- **新**：触及质量 × 2.0 + 横盘度 × 2.0 + 宽度适中 × 1.5
- **效果**：质量优先，不再高估低质量信号

#### 横盘判定更严格
- **旧**：斜率 < 0.5%/天（允许15%的30日涨跌幅）
- **新**：斜率 < 0.3%/天（要求30日涨跌幅 < 9%）
- **效果**：真正的"箱体"而不是"宽松的波动区间"

### 2. 箱体质量评分体系

K线图中的每个箱体现在显示**质量评分**，包含三个维度：

#### 2.1 宽度等级（width_grade）
```
微箱体   (<5%)    — 敏感但容易假突破，突破阈值最严格
优箱体   (5-15%)  — 正常箱体，最稳定，最值得关注
宽箱体   (>15%)   — 波动大，突破需要更多确认
```

#### 2.2 触及质量等级（touch_grade）
```
极强 (4+次精确触及)  — 非常稳定的支撑/阻力，可靠
强   (2-3次精确触及) — 较稳定，有参考意义
弱   (1次精确触及)   — 可能是噪音，需谨慎
```

#### 2.3 综合质量分（quality_score）
```
1-10分的综合评分，综合考虑：
- 触及质量（权重 1.5）
- 宽度合理性（权重 0.3）
- 箱体新鲜度（权重 0.1，最近30天加分）

显示示例：
  优箱(8.5%) 触及强(4次) 质量 7.8/10  — 非常值得关注
  微箱(3.2%) 触及弱(2次) 质量 3.2/10  — 信号级，谨慎
  宽箱(18%) 触及强(5次) 质量 6.5/10   — 中等可靠
```

### 3. 箱体显示标签

K线图中每个箱体旁边现在显示完整的**质量评分标签**：

```
格式：[宽度等级]箱([宽度]%) 触及[质量等级]([次数]次) 质量[评分]/10

示例：
  优箱(9.8%) 触及强(4次) 质量 7.5/10
  微箱(3.1%) 触及极强(6次) 质量 4.2/10
  宽箱(16.5%) 触及强(3次) 质量 6.1/10
```

## K线图中的箱体显示逻辑

### 显示优先级
1. **rel=0**（现价在箱体内）— 最重要，优先显示
2. **rel=-1**（上方历史箱体）— 阻力位，次要显示
3. **rel=-2**（下方历史箱体）— 支撑位，参考显示

每个优先级内按**质量分降序**排列，最多显示3个箱体。

### 箱体筛选条件
- 只显示近期箱体（距今 ≤45天）
- 只显示有真实触及的箱体（精确触及 ≥1次）
- 自动合并严重重叠的箱体（价格重叠>80% + 时间重叠≥5天）

## 对加仓条件的影响

### 加仓突破判定保持一致

K线显示的箱体突破等级与加仓条件判定使用**同一套逻辑**：

| 突破等级 | 幅度 | 加仓条件 | K线显示 |
|---------|------|---------|--------|
| signal | 0.5-1% | ❌ 不触发 | 显示但标记为"信号级" |
| reliable | 1-3% | ✅ 触发 | 显示为"可靠突破" |
| strong | 3%+ | ✅ 触发 | 显示为"强势突破" |

### 使用建议

**对于选股猎手的应用**：
- 在选股结果中点击股票，查看K线中的箱体质量评分
- 质量分<4分的箱体突破 = signal级，谨慎对待
- 质量分≥7分的箱体 = 真实的支撑/阻力，值得关注

**对于手动操作**：
- 关注K线中标记为"优箱"且质量分≥7分的箱体
- 这些是最可靠的进场/加仓位置
- 对于"微箱"突破，需要额外的形态确认

## 技术细节

### 新增返回字段
_detect_boxes现在为每个箱体返回以下新字段：

```python
{
    # 原有字段
    "start": "2026-08-01",
    "end": "2026-08-30",
    "low": 15.23,
    "high": 18.56,
    "width": 9.8,  # 箱体宽度百分比
    "touches": (3, 4),  # (上沿触及次, 下沿触及次)
    "conf": 8.5,  # 置信分
    "rel": 0,  # 关系: 0=现价在内, -1=上方, -2=下方
    
    # 新增字段（P1改进）
    "width_grade": "优",  # 宽度等级: 微/优/宽
    "touch_grade": "强",  # 触及质量: 极强/强/弱
    "quality_score": 7.5,  # 综合质量分 1-10
    "display": "优箱(9.8%) 触及强(7次) 质量 7.5/10",  # 显示标签
}
```

### 前端适配

如果前端使用K线图的boxes数据，建议：
1. 优先使用新的 `display` 字段作为标签文本
2. 如需自定义显示，可使用 `width_grade`、`touch_grade`、`quality_score` 组合
3. 原有字段（start/end/low/high/conf/rel等）保持不变，向后兼容

### 示例代码
```python
# 前端展示示例
for box in boxes:
    color = "green" if box["quality_score"] >= 7 else "yellow" if box["quality_score"] >= 5 else "red"
    label = box["display"]  # 直接使用新的显示标签
    draw_box(start=box["start"], end=box["end"], 
             low=box["low"], high=box["high"],
             color=color, label=label)
```
