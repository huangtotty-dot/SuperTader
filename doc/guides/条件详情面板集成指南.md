# 建仓条件详情面板集成指南

## 概述

**条件详情面板**（`condition_detail_panel.html`）提供精细化的建仓卡点分析，解决原来"晨添-NO-GO"提示过于粗略的问题。

## 功能

用户在主表格中点击某只股票的"NO-GO"标签 → 展开折叠式面板，显示：

1. **通道条件**：冰点反转、突破跟随的具体得分和状态
2. **背离信息**：m30/m60 的背离类型和连续性标记
3. **建仓卡点**：精确显示哪些条件卡住了，差距多少
   - 市场有方向：指数当前位置 vs 需要位置
   - 多头结构：价格离 MA20/MA60 还差多少百分比
   - 回撤到位：当前回撤 vs 需要的回撤深度
   - 日内确认：具体缺什么条件

## 前端集成

### 方案 A：弹窗（推荐快速集成）

在主表格 HTML 中，为每个 NO-GO 标签添加点击事件：

```html
<!-- 原来的标签 -->
<span class="badge no-go">晨添-NO-GO</span>

<!-- 修改为可点击 -->
<span class="badge no-go clickable" onclick="openConditionDetail('002451')">
  晨添-NO-GO
</span>
```

JavaScript 代码：

```javascript
function openConditionDetail(code) {
  // 方案1：打开浮窗
  const url = `condition_detail_panel.html?code=${code}`;
  window.open(url, '_blank', 'width=650,height=800,scrollbars=yes');
  
  // 或方案2：iframe 嵌入（更优雅）
  // showDetailPanel(code);
}

function showDetailPanel(code) {
  const panel = document.createElement('div');
  panel.className = 'modal-overlay';
  panel.innerHTML = `
    <div class="modal-content">
      <div class="modal-close" onclick="this.parentElement.parentElement.remove()">×</div>
      <iframe src="condition_detail_panel.html?code=${code}" 
              style="width:100%;height:100%;border:none;"></iframe>
    </div>
  `;
  document.body.appendChild(panel);
}
```

CSS for modal:


### 方案 B：表格内折叠行

直接在表格行后展开详情，无需打开新窗口：

```html
<!-- 原表格行 -->
<tr>
  <td><span class="code">002451</span></td>
  <td><span class="badge no-go" onclick="toggleDetail(this)">晨添-NO-GO</span></td>
  <td colspan="10">
    <div class="detail-panel" style="display:none;">
      <!-- 由 JS 动态插入 -->
    </div>
  </td>
</tr>
```

## 使用场景

### 场景1：快速诊断
用户看到某支股票"NO-GO"，点击标签 → 立即看到具体原因
- "哦，是指数卡位了，MA60 位置是 3893.10"
- "缺量 15%，再跌一点就满足"
- "背离是单次的，不连续"

### 场景2：监控决策
用户根据卡点信息决定下一步：
- 若卡"市场有方向"→ 监控指数突破 MA60
- 若卡"回撤到位"→ 监控继续下跌
- 若卡"日内确认"→ 设置 15 分钟再检查

## 数据更新

条件详情数据来自 `position_builder_{date}.jsonl`，实时更新。
- 09:30-16:00 每 5-10 分钟扫描一次
- 盘后（16:00+）如需最新数据，需手动刷新或调用 `refresh_pb()`

## 样式定制

条件详情面板使用 CSS 变量，可自定义主题：

```css
:root {
  --pass: #10b981;      /* 绿色 - 满足 */
  --warn: #f59e0b;      /* 橙色 - 接近 */
  --fail: #ef4444;      /* 红色 - 卡住 */
  --info: #3b82f6;      /* 蓝色 - 信息 */
}
```

## 限制与已知问题

1. 数据来源于日内扫描，如果该时段未扫描过该股票，会提示"未找到扫描数据"
2. 背离信息仅在有 30/60 分钟线数据时显示
3. 若指数数据源不可用，卡点信息中"市场有方向"可能为近似值
