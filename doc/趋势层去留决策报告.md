## 1. 一句话结论

统一口径复测后：**趋势层对胜率无害（+1.50pp，p=0.73 不可判）、密度治理有效（−28%），但其拦截质量连续三轮跨口径不合格（44.3% < 50%），且 v2 轮支撑"留"的核心证据——102 条买入信号与 +¥633.85 闭环收益——被证实全部是快照口径伪迹，在洁净数据下整体蒸发。** 按 v2 预注册逻辑（P2① ≥−2pp 且 P2② <50%）执行：**不整体降级，转入拦截逻辑专项修复**；同时登记：趋势层的"买入侧增量"价值主张已证伪，修复后下一轮复测若仍无买入侧增量，降级无需再议。

## 3. 下一步优化指引方案（裁决主路线：拦截质量修复）

### 3.1 拦截逻辑专项修复（本轮裁决的直接行动项，最高优先）

问题定义：趋势层消灭的信号中 56% 事后看是好的（统一口径 318 条被拦、51.9% 胜率；共有信号仅 38.3% 胜率反而最低——**被拦集合质量高于被放行集合**，拦截方向性错误）。

修复路线（按序执行，每步独立可回退）：
1. **拦截归因分解**（纯分析，不改代码）：对统一口径 318 条"仅 baseline"信号，按拦截时刻 trend_state（BULL/BEAR/NEUTRAL）、置信度、时段（早盘/午后）、拦截后持有时长分层统计胜率，定位"哪类拦截最伤"——输出 `t_io/validation/intercept_attribution.json`。
2. **假说形成**：预期头号嫌疑是"BEAR 状态下拦截卖出信号"（卖信号在 BEAR 中本就是顺势，趋势层若按'逆势'误拦即方向性错误）与"低置信度状态切换后的惯性拦截"。归因结果验证后再动代码。
3. **最小修复候选**（归因确认后择一，均需重新 A/B）：
   - a. 拦截仅作用于买入侧，卖出侧不做趋势拦截（顺势卖出不受限）；
   - b. 拦截增加置信度门槛（如 conf < 0.6 的状态不用于拦截）；
   - c. 拦截有效期（状态切换后 N 根内不拦截）。
4. **验收**：修复后 P2② ≥ 50% 且 P2① 不跌破 −2pp，仍走分块管线 + 双跑确定性验收。

### 3.2 信号密度治理（与 3.1 并行，纯参数面）

- 现状：统一口径密度 0.83（baseline）/ 0.60（v102）个/股/日，**低于 3-8 健康区间的下限**——问题不是信号太多而是太少。
- 结构性根因（本轮新发现）：**信号记录阈值（卖：早盘 75 / 午后 65；买：同族参数）远高于引擎触发阈值（~42）**。000988 全样本 109 次引擎 SELL 决策、0 次过记录阈值，是该断层的极端案例；其余股票亦被同一闸门压制。
- 行动：将"记录/通知阈值"与"引擎触发阈值"的映射关系参数化梳理（X2 遗留的 qty=0 口径一并拍板），设计阶梯实验：记录阈值 65→55→45 三档各跑一次密度与胜率响应曲线，**用数据定阈值而非拍脑袋**。预期密度进入 1-3 区间后再评估是否继续下探。
- 注意：该实验只动 harness 记录阈值参数，不动引擎评分。

### 3.3 X4 结果对 trend 参数的含义（中期）

- 切换滞后均值 24 根、反转日正确率 0.5% 表明：**趋势层的状态机不是日内反转检测器**，其设计（滞后确认换稳定）与"识别 0.8% 级日内拐点"存在结构性错配。
- 含义一：不要用趋势状态做"反转日快速切换"类门控（它在该场景统计上必然迟到）；P1② 的 ≤3 根闸门对当前架构不现实，建议方案层面将 P1② 修订为"趋势日内主方向识别正确率"类口径（X5 一并处理）。
- 含义二：若未来需要反转检测能力，应建独立的短周期反转信号（RSI trigger 体系已有雏形），而非调快趋势状态机（调快会同时恶化一致率与 NEUTRAL 占比）。
- 含义三：3.1 的拦截修复不应引入"更快切换"作为解法——滞后不是拦截错误的根因，方向性误拦才是。

### 3.4 阴跌判多（W5）与 000988 处置

- 000988 零信号已定性为**真实评分状态**（统一口径下 sell_score max 64.2 < 65 记录阈值）+ 记录阈值结构断层，非数据伪迹、非"阴跌判多"直接证据。
- W5 专题收缩为两问：① 000988 类深套阴跌标的（成本 313 / 现价 111）的评分分布是否系统性偏低（p95 距引擎阈值 ~25 分）——若是，是个股参数（STOCK_PARAMS）问题还是因子体系对阴跌形态不敏感；② 4.1% 评分 NaN 行（RSI 因子 NaN 传导）归因修复。
- 处置：000988 不进入 3.2 阈值实验的首批调参名单（其问题是评分分布而非阈值），单列跟踪。

### 3.5 P3 入口条件与寻优空间预设计

**入口条件（全部满足才进 P3）**：
1. 3.1 拦截修复后复测：P2② ≥ 50% 且 P2① ≥ −2pp（统一口径、同一管线）；
2. 3.2 密度阶梯实验完成，记录阈值定版，密度 ≥1 个/股/日且胜率不显著劣化（Fisher p<0.2 方向为正）；
3. X5 偏差比口径修正 + P1④ 重测；P1② 闸门口径按 3.3 含义一修订；
4. 买入侧恢复可观测：统一口径下 v102（或修复版）买入信号 >0 且闭环对数 ≥10（否则闭环维度永久不可判，趋势层价值主张需重写）。

**寻优空间预设计（进 P3 后）**：优先级 ① 1 分钟体系校准（v2 轮已识别的转向）；② 拦截规则参数（3.1 修复版的置信度门槛/有效期）；③ 记录阈值精细档；明确**不寻优**：趋势状态机速度参数（3.3 含义三）、个股级过拟合参数（600176 小样本教训）。

## 4. 降级自动触发条件（下一轮预注册，避免三拖）

满足任一即执行 §3.5 降级（factor_weight_5m_trend=0、保留 RSI trigger 加分、权重还给 1 分钟体系），无需再开评审：
1. 3.1 修复后复测 P2① < −2pp；**或**
2. 3.1 修复后 P2② 仍 < 50%（即拦截不可修复）；**或**
3. 3.5 入口条件 4 在两次复测后仍无法满足（买入侧增量永久性缺席）。
