## 1. 一句话结论

拦截修复路线收官：**X8 归因把误拦主因精确定位为"趋势重构压记录阈值线"（显式门控开火 0 次），但 X9 同阈值干净实测证明该通道的修复（阈值补偿）对拦截率无效（44.34%→44.25%）**——趋势重构改变信号集合成员资格却对信号质量无选择性，这是结构性属性，不拆重构本身则 P2② 永不可过。按 v3 §4 预注册触发条件 2，**降级条件已字面达成，建议执行 §3.5 降级**（factor_weight_5m_trend=0、保留 RSI trigger 加分、权重还给 1 分钟体系）；同时**阈值 55 档是与趋势层无关的独立改进（两组胜率 +2.1~2.8pp、密度双升），建议无论降级与否都采纳**。

## 2. X8→X9 证据链（本轮新增）

### 2.1 X8 拦截归因（318 条被拦信号）
- 25%（80 条）是 churn 精确匹配假象（v102 ±10min 内已发同向信号）；75%（238 条）真被拦。
- 真被拦中 **83%（198 条）v102 同时刻自己也决策卖出**，只是 trend 重构把卖分平均压低 7.6 分跌穿 65/75 记录阈值；**显式 BULL 门控（strong_uptrend）作为主因的拦截 = 0 条**（v3 §3.1 的头号假说被数据排除）。
- 被压线信号事后胜率 58.7%（BULL 态子集 63%）——误拦集中于压线通道。

### 2.2 X9 阈值阶梯实测（两组同阈值，全管线含冷却联动）
| 指标 | t65（生产现值） | t55（统一 55/65） |
|---|---|---|
| baseline 胜率 | 50.00% | **52.80%（+2.8pp，纯阈值效应）** |
| v102 胜率 | 51.50% | **53.64%（+2.1pp）** |
| 趋势层效应 | +1.50pp | **+0.84pp**（Fisher p=0.82） |
| 被拦数 / P2② | 318 / 44.34% | 174 / **44.25%（不过闸）** |
| 密度 b/v | 0.831 / 0.596 | 0.902 / 0.829 |
| 买入侧 / 闭环 | 0 / 0 对 | 0 / 0 对 |

- X8 估计的回收量（174 条）实测**精确命中**；但估计的"P2② 过闸 51.4%"是比较口径假象（其设计为 v102 单边补偿 + baseline 冻结），同阈值下 baseline 新增的 55-65 分带信号重新稀释被拦集。
- 600176 在 t65 的 −26.2pp 单股退化于 t55 消失（−3.3pp, n≈15）——确认为小样本噪声。
- 588170 的趋势层贡献在 t55 翻转为 −3.6pp——t65 的 +7.4pp 改善主要压线抑制假象。

## 3. 降级触发条件评估（v3 §4 逐条核）

| v3 预注册触发条件 | 本轮证据 | 状态 |
|---|---|---|
| ① 修复后复测 P2① < −2pp | X9 实测 +0.84pp | 未触发 |
| ② **修复后 P2② 仍 <50%（拦截不可修复）** | X8 首选修复候选（阈值补偿）全管线实测后 44.25%；且机理上任何固定阈值下重构挤出集 ~56% 为好信号 | **字面达成** |
| ③ 买入侧增量两次复测缺席 | t65、t55 两档 v102 均 0 买入、0 闭环 | **达成** |

**评估结论：触发条件 ②③ 达成。按 v3"无需再开评审"的预注册纪律，应执行 §3.5 降级。** 降级是生产引擎变更，**需用户最终拍板**；拍板后执行形态：factor_weight_5m_trend=0、保留 RSI trigger 加分、权重还给 1 分钟体系，harness 重跑验证（降级形态 ≈ baseline，预期胜率 ≈52.8%@55 档）。

## 4. 阈值决策建议（独立于去留的系统改进）

**采纳 55 档**：两组胜率 +2.1~2.8pp、密度双升、无可比单股恶化、55-65 分带信号质量高于存量均值。58 档不实测（决策增量低）。
**实盘落地改动点**（本次未动 main.py/config.py，完整清单见阈值阶梯报告 §4）：`config.py:323` 65→55、`:324` 75→65、`:325` panic 60→50（防倒挂）、`:370/382/391/408` 个股覆盖对齐 55（600176 的 51 保留）；main.py 消费逻辑（1325-1332、1361-1362）随参数自动生效，买侧 68 不动。

## 5. 优化指引方案更新（v4 版，替代 v3 §3）

1. **拦截质量修复——路线关闭**：阈值路线实测无效，结构性结论成立（§3 触发条件②）。剩余唯一"修复"就是降级本身（拆除重构）。~~3.1~~ 关闭。
2. **信号密度治理——转参数落地**：阈值 55 档采纳后密度 0.83-0.90，仍低于 3-8 健康区；下一步密度空间在**买侧**（买阈值 68 从未实验，且买入侧全样本 0 信号是闭环/做T体系的根基性问题）——建议下一实验：买侧记录阈值阶梯（68→60→52），同样两组同参数。
3. **X4/trend 参数**：结论不变（趋势层非反转检测器）；若降级执行，趋势状态机仅保留为展示层，P1 闸门体系整体退役，P1② 口径修订问题随之消失。
4. **阴跌判多（W5）/000988**：t55 下 000988 仍 0 信号，已复核为**完全自洽的阈值结构结果**——全样本 278 次 SELL 决策中仅 2 次 score≥55（55.7/55.9），且均发生在 09:42 早盘档（适用早盘阈值 65），午后档无一过线；其评分分布（p95≈18.5）距任何合理记录档都过远，**阈值治理救不了 000988**，其问题在评分体系对阴跌形态不敏感（W5 专题）或该标的应移出做T池。另 4.1% 评分 NaN 行仍未归因。
5. **P3 入口条件（修订版）**：① 降级落地且 harness 复测确认 ≈baseline 形态；② 阈值 55 档实盘同步完成；③ 买侧阈值实验完成且买入信号恢复可观测（闭环对数 ≥10）；④ 000988 中间环节归因关闭。寻优空间转向 1 分钟体系校准（v2 轮既定方向）。
