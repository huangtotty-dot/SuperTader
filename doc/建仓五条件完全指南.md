# 建仓五条件完全指南

## 概述

系统建仓的必要条件共 **5 项**，全部满足时评分达 **100 分**，触发 **signal** 级别信号。

| 序号 | 条件 | 权重 | 满足时 | 不满足时 |
|-----|------|------|--------|---------|
| 1 | 市场有方向 | 30分 | ✅ 多头或空头 | ❌ 震荡市 |
| 2 | 多头结构 | 30分 | ✅ 价>MA20 & 价>MA60 | ❌ 价低于移动平均线 |
| 3 | 回撤到位 | 30分 | ✅ 浅回撤-3%或深回撤-10% | ❌ 回撤不足 |
| 4 | 背离信号 | 加分项 | ✅ 连续背离 | ❌ 无/单次背离 |
| 5 | 日内确认 | 加分项 | ✅ 15m右侧 | ❌ 未确认 |

---

## 详细规则

### 1️⃣ 市场有方向 (30分，必要条件)

**规则**：指数需要突破 MA60 的缓冲带

```
多头确认:  指数 > MA60 × 1.005  (突破上方)
空头确认:  指数 < MA60 × 0.97   (跌破下方)
否则:     震荡市 (无方向，signal 结构性不可达)
```

**例子**：
- 上证指数当前 3889.24，MA60 = 3885.50
- 多头目标 = 3885.50 × 1.005 = 3894.65  ← **需上升 +5.41 点**
- 空头目标 = 3885.50 × 0.97  = 3767.74  ← **需下跌 -121.50 点**

**为什么这样设定**？
- MA60 是中期趋势线，突破 MA60 代表 **趋势反转**
- 1.005 / 0.97 的系数防止 **假突破**（缓冲带），确保趋势强度

**你能做什么**？
- 监控大盘指数 K 线
- 关注成交量是否配合
- 设置价格提醒


### 2️⃣ 多头结构 (30分，多头时必要)

**规则**（仅当指数多头时检查）：
```
价 > MA20 AND 价 > MA60
```
> 2026-08-27 注：盘中扫描用**实时价**（当日 forming bar，有 15 分钟缓存冻结窗），不是昨日收盘。

**解释**：
- **MA20**：短期支撑线，快速移动平均
- **MA60**：中期支撑线，趋势确认线
- 两线都站上 = 多头组织完整 ✅

**例子**：
- 某股当前 10.00 元
- MA20 = 9.95 元，MA60 = 9.80 元
- 检查：10.00 > 9.95 ✅ AND 10.00 > 9.80 ✅
- **结论**：多头结构完整 ✅

**如果卡在这里**：
- 距 MA20 差 +0.5%？再涨一点
- 距 MA60 差 +1.2%？等待回调后再上破

**为什么不检查空头**？
- 空头时不需要检查这条（空头反而要求价<MA线）
- 系统只在多头趋势下建多头仓


### 3️⃣ 回撤到位 (30分，必要条件)

**规则**：根据趋势方向，要求不同的回撤深度

#### 多头趋势
```
浅回撤 ≥ -3%
意思：股价从高点下跌，回撤幅度不超过 -3%
```

**为什么**？
- 多头中的小回撤 = 获利回吐 + 洗盘
- 如果回撤 < -3%，说明多头动能不足，需要继续回调
- 如果回撤 ≥ -3%，说明多头力度足够，可以建仓

**例子**：
- 股价高点 10.50 元
- 当前 10.20 元
- 回撤 = (10.20 - 10.50) / 10.50 = -2.86%
- 检查：-2.86% ≥ -3% ✅ **满足浅回撤**

#### 空头趋势
```
深回撤 < -10%  且  RSI(14) < 20
意思：股价从低点反弹，反弹幅度超过 -10%（即幅度足够深），且 RSI 进入深度超卖区
```
> ⚠️ 2026-08-27 修订：RSI<20 是**硬条件**（此前文档漏写）。只满足深回撤不满足 RSI 极值时，
> 仍判 NO-GO（approaching），详情面板/卡点会显示 RSI 差距。

**为什么**？
- 空头中的深回撤 = 轧空 + 获利回补
- 如果回撤 ≥ -10%（太浅），说明空头力度不足，需要继续反弹
- 如果回撤 < -10%（足够深），说明空头有足够的承载力，可以建空

**例子**：
- 股价低点 9.50 元
- 当前 10.00 元
- 回撤 = (10.00 - 9.50) / 9.50 = +5.26%（反弹幅度）
- 实际回撤 = -5.26%（相对于低点）
- 检查：-5.26% ≮ -10% ❌ **未满足深回撤**（还需继续反弹到 -10% 以上）

#### 震荡市
```
按浅回撤 ≥ -3% 判断（保守）
```

**实战判断**：

| 当前回撤 | 多头评价 | 空头评价 | 建议 |
|---------|--------|--------|------|
| -1% | ✅ 已满足 | ❌ 太浅 | 多头可建，空头继续等 |
| -3% | ✅ 刚满足 | ❌ 太浅 | 多头建仓，空头等深跌 |
| -5% | ✅ 满足 | ❌ 还差 | 多头可建，空头差 -5pp |
| -8% | ✅ 满足 | ❌ 接近 | 多头可建，空头快到达 |
| -12% | ✅ 满足 | ✅ 满足 | 两个方向都可建 |
| -15% | ✅ 满足 | ✅ 满足 | 深度回撤，空头优先 |


### 4️⃣ 背离信号 (加分项，不是必要条件)

**规则**：检测 30/60 分钟线背离，特别是 **连续背离**

#### 背离类型
```
顶背离：价新高，MACD DIF 不创新高  → 顶部风险信号
底背离：价新低，MACD DIF 不创新低  → 底部机会信号
```

#### 连续性
```
单次背离：孤立的一次  → 信噪比低
连续背离：前后两个极值都有同向背离  → 高可信度
```

**验证结论**（2026-08-19 验证报告）：
- 单次背离命中率 ≈ 随机基线（无效）
- 60分钟连续底背离：是 **唯一可信的正向信号** ✅

**实战含义**：
- 如果看到 "m60: 底背离✓连续" → **优先级最高**
- 如果看到 "m30: 顶背离" 但 "m60: 无" → **可忽略**
- 如果看到 "m30: 底背离 m60: 顶背离" → **互相抵消，无效**


### 5️⃣ 日内确认 (硬闸门，仅 intraday 模式)

**规则**（仅当必要条件全过、时机门控 GO 时才成为卡点）：
```
15分钟 K 线 右侧确认：
  • 站上 EMA8 (8 周期指数移动平均)
  • 配合放量 (15m 成交量 > 1.2 倍均量)
  • 站上 VWAP (成交量加权平均价)
```

**含义**：股价在日内开始有效上升（右侧），不是左侧反弹

**什么时候检查**？
- 仅在日内盘中扫描（scan_type=intraday，09:30-11:30 / 13:00-14:55 每 5 分钟）
- 必要条件全过且 GO 时：确认通过 → 保持 signal；未确认 → 降级 approaching(待日内确认)
- 数据不足时不惩罚（维持 signal 但标注 intraday_pending）
- eod/manual 扫描不套此闸门

## FAQ

### Q: 为什么我的股票一直是 "approaching"（60-80分）？

**A**: 通常卡在这几个地方：
1. **市场无方向** → 等指数站上/跌破 MA60
2. **回撤不足** → 需要继续回调
3. **背离无法连续** → 需要第二个同向极值

等待这些条件自然满足，无法主动促进。

---

### Q: 我看到了连续底背离，为什么还是 approaching？

**A**: 背离是加分项，不是必要条件。

需要同时满足：
- ✅ 市场有方向
- ✅ 多头结构
- ✅ 回撤到位
- + 背离信号（加分）

如果前三项中有一项未过，背离也只能是 approaching。

---

### Q: 日内确认是什么意思？

**A**: 针对 **盘中扫描** (intraday)：

系统在盘中会多次扫描。为了避免追高，要求：
- 早上 9:30-11:00 的扫描 → 可能评分高但不确认
- 11:00-14:30 的扫描 → 需要 15 分钟 K 线右侧确认后才能 signal

这防止了在高点建仓的情况。

---

### Q: 为什么要有缓冲带（MA60±）？

**A**: 防止 **假突破**：

```
无缓冲带（太敏感）：
  指数 3885.00 → 3885.01 突破 = signal?  ❌ 假突破
  1 秒后反弹回 3884.99 = 取消 signal? 混乱

有缓冲带（更严谨）：
  需要指数 > 3885 × 1.005 = 3897.4  才算突破
  这样的突破强度足够，真实性高
```

## 监控建议

### 实时看板检查清单

每次看表格时，检查这几点：

- [ ] **市场有方向?** 
  - 看大盘指数是否站上/跌破 MA60
  - 如果否，所有 signal 都是 approaching/weak

- [ ] **你的股票有连续背离?**
  - 看 m60 是否有连续背离
  - 如果有，signal 质量高；如果无，需要等

- [ ] **回撤深度?**
  - 多头: -2% 或 -3% 或 -5%?
  - 空头: 已经 -10% 以上了吗?

- [ ] **15 分钟确认?** (盘中时)
  - 是否已站上 EMA8
  - 成交量是否放大

### 决策流程

```
发现一只 approaching 信号
    ↓
查看卡点详情 (点击面板)
    ↓
【市场无方向】→ 等指数突破 MA60（监控大盘）
【回撤不足】  → 等继续回调（设置价格提醒）
【背离无】   → 等第二个极值（观察 K 线形态）
    ↓
当卡点自然满足时，自动升级为 signal ✅
```
