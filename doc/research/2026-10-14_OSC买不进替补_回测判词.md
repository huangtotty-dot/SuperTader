> 实验：`t_io/validation/weak_strong/exp26_osc_backfill.py` → `results/exp26_osc_backfill.json`
> 方案：`doc/solutions/2026-10-14_OSC买不进替补机制设计.md`（推荐 B：受限顺移）
> 生产代码已落地（`oversold_gap_confirm/backfill.py` + 网关撤单 + 钩子），**总闸 `osc_backfill_enabled` 保持 `False`**。

## 结论一句话

**顺移（C）相对「今天生产里真实发生的事」（B）是改善的（Sharpe +0.134），但相对 doc 字面要求的
对照 A（幻想臂）未占优（−0.102），且分半窗方向不一致 ⇒ 未过闸，开关不翻。**
是否上线由 owner 定 —— 见 §4 的两个口径为什么不能混为一谈。

## 2. 闸门判定（doc §3.2 第 4 条）

- **doc 字面口径 C vs A**：ΔSharpe = **−0.102**，分半窗 +0.361 / −0.442（**方向相反**）⇒ ❌ 未过。
- **决策相关口径 C vs B**：ΔSharpe = **+0.134**，分半窗 +0.253 / **−0.017**（h2 差值为噪声级）⇒ 全样本占优，
  但分半窗符号仍判"不一致" ⇒ 机械判词 ❌。

## 3. 为什么 A 是「幻想臂」

回测里 A 假设 top-4 **全部按 10:00 收盘成交**。而被判"买不进"的那 60 笔（21%）恰恰在 A 里
**按 10:00 收盘记了收益**——现实中这 60 笔一股都拿不到（10-14 事故：600097 / 000823 全天封死）。
⇒ A 系统性**高估**，且高估幅度不小：A 0.620 vs B 0.384，**差 0.236**。

**这本身是一条独立且重要的结论**：策略在**这个窗口**的真实期望更接近 **B≈0.38**，
而不是回测常报的 ~0.62 / exp9 的 2.378（exp9 用的是猎手池 + 更长窗口，与本次不可直接比）。
"gap 最强的那批买不进"不是执行瑕疵，而是**信号定义与可成交性的结构性负相关**——
它吃掉的是**最强的那几笔**。

## 4. 为什么 C 没能超过 A（可解释）

顺移票是**第 5~8 名**，gap 更弱 ⇒ 期望收益本就低于被替掉的第 1~2 名。
C 的收益 = "第 1~2 名的纸面收益"换成"第 5~8 名的真实收益"，**换亏是必然**，只是比什么都不买（B）强。
若目标是"追上 A"，需要的是**提高第 1~2 名的成交概率**（追价/挂涨停价排队/更早下单），
不是换人 —— 但方案 A（追价）已论证对封板无效，故这条上限大概拿不到。

**顺移的真实价值不在 Sharpe，而在两点**：① 少空转（B 少 60 笔 × 一天的资金闲置）；
② 19.8 万级别的资金不再冻结到 15:00。这两点本回测**度量不到**（它只算收益序列）。

## 5. 已知近似（照实写，别过度解读）

1. **可成交性 = 「10:00~10:30 那根 30min 棒始终贴着涨停价」**。粒度是 30min，而方案原文要的是
   5/15 分钟 ⇒ **会低估**"盘中短暂封板又打开"（那类在 30min 粒度看算可成交）⇒ 对顺移偏保守。
2. **顺移票入场价 = 10:30 棒收盘**（≈10:30 价）作为 10:08~10:14 的**代理**，比真实成交时点晚
   ⇒ 对 C **偏不利**（入场价更高）。
3. **板块口径用申万一级**（`t_io/rotation/industry_map.csv`），**故意不用韭研概念**——
   韭研分类多为 2026-08 后新建，回测里用 = 严重前视偏差。生产侧不受影响（实盘用"今天的"映射不是前视）。
4. 样本 114 日 / 280 笔 / 60 笔买不进 ⇒ **功效有限**，分半窗只能当参考，不宜当铁律。

## 6. 附：宇宙扩展的回退闸（2026-10-14 新增）

同一天还有一件**独立于本方案**的事：OSC 宇宙从「猎手表里有韭研板块的 ~1551 只」扩到
「全 A ~5020 只」（commit `9077145` + `industry_map.csv` 入库）。它**只有行为证据、没有通过的回测证据**：

- 干净的事实：**候选 292 → 357**，热门板块换血 —— 新增 **医药生物 106 / 军工 49**，
  丢掉 **煤化工 53 / 光通信 37**（`tmp/osc_dryrun_fullmarket_20261014.py` 实测）。
- 补做的 A/B（`exp27_osc_universe.py`）：窄臂 Sharpe 1.584 vs 宽臂 0.620（Δ=**−0.964**），
  但**该数不可采信** —— 窄臂的标的集合取的是**今天的**韭研快照，等于用"事后知道谁入选了猎手表"
  回测 2026-04~09 ⇒ 严重事后选择偏差，方向恰恰是抬高窄臂。⇒ **判为无效证据**，
  既不能据此说扩展有害，也不能说无害。

**回退闸**：`osc_universe_full_market`（`PARAMS`，**默认 `True` = 当前扩展行为**）。
翻 `False` ⇒ `prescreen.universe_board_map(full_market=False)` 只返回猎手池那份映射
（实测 5020 → 1551，且窄 ⊆ 宽），行为回到扩展前。日志会打
`── 盘前预筛开始 ──（前5热门板块 ∩ 猎手池(已回退) ∩ 昨收<MA20）`，audit 里带
`universe: hunter_pool`。

⚠️ **改参数文件后仍需重启策略进程**才生效（`.gszq` 壳 importlib 一次性加载）——
所以这个闸是"**重启时**决定要不要带扩展"，不是"盘中热翻"。

## 7. 建议下一步（供 owner 选）

| 选项 | 说明 |
|---|---|
| **① 保持关闭** | 代码已在、行为不变。等更长窗口（≥1 年）重跑 exp26 再定。**当前默认。** |
| ② 翻开关（按 C vs B 立论） | 依据"真实现状是 B 不是 A，C 优于 B +0.134、且少冻结一天"。风险：分半窗不干净、样本短。 |
| ③ 只做"撤单释放资金"不做顺移 | 即"买不进就撤、当天不再开仓"——纯资金效率改善、不改选股组合，**风险最低**（对应 B 的收益分布 + 资金不再白冻）。 |

**不推荐**：为了让 C 追上 A 去放宽复检条件（现价≥昨收 / ≥VWAP / 非封死）——
那等于把"能买进的弱票"也放进来，是方案 C（限价容忍）已经论证过的坏方向。
