## 一、经典出处与标准定义

### 1.1 经典（正统）口径 ——【实证】

中文圈对 MACD 背离的定义高度一致，可溯源至技术分析经典（Appel 的 MACD 原著体系经《MACD背离技术交易实战技法》等中文著作本土化）：

- **顶背离**：股价创新高（后高 ≥ 前高），但 MACD 的 DIF 或红柱**未同步创新高**（后高 < 前高）→ 上涨动能衰竭，卖出/高抛信号。
  - 新华网客户端有财课堂（权威度S）：https://app.xinhuanet.com/news/article.html?articleId=44902739-4528-4512-90a8-5f30e9372f00
  - 百度百科「背离信号」词条：https://baike.baidu.com/item/%E8%83%8C%E7%A6%BB%E4%BF%A1%E5%8F%B7/9058012
  - 百度百科「MACD顶背离」词条：https://baike.baidu.com/item/macd%E9%A1%B6%E8%83%8C%E7%A6%BB/18221162
  - 雪球《周末课堂：MACD的顶背离和底背离》：https://xueqiu.com/7078444120/211850249
- **底背离（镜像）**：股价创新低（后低 ≤ 前低），但 DIF/绿柱**未同步创新低**（后低 > 前低，低点抬高）→ 下跌动能衰竭，买入/低吸信号。
  - 同上来源；另见和讯网多篇文章（A级）。

**细节共识**【实证】：
- 比较对象优先级：DIF 线位置背离最重要，红绿柱面积/高度次之（百度百科引《MACD背离技术交易实战技法》）。
- 顶背离只需「后高 ≥ 前高」（平或略高都算），不要求显著创新高——这与 owner「第二个高点价格不弱于前高」的口径**完全一致**。
- 底背离镜像即「后低 ≤ 前低（平或略低），DIF 后低 > 前低」。

### 1.2 owner 低吸口径与经典口径的差异 —— 关键发现

owner 的低吸规则：**第二低点价格不弱于前低（价格抬高/持平），但 DIF 低于前低处 DIF** → 判全天相对低点 → 低吸。

- 这与经典底背离（价新低 + DIF 抬高）**方向相反**。
- 但它**精确吻合西方技术分析的「隐藏底背离」（Hidden Bullish Divergence）**：价格低点抬高 + 指标低点更低，含义是「回调健康、上升趋势延续」，是**趋势延续信号而非反转信号**。
  - 雪球《顶背离与底背离》明确列出该分类：https://xueqiu.com/3414045775/327492816 【经验，但定义与西方正统一致】
  - Sohu/UNFX 课堂同样区分常规背离（反转）与隐藏背离（延续）：https://www.sohu.com/a/909891417_122365340

**两种说法各自的逻辑依据评估**：
- **经典底背离**（价新低 + DIF 抬高）：逻辑是「价格还在杀但做空动能已衰竭」→ 赌**反转**。适合做左侧抄底，风险是接飞刀。
- **owner 口径 = 隐藏底背离**（价抬高 + DIF 更深）：逻辑是「价格承接变强（低点抬高），指标深踩是洗盘/动能超调，趋势未坏」→ 赌**延续/日内在上升趋势中的回调结束**。它要求前提是**当日整体偏强**（如分时在均价线上方、日线处上升趋势）；若当日是单边下跌，价格低点抬高+DIF更深这个组合本身就很难出现（价格低点抬高的同时 DIF 更深，意味着跌速快但跌幅被买盘截住）。
- 结论：owner 口径**不是错误，而是另一套正统形态（隐藏背离）**，但它隐含「当日偏多/强势」前提，必须加环境门控；且在中文圈的主流教学里，低吸做T几乎一律用经典底背离，owner 口径属于少数派用法，社区实证反馈极少【存疑：无中文圈该口径的胜率数据】。

## 二、现成平台实现（通达信/同花顺/东财）

### 2.1 有成熟实现 ——【实证：源码可复现】

通达信生态中 MACD 背离公式极其成熟，典型判定模式（多处源码互证）：

- 好股网「分时买入待涨：macd底背离（分时指标）」：https://goodgupiao.com/gupiaogongshi/25651.html
  ```
  A1:=BARSLAST(REF(CROSS(DIF,DEA),1));
  背离:=REF(CLOSE,A1+1)>CLOSE AND DIF>REF(DIF,A1+1) AND CROSS(DIF,DEA);
  ```
  规则细节：**以「相邻两次金叉」为锚点界定两个低点区间**（不是简单找相邻极值），背离成立还要求**当前金叉确认**——即背离确认时机 = 第二次金叉发生的那根K线，是右侧确认而非左侧预测。
- 理想论坛《背离做T分时策略》：https://www.55188.com/thread-30785734-1-1.html —— 同样给出通达信 MACD 背离做T公式框架。
- 缠论系指标（MACD柱背离画线）：http://zbgs3.com/202501245760897.html —— 用「笔/段」划分高低点（段低A:=最低价<=N日内最低 这类分型锚定），自带未来函数声明。

同花顺/东财：搜索未见与通达信同等密度的免费源码生态，但东财富路演官方教程把「15/30分钟 MACD/KDJ 背离」列为超短做T标准工具：https://roadshow.eastmoney.com/zw/20210427100939474121280 【实证：官方教程级别】

### 2.2 确认时机与防未来函数的通用做法 ——【实证+经验】

1. **金叉/死叉锚定法**（主流）：两个低点用两次金叉位置定位，背离信号在**第二次金叉**触发——天然无未来函数，但信号滞后，高点已回落一段。
2. **分时图=1分钟周期**：Sohu《激战分时图之——分时图背离》明确指出「分时图的背离其实就是周期变成了一分钟的背离，化解概率大」：https://www.sohu.com/a/208277068_564913 【经验】
3. **信号漂移问题**：抄底逃顶类分时指标在震荡市信号稳定，「只有在极端单边行情会出现漂移，这是大部分抄底逃顶类分时指标无法避免的问题」：https://www.topgongshi.top/4114.html 【经验】
4. **缠论/分型类画线背离**必然含未来函数（前低被刷新后旧信号消失重画），卖家自己也明示：「缠论必定用到未来函数」：https://zbgs518.com/178.html 【实证：自我声明】
5. **owner 若要程序化**：应模仿金叉锚定法——高低点配对用「DIF 两次上穿/下穿 DEA」界定区间，信号在第二次交叉+价格极值确认时触发，可完全规避未来函数；切忌用「事后回看全天最高/最低点」的全局口径（那是典型的未来函数陷阱）。

### 2.3 失效条件（平台/公式圈共识）——【经验】

- 单边行情漂移（同上 topgongshi）。
- 「主力利用散户对 MACD 的迷信故意制造假象」——公式网老牌 MACD 背离指标的自我警示：https://gszx.com.cn/html/tongdaxingongshi/gs26498.html
- 原则「该涨不涨就逃，该跌不跌就进」（同上）。

## 四、已知批评与局限 ——【实证+经验，多源互证】

1. **背离再背离（多次背离）**：百度百科「MACD顶背离」词条明示需防「多次背离」陷阱，建议「首次背离减仓、再次背离清仓」：https://baike.baidu.com/item/macd%E9%A1%B6%E8%83%8C%E7%A6%BB/18221162 。下跌趋势中可出现三重四重底背离才真正见底：https://ag.yueniuzq.com/qa/ge-gu-macd-shuang-chong-di-bei-li-hou-wei-s2-88867/
2. **指标钝化**：极端单边行情中 DIFF/DEA 长期粘合零轴一侧缓慢爬升/下降，背离被趋势力量压制失效（3k2k）：https://www.3k2k.com/a629.html 。凤凰网：「钝化后背离较为准确，完全按背离操作常带来较大失误」：https://finance.ifeng.com/c/7cCKCUY6qdC
3. **单边市连续打脸 / 假背离三特征**（搜狐，B级）：① 仅单周期背离而大周期不背离；② 未进入指标高位/低位区就背离（20~80 之间往往是强势调整而非背离）；③ 单一指标背离。https://www.sohu.com/a/396243137_527901
4. **顶背离陷阱**（百度百科「背离信号」新增子类）：顶背离后股价继续上涨突破前高，走势由情绪主导——即 owner 高抛口径在强势日的最大风险「卖飞」。
5. **滞后性**：MACD 基于均线差值天然滞后，「等背离确认时行情已走一截」；中文圈流行的对策是改参数 8,17,5 提升灵敏度（头条，数字存疑但方向是共识）。
6. **确认派 vs 左侧派之争**：多数严肃来源主张背离只是**预警**而非指令，须等死叉/跌破均价线确认再动手（宁可牺牲最高/最低那段）；这与 owner「第二高点出现即判全天高点高抛」的左侧打法存在张力——左侧版赔率好但胜率低，且「全天相对高点」的事后判定口径若用于信号触发即构成未来函数。
7. **幅度小于 2% 的织布机行情不做T**（手续费+印花税吃掉差价）：和讯投顾文。【经验】
8. **做T不留隔夜单**铁律：做亏也要当日恢复底仓，否则变成补仓深套：同上。

## 五、对 owner 假设的总评

| owner 规则 | 对应正统形态 | 可信度评估 |
|---|---|---|
| 高抛：二高 ≥ 前高 且 DIF₂ < DIF₁ → 全天相对高点 | **经典顶背离**（放宽为「平或略高」，与百度百科口径一致） | 形态定义【实证】；「= 全天相对高点」的强断言【存疑】，正统口径只说「可能反转」且需死叉/破位确认 |
| 低吸：二低 ≥ 前低（价格不弱）且 DIF₂ < DIF₁ | **隐藏底背离**（趋势延续信号，非经典反转底背离） | 形态定义【实证】（西方正统/雪球有载）；中文圈用于做T低吸的实证反馈【存疑】，且隐含「当日偏强」前提，必须加环境过滤 |

建议传递给后续验证阶段的三条约束：
1. 信号触发必须用「金叉/死叉锚定 + 第二次交叉确认」的无未来函数口径，不能用事后全天极值；
2. 隐藏底背离低吸需加前置门控（如：分时价在均价线上方、日线非下降趋势），否则与经典底背离混用会自相矛盾；
3. 两次背离后的第三次同向信号应降权或禁用（多次背离=钝化高发区，百度百科建议首次减仓再次清仓的递进应对）。
