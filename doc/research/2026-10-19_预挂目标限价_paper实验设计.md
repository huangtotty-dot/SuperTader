# 「预挂目标限价」paper 实验设计（2026-10-19，预注册）

> 背景：`doc/research/2026-10-19_OSC_gap上限与早盘卖执行_回测判词.md` §二。
> exp31 在 1,663 个触发样本上给出：现行 10:00 市价卖 **+1.39%/笔**（t=27.6），
> 预挂目标限价（上界）**+3.83%/笔**，差 **+2.44pp/笔**；全样本（含未触发）增量 +0.23pp/笔。
> 但"30min 棒 high 够到目标 ⇒ 限价成交在目标价"是**成交上界**，排队/脉冲不成交的现实
> 未知。且 exp25 在生产 top-4 选股上实测：E0−E1 只有 **+1.32pp**（SD 3.70pp，n=223），
> 不是全宇宙的 2.44pp —— 本设计按**生产口径 1.32pp** 做功效。
> 本文件把该候选规则冻结成可执行、可证伪的前向实验，**先定判据再动手**。

## 一、假设与判据（预注册，实验期间不得修改）

**H1（执行改善）**：把早盘卖从「10:00 棒 high 触发 → 10:00 市价」改为
「D+1 开盘前预挂 `round(entry×1.03, 2)` 卖限价 → 触及即成交；10:00 未成交则撤单、转回现行规则」，
在**同一批触发事件**上，成交价相对现行 10:00 市价平均提高 **≥ +0.8pp**
（生产选中样本的回测上界 **+1.32pp**；exp31 全宇宙口径 +2.44pp 不适用于生产样本）。

**主要终点（primary endpoint）**
每笔触发事件：

```
edge_px = (fill_price - px_10am_ref) / entry_price
```

- 只统计「按现行规则会触发」的事件（10:00 棒 high ≥ entry×1.03）；
- `px_10am_ref` = GM 10:00 时点的参照价（10:00 棒 close，独立取数，**不得**用成交价倒推）；
- **未成交（含部分成交未卖完）⇒ `edge_px` 记 0**（intent-to-treat，不把没成交的样本剔掉）；
  另报「仅成交样本」的条件均值作次要终点，避免用成交率换收益的假象；
- 不含成本（成本两臂相同，只比执行价差）。

**判据（全部满足才进入 S2）**
1. 样本量 ≥ **120 笔触发**（或实验满 **6 个月**，先到者为准；不足 120 笔则按实际笔数报功效）；
2. 主要终点配对均值 **≥ +0.8pp**，双侧 t ≥ 2.0（并报 bootstrap 95% CI）；
3. **成交率 ≥ 85%**（预挂限价成交 / 应触发）；
4. **保守口径**（见 §四）下主要终点仍 **≥ +0.5pp** —— 防"GM 仿真触及即成交"的乐观偏差；
5. 运维零事故：重复下单 0、撤单失败 0、单笔资金冻结 > 10 分钟 0。

任一不满足 ⇒ 判词「不上线」，写进本文件回执；**不得**通过换阈值/换子样本救回。

**安全停止（可不看判据提前终止）**：预挂限价导致同一票在 14:50 止损时仍被挂单占用、
或出现一次重复卖出/超卖 ⇒ 立即停止实验并回滚。

## 二、实验臂：单臂治疗 + 模型化对照（不做随机化）

**为什么不做 A/B 随机化**：两臂在**触发时点、标的、数量**上完全相同，唯一差异是成交价；
买入侧与选股不受影响。真正无法同时观测的只有"同一笔持仓的两种卖法"，而对照价
（10:00 参照价）可从行情独立取得。因此：

| | 现行规则（对照，**只做反事实**） | 治疗（**实际下单**） |
|---|---|---|
| 账户 | 不实际执行；取 10:00 参照价 | 现行 GM 模拟账户（替换规则） |
| 早盘卖 | 10:00 high 触发 → 市价（参照价 = 10:00 close） | 09:15–09:25 预挂目标限价 |
| 未触发 | 持有，14:50 止损/5 日到期 | 同样持有（目标价挂着，10:00 撤单后与对照一致） |
| 反事实 | —— | 逐笔记录 10:00 参照价 |

⚠️ 本仓 OSC 生产**本身就跑在掘金模拟盘上**（`osc_enabled` 只动模拟盘）⇒ 实验就是
在该账户上把早盘卖规则替换成治疗版，对照用**逐笔 10:00 参照价**，而不是再开一个并行账户：
`framework/gateway.py` 的归属硬锁（`_lock_check`）禁止两个策略同时持有同一代码，
拆账户并行还会引入资金/撮合差异。若后续 OSC 上真实资金，则实盘（对照）与模拟盘（治疗）
可形成天然并行对照，届时可升级设计。

**单臂的代价**：失去"同一时刻两笔真实成交"的直接对照，依赖 10:00 参照价的可比性。
接受此代价的理由：参照价与生产触发判定用同一根棒（`hm=="10:00"`），且 exp31 已证明
两臂差价的横截面 SD 仅 **2.09pp**（配对差，`n=1,663`），对照误差远小于待测效应。

## 三、执行细则（冻结）

### 3.1 挂单时点与价格
- **时点**：D+1 **09:15–09:20**（开盘集合竞价可申报段；09:20–09:25 不可撤单）。
  - 目的：吃到"开盘即高于目标"的样本（占触发样本 **50.45%**，见 §五）。
  - 若券商/GM 仿真不接受盘前委托 ⇒ 退化为 **09:30:00 后第一笔行情** 挂单，并**重跑判据**：
    此时"开盘跳空"部分拿到的是 09:30 价而非开盘价，预期增量下降，**不得**沿用 +1.32pp。
- **价格**：`limit_px = round(entry_price × (1 + 0.03), 2)`，再按交易所最小价位（0.01）与
  当日涨停价夹紧（`min(limit_px, 涨停价)`）。
  - `entry_price` 取账本 `open[code].entry_price`（与生产同源）。
- **数量**：账本 `qty` 与账户 `available` 取小（T+1 可卖量）；`available=0` ⇒ 记录
  `t1_locked`，不挂单（与现行卖侧同口径）。
- **订单类型**：显式限价（`OrderType_Limit`），**不是** `limit_slippage_bp` 的
  "现价±bp"口径。现 gateway 只在 `limit_slippage_bp>0` 时下限价单
  （`execution/auto/framework/gateway.py:172-184`），需新增显式 `limit_price` 入参。

### 3.2 未成交处理
- **10:00 检查点**：未成交的预挂单**一律撤单**，然后按现行规则继续（若该持仓本应 pop_sell，
  则 10:00 市价卖；否则持有到 14:50 止损/5 日到期）。
  - 理由：让"未成交"路径与对照**逐位一致**，只测执行价，不混入新的出场规则。
  - "挂一整天等后面再冲高"是另一条策略规则（exp31 的 E3），**本实验不测**。
- **撤单失败**：重试 2 次；仍失败 ⇒ 记录 `cancel_failed`，转人工告警；
  不得在持仓被挂单占用时执行 14:50 市价卖（会因可用量不足拒单）。

### 3.3 与 14:50 止损/到期的关系
- 14:50 前必须先撤掉当日所有未成交预挂单，再执行止损/到期卖；
- 若预挂单在 14:50 前已成交 ⇒ 账本剔除，14:50 不再处理该票。

### 3.4 重启恢复
- 预挂单的 `order_id / cl_ord_id / limit_px / submitted_at` 落盘到当日状态文件
  （沿用 `hooks.load_day_state/save_day_state`），进程重启后：
  - 已挂未撤 ⇒ 继续跟踪，10:00 正常撤单；
  - 已成交 ⇒ 按 `poll_order` + 账户持仓变化回填账本（复用 `executor` 的迟确认逻辑）。

### 3.5 异常
任何下单/撤单异常**不得阻断主循环**；按 `rt.risk(...)` 发飞书告警（沿用现有钩子风格），
并记 `event` 供判据第 5 条统计。

## 四、数据与测量（逐笔日志，字段冻结）

每笔应触发事件落一条记录（新增 `preplace_probe_{date}.json` 或并入 `sells_*_morning.json`）：

| 字段 | 含义 / 来源 |
|---|---|
| `code, entry_date, entry_price, qty` | 账本 |
| `limit_px` | `round(entry×1.03,2)`（夹紧后） |
| `submitted_at, order_id, cl_ord_id` | 委托链路 |
| `touch_time` | 首次 `price ≥ limit_px` 的 1min 时间（GM history 60s，独立取数） |
| `fill_status, fill_time, fill_price, fill_qty` | 真实成交回报 |
| `px_10am_ref` | 10:00 棒 close（独立取数） |
| `conservative_fill` | 见下 |
| `cancel_requested_at, cancel_status` | 10:00 撤单 |
| `would_trigger_control` | 10:00 棒 high ≥ limit_px（应在所有样本为 True） |

**保守成交口径（判据第 4 条的输入）**
- 只有「1min **最高价 ≥ limit_px + 0.01**（有**高于目标价**的打印，而非仅触及）」才算
  `conservative_fill=True`；卖限价挂在 L，市场价等于 L 可能卡在队列，必须有人以更高价成交；
- 仅触及/队列未成交 ⇒ `False`，其 `edge_px` 记 0（而非记成"会成交在目标价"）。
- 该口径用事后行情复算，不改真实委托，只影响判据统计。

**反事实参照价**：`px_10am_ref` 必须来自独立行情调用（`gm.history` 1800s 或 60s 聚合），
**禁止**用 `fill_price` 或事后的日线倒推。

## 五、功效与工期（exp31 全宇宙面板 + exp25 生产组合实测）

### 5.1 全宇宙触发样本（exp31）

来源：`t_io/validation/weak_strong/exp31_osc_pop_sell_exec.py`，窗口 2026-04-14~2026-09-24，
17,583 条信号、1,663 条触发（9.46%）。

| 量 | 值 |
|---|---:|
| 触发子集配对差 `E0−E1` 均值 | **+2.435pp** |
| 配对差 SD | **2.088pp** |
| 触发样本开盘价 ≥ 目标 占比 | **50.45%**（盘前挂单才吃得到） |
| 触发样本盘中触及（开盘 < 目标）占比 | 49.55% |
| 信号级触发率 | 9.46% |

### 5.2 生产组合实测（exp25，2025-09-19~2026-09-18，E1 口径）

来源：`t_io/validation/weak_strong/exp25_osc_vs_strong.py::run_osc`（4 槽、10 万/票、
top-4 gap 选股）。**重要：生产选股与全宇宙触发样本不是同一分布。**

| 量 | 值 |
|---|---:|
| 平仓笔数 | 332（slip=0）/ 326（slip=20bp） |
| 其中 `pop_sell` | **223（67%）** / 211（65%） |
| `pop_sell` 单笔净收益均值 | **+6.81%** / +6.35% |
| `pop_sell` 频率 | **223 笔 / 243 交易日 ≈ 0.92 笔/日** |
| 生产口径 **E0 − E1**（毛，成本两臂相同） | **+1.32pp** |
| 生产口径配对差 SD | **3.70pp** |
| 生产口径开盘即达目标 | **39.9%** |

**读数**：生产选中的是 gap 降序 top-4，D+1 冲高概率（≈67% 的平仓走 pop_sell）
远高于全宇宙 9.46%，单笔冲高幅度也大得多（生产口径 E1 毛 +5.20% vs 全宇宙 E1 净 +1.39%，
仅量级参考）；但**执行价差反而更小**：生产口径 E0−E1 = **+1.32pp**（SD 3.70pp），
不是 exp31 全宇宙的 +2.44pp。⇒ exp31 的效应量**不能直接搬**，
本节功效一律用**生产口径**的 +1.32pp / SD 3.70pp。

### 5.3 样本量与工期

**样本量**（配对设计，双侧 α=0.05，power=0.8；配对差 SD=3.70pp）：
`n = (1.96+0.84)² × (SD/δ)²`
- 检测 +1.32pp（生产口径上界）：**n ≈ 62 笔触发**；
- 检测 +1.0pp：**n ≈ 108 笔触发**；
- 检测判据下限 +0.8pp：**n ≈ 168 笔触发**。

⇒ 预注册目标取 **120 笔触发**：对 +1.32pp 的 power≈**97%**、+1.0pp≈**84%**、
判据地板 +0.8pp≈**66%**（**设计功效对应 ~0.95pp**；0.8pp 是决策地板，不是有功效的终点）。
按 **0.92 笔/日 ≈ 130 个交易日（约 6 个月）**；上限 **6 个月**。
⚠️ 频率来自 2025-09~2026-09 的韭研池面板组合；生产 2026-10-14 起已扩到全市场宇宙，
候选更多 ⇒ 触发可能更密（若达 1.3 笔/日则约 4.5 个月）；工期按 **4~7 个月** 报。
⚠️ 样本量较大的原因：生产口径的配对差 SD（3.70pp）比全宇宙（2.09pp）大得多，
30 笔只能检测约 1.9pp（80% power），会漏掉 ~1.3pp 的真实效应；**不得**为缩短工期把目标改回 30 笔。
只有 120 笔后按实测 SD 重算置信区间，**不得**据此中途改判据。

## 七、已知限制（写死，避免事后 reinterpret）

1. **30min/60s 粒度**看不到盘口队列；任何"触及即成交"的假设都是上界。
2. exp31 的 E0 用 `max(开盘, 目标) `，依赖盘前挂单能被集合竞价撮合；09:31 才挂会损失
   开盘跳空段（50.45% 的样本）。
3. 只测"早盘卖执行"，不测 `pop_target_pct` 阈值本身（3% 固定，不扫描）。
4. exp31 的效应量来自 2026-04~09 的 114 日窗口（GM 30min 面板 180 天上限），
   exp25 的触发频率来自 2025-09~2026-09；跨市场状态（exp30 的 h2 为负）可能不同；
   paper 结果按**配对**统计，不主张组合年化。
5. 实盘账户若在实验期间也改了早盘卖规则，则对照污染 ⇒ 实验作废重来。
