## §0 规则（生产单一真源）

`core/position_structure.py::stage_daily`（`core/build_decision.features_from_daily` 内联同款）：

```
s20 = MA60_t / MA60_{t-20} - 1          # 60 日线**20 个交易日**的变化率
多头 = s20 > +3%
空头 = s20 < -3%
震荡 = |s20| <= 3%                      # 60 日线一个月内几乎没动
```

**为什么不能用「今天 MA60 > 昨天 MA60」**：符号版实测 震荡占比 ≈ **0.0%**
（MA60 逐日几乎不会恰好相等）⇒ 三态直接退化成两态，等于没定义震荡。

## §1 候选口径（前向 = t+1 开盘 → t+h 收盘，扣同池同日横截面均值，按日聚类 t）

阈值取「让震荡成一个有意义的中间态」的几档；只列 k=10/20 的代表行（完整网格见 exp3 输出）：

| 口径 | 震荡占比 | 多头 H20 | 震荡 H20 | 空头 H20 | 多头−空头 |
|---|---|---|---|---|---|
| k=10 ±1.0% | 25.9% | −0.03 (−0.4) | +0.06 (+1.2) | −0.34 (−3.5) | +0.31pp |
| k=10 ±1.5% | 37.5% | −0.05 (−0.6) | +0.08 (+1.6) | −0.45 (−4.5) | +0.40pp |
| k=20 ±2.0% | 26.7% | +0.06 (+0.8) | +0.01 (+0.2) | −0.24 (−2.5) | +0.30pp |
| **k=20 ±3.0%** | **38.7%** | **+0.05 (+0.6)** | **+0.03 (+0.6)** | **−0.35 (−3.5)** | **+0.40pp** |
| k=20 ±4.0% | 49.2% | +0.03 (+0.3) | +0.02 (+0.4) | −0.52 (−5.3) | +0.55pp |

- **排序在 H=5/10/20 上一致**：多头 ≈ 震荡（都约 0）> 空头（显著为负）。
- 半窗（H=20，k=20 ±3%）：h1 多头 +0.02 / 震荡 +0.12 / **空头 −0.50(t−3.4)**；
  h2 +0.10 / −0.09 / **−0.13(t−1.0)** ⇒ 「空头最差」两段同号；震荡两段在 0 附近摆动
  （+0.12 / −0.09），符合"中间态、没有方向"的定位。
- 按年震荡占比 31%~47%（2017 只有 9% 因样本起步），不随行情消失。

**结论**：取 **k=20、±3%** —— ①月度视角、抗单日噪声；②三组 31%/39%/30% 不退化；
③±2% 更紧但分离更弱，±4% 让震荡占一半、标签失去信息量。

## §2 与旧四阶段的关系（别把旧结论套过来）

| | 旧「④下跌」 | 新「空头」 |
|---|---|---|
| 条件 | MA20<MA60 **且 MA20 下行** | 只要 MA60 近 20 日跌 >3% |
| 含义 | 急跌/超跌段 | 阴跌段 |
| 实测 H20 | **+0.02~+0.034（t+7~+12）更好** | **−0.35（t−3.5）更差** |

两者方向相反是**条件不同**，不是矛盾：超跌反弹属于前者，趋势性阴跌属于后者。

## §3 得分项：**不跟着换**（关键决定）

`stage_daily_code` 原本是 `timing_score` 的一项（0~3 分 / 总分 30 点）。把阶段项换成三态后，
得分 IC 反而变差（exp4，固定其余五项，只替换阶段项）：

| 阶段项 | H5 IC (t) | H20 IC (t) | h1 H20 | h2 H20 | 同号 |
|---|---|---|---|---|---|
| 旧四阶段 {4:3,3:2,1:1,2:0} | +0.0129 (6.1) | **+0.0123 (6.2)** | +0.0116 | +0.0133 | ✓ |
| 三态 多头3/震荡2/空头0 | −0.0196 (−5.9) | **−0.0303 (−8.7)** | −0.0239 | −0.0388 | ✓ |
| 三态 多头3/震荡1.5/空头0 | −0.0220 (−6.5) | −0.0330 (−9.3) | −0.0268 | −0.0414 | ✓ |
| 三态 反向 空头3/震荡2/多头0 | +0.0009 (0.3) | −0.0015 (−0.6) | −0.0048 | +0.0030 | ✗ |
| 无阶段项（对照） | −0.0146 (−5.3) | −0.0268 (−9.7) | −0.0238 | −0.0309 | ✓ |

- 现有得分其余分量（−多头结构 −金叉 −站上MA5 +3×站上MA20 +支撑企稳）本身是**混合方向**的，
  旧四阶段项（逆向：④下跌给最高分）恰好把整体 IC 从 −0.027 拉到 **+0.012**；
  三态是动量方向，叠上去与之对冲 ⇒ IC 转负。
- ⇒ **显示列换三态，得分项继续用旧四阶段**（`stage4_code`），得分/GO 行为不变、无需 bump
  `GO_RULES_VERSION`。代价是表格里「日线阶段」列与得分内部口径不同 —— 已在列头/得分 tooltip 写明。
