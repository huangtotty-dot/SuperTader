## 方案卡 1：Dual Thrust（双推力开盘区间突破）

**来源**：策略族 —— Michael Chalek 于 1980 年代开发，曾长期位列《Futures Truth》杂志最赚钱策略榜（社区转述，未见原始榜单）。中文规则来源：[同花顺 SuperMind《Dual Thrust策略原理（期货）》](https://quant.10jqka.com.cn/view/article/1467)、[信易科技（天勤）Dual Thrust 策略页](https://www.shinnytech.com/articles/trading-strategy/trend-following/dual-thrust)（含完整 Python 源码）、[BigQuant 日内高频 Dual Thrust 应用](https://bigquant.com/wiki/doc/9zCGg7j7az)。

**完整规则（参数化，已写全）**：

```
记前 N 日（不含今日）日线：
  HH = N日内最高价的最高值
  HC = N日内收盘价的最高值
  LC = N日内收盘价的最低值
  LL = N日内最低价的最低值
  Range = Max(HH - LC, HC - LL)

今日开盘集合竞价/第一根K线定 Open 后：
  上轨 BuyLine  = Open + K1 * Range
  下轨 SellLine = Open - K2 * Range     （注意：原文献中两页中文资料把下轨写成
                                          Open + K2*Range，属笔误；天勤源码为减号）

信号（原策略为双向反手、永远在市）：
  价格 > BuyLine  → 做多（有空先平空再开多）
  价格 < SellLine → 做空（有多先平多再开空）

参数：
  N：常用 4 或 5（天勤示例 N=5）
  K1、K2：经典对称 0.5/0.5；天勤示例 0.2/0.2；实战常用 0.2~0.7 非对称
          （K1>K2 偏空易触发，K1<K2 偏多易触发，可按大周期方向动态调整）
出场：
  原版无止盈止损、反手即出场 → 同花顺文中明确指出这是缺陷
  日内改造版（中文社区通行做法）：当日收盘前（如 14:50/14:55）强制平仓，不隔夜；
  可叠加固定止损（注：同花顺文中实测加固定止损反而降低盈利，
  止损位要放到很大才不影响——说明该策略依赖扛回撤，这是重要风险警示）
过滤条件：原版无。常见改进：30min MA5>MA10 才开多（王亚伟/王立立股指期货改进版，
          见雪球转载 https://xueqiu.com/7060676637/67429135）
仓位/次数：原版不限次数反手；日内版通常每日最多 1-2 次
```

**有效性证据**：
- 信易科技官方回测：2018.11.13–2018.11.28（仅约 2 周，样本极短），N=5、K1=0.2、K2=0.5，30 手：沪金 au1812 收益 13.71%、最大回撤 2.04%、年化夏普 8.87；螺纹钢 rb1812 收益 11.50%、回撤 4.99%、夏普 5.93。[来源](https://www.shinnytech.com/articles/trading-strategy/trend-following/dual-thrust)。**注意：窗口只有两周，只能证明规则可执行，不能证明长期有效。**
- 《Futures Truth》「最赚钱策略之一」为社区反复转述，未检索到原始榜单 PDF，按「传闻级证据」处理。
- 反面证据：同花顺 SuperMind 原文明确指出无止损时「最大回撤可达保证金账户 300%」、参数缺乏客观依据。

**T+1 底仓改造**：
- 向上突破上轨 → **买入腿**：用现金买入（即「低买」/追突破加仓），随后在更高位卖出等量底仓完成回转；或作为持有底仓不卖出的确认信号。
- 向下跌破下轨 → **卖出腿**：卖出部分底仓（高卖），尾盘或回落后买回（低接）。
- 原版「反手做空」不可用，直接截断为「只平不开空」。
- 关键改造点：突破腿与回补腿必须同日完成才算一次做T；建议拆成「只做一个方向」的两个独立子策略分别评估（向上做T子策略 / 向下做T子策略）。

**数据可行性**：✅ 完全可行。HH/HC/LL/LC 用历史日线，Open 用今日第一根 1min K线，触发用 1min 收盘价判定。无未来函数。

**成本可行性**：个股日内波动 2-5%，N=4、K=0.5 时 Range 通常为近4日最大振幅（约 3-8%），上轨触发距离 ≈ 0.5×Range ≈ 1.5-4%——**轨道可能过宽，触发当天已是强趋势，做T价差大但频率低**；K=0.2 时触发距离 0.6-1.6%，预期单笔价差 0.5-2%，可覆盖 0.136% 成本。频率估算：每标的约 2-4 天一次信号。**低频高价差，成本维度合格。**

**实验优先级：P0**。理由：规则极简、完全确定、我们的数据全覆盖；直接用「昨日+今日开盘」替换现有 Renko+MACD 入场做 A/B 实验，改动量最小。风险点：A股无做空腿，需在回测里按「卖出腿用底仓」重写损益归因。

## 方案卡 2：R-Breaker（趋势+反转六轨系统）

**来源**：策略族 —— Richard Saidenberg 1994 年开发，曾连续十余年入选《Futures Truth》年度前十（社区转述；信易科技页面给出一张「S&P 前十大交易系统排名」表，R-Breaker 第 9、年收益 37.1%，该表转自 CSDN，非原始杂志，按弱证据处理）。中文完整规则：[迅投 QMT 社区 R-Breaker 模板帖](https://www.xuntou.net/forum.php?mod=viewthread&tid=255&user_code=1L5eYT)、[信易科技 R-Breaker 页（含天勤完整源码）](https://www.shinnytech.com/articles/trading-strategy/trend-following/r-breaker)、[雪球《日内交易最强量化策略：R-Breaker策略》](https://xueqiu.com/6225662583/340245420)。

**完整规则（两个公开公式变体都写全）**：

记昨日 High、Low、Close。

**变体 A（Saidenberg 原版枢轴式，天勤/QMT 源码采用）**：
```
Pivot  = (High + Low + Close) / 3
突破买入价 bBreak = High + 2*(Pivot - Low)
观察卖出价 sSetup = Pivot + (High - Low)
反转卖出价 sEnter = 2*Pivot - Low
反转买入价 bEnter = 2*Pivot - High
观察买入价 bSetup = Pivot - (High - Low)
突破卖出价 sBreak = Low - 2*(High - Pivot)
```

**变体 B（国内流传系数版，0.35/1.07/0.25）**：
```
观察卖出价 sSetup = High + 0.35*(Close - Low)
观察买入价 bSetup = Low  - 0.35*(High - Close)
反转卖出价 sEnter = (1.07/2)*(High + Low) - 0.07*Low
反转买入价 bEnter = (1.07/2)*(High + Low) - 0.07*High
突破买入价 bBreak = sSetup + 0.25*(sSetup - bSetup)
突破卖出价 sBreak = bSetup - 0.25*(sSetup - bSetup)
```
两变体价位排序相同：bBreak > sSetup > sEnter > bEnter > bSetup > sBreak（sEnter/bEnter 相对位置随昨日收盘位置互换）。

**交易规则（原版）**：
- 空仓时（趋势腿）：价格 > bBreak → 开多；价格 < sBreak → 开空。
- 持多时（反转腿）：**当日最高价曾超过 sSetup**，随后价格回落跌破 sEnter → 平多反手做空（即冲高回落止盈反转）。
- 持空时（反转腿）：当日最低价曾低于 bSetup，随后价格反弹超过 bEnter → 平空反手做多。
- 止损：固定价差止损（天勤示例 STOP_LOSS_PRICE=10 跳，按品种调；回测用 35 跳）。
- 时间平仓：14:50/14:55 强平，不隔夜（参数化：CLOSE_HOUR=14, CLOSE_MINUTE=50）。
- 过滤：原版无；反转腿要求「先触及观察价再反向穿越反转价」，本身是二段确认。

**有效性证据**：
- 信易科技官方回测：INE 原油 sc1905，2018.11.14–2018.12.25（约 6 周），14:50 平仓、止损 35 跳、20 手：收益 37.32%、最大回撤 2.78%、年化夏普 6.12。[来源](https://www.shinnytech.com/articles/trading-strategy/trend-following/r-breaker)。**窗口短，且为单品种单参数。**
- S&P 排名表（R-Breaker 年收益 37.1%）：转引自 CSDN，非一手来源。
- 无找到 A股个股上的公开 R-Breaker 回测（期货圈共识是该策略「不适用于 T+1 股票」，原文如此表述——但那是针对纯日内开平，不针对我们的底仓回转模式）。

**T+1 底仓改造**：
- bBreak 向上突破 → 买入腿（现金买入，高位卖等量底仓完成回转）。
- sBreak 向下突破 → 卖出腿（卖底仓，低位回补）。
- **反转腿恰好就是为做T量身定做的**：持多（底仓）时「日内冲高过 sSetup 再回落破 sEnter」= 教科书级的「高卖」信号；反过来 bSetup/bEnter 是「低接回补」信号。这是四个经典框架里唯一自带「冲高出货」出场的，与我们「+0.5% 固定止盈」形成直接替代关系。
- 反手做空截断为「只平不开空」。
- 六轨全部用昨日日线计算，早盘开盘前即可算出全天六条价位线，无未来函数。

**数据可行性**：✅ 完全可行。昨日 H/L/C + 当日 1min 价格与日内最高/最低价即可实现全部规则。「日内最高价曾超 sSetup」用累计日内 max(high) 判断即可。

**成本可行性**：六轨间距与昨日振幅正相关；昨日振幅 3% 时，sEnter 距 bBreak 通常 1-2.5%，预期单笔价差 0.8-2%，覆盖成本。信号频率：突破腿约 2-4 天一次，反转腿在震荡日更频繁——**注意反转腿频率高时单笔价差可能压缩到 0.3-0.6%，需实测，贴成本线**。

**实验优先级：P0**。理由：唯一自带「高卖出场」的完整框架，直接替代我们现有「固定 +0.5% 止盈」这一最弱环节；两个变体可并行 A/B。建议先只迁移**反转腿**（sSetup/sEnter 高卖 + bSetup/bEnter 低接）到现有买入信号之后，作为出场模块实验，比整体替换风险小。

## 方案卡 3：菲阿里四价

**来源**：策略族 —— 日本期货冠军菲阿里实盘使用的突破参照系（人物与业绩为中文期货媒体反复转述，如[七禾网《半年创造1089%收益率》](https://www.7hcn.com/article/446157-1.html)、[新浪财经转载](https://finance.sina.cn/2024-01-29/detail-inafezea8105170.d.html?vt=4)；「半年 11 倍」是该媒体对实盘大赛冠军的报道，含主观心智交易成分，不能归因于四价规则本身）。规则来源：[掘金量化社区《10种经典日内交易策略模型思路》](https://bbs.myquant.cn/thread/1835)、[天府财经《菲阿里四价在日内交易中的使用》](https://www.tianfucaijing.com/news/5210.html)、[BigQuant 菲阿里四价策略示例](https://bigquant.com/wiki/doc/BdvkDT4zgI)。

**完整规则**：
```
四价：昨日高点、昨日低点、昨日收盘、今日开盘
上轨 = 昨日高点
下轨 = 昨日低点
信号：价格突破上轨 → 买入开仓；价格跌穿下轨 → 卖出开仓
出场：收盘前平仓（日内策略，不隔夜）
过滤：原版无参数化过滤；菲阿里本人结合主观「阻溢线」（压力/支撑线）——
      主观部分不可工程化，标注「来源未给出，需自行补全」
止损：来源未给出参数化止损，需自行补全（常见补法：跌回轨内 X% 或固定比例止损）
昨日收盘、今日开盘：作为参考价，原版不直接进入计算公式
```

**有效性证据**：**仅方法论声称**。未检索到带胜率/盈亏比/年化的公开规范回测（BigQuant 页面只有规则与框架截图，无绩效表）。「半年 11 倍」为带主观交易的实盘大赛报道，非本规则的回测证据。

**T+1 底仓改造**：
- 突破昨日高点 → 买入腿；跌破昨日低点 → 卖出腿（卖底仓）。
- 本质等同「昨日高低点区间突破（NRB 的特例）」，与 Dual Thrust N=1、K1=K2 且 Range 锚定昨高昨低的形式高度相似。
- 昨日高低点是 A股散户最密集盯住的价位，自我实现效应强，但也容易被主力做假突破——A股个股上假突破成本需实测。

**数据可行性**：✅ 完全可行，最简单的一个。

**成本可行性**：昨日高/低点距离开盘通常 0.5-3%，突破后延续空间不定；预期单笔价差 0.5-2%，频率约 2-5 天一次。合格但**轨道比 Dual Thrust 更「裸」，无缓冲，假突破磨损是主要风险**。

**实验优先级：P1**。理由：规则是 Dual Thrust 的退化特例，若 Dual Thrust（P0）有效，菲阿里四价可作为 K→0 的边界参数顺带测；不值得单独优先排期。除非 owner 想要「最简可解释基线」——那它是最干净的基线。

## 方案卡 4：空中花园（隔夜跳空 + 首根K线通道）

**来源**：策略族 —— 中文期货社区经典日内策略（原创出处不可考，程序化交易教材级规则）。规则来源：[掘金量化 10 种经典日内策略](https://bbs.myquant.cn/thread/1835)、[BigQuant《空中花园策略：基于中证1000股指期货的日内交易策略》](https://bigquant.com/wiki/doc/ymMW6nGhXl)、[经管之家 backtrader 空中花园多品种参数优化帖](https://bbs.pinggu.org/thread-10778967-1-1.html)。

**完整规则（参数化）**：
```
前置过滤（关键）：今日开盘价 >= 昨收 * 1.01（高开≥1%）
              或 今日开盘价 <= 昨收 * 0.99（低开≥1%）
              ——只在跳空日交易，不跳空不做
通道：上轨 = 当日第一根K线（1min 或 5min）最高价
      下轨 = 当日第一根K线最低价
入场：价格突破上轨 → 做多；价格跌破下轨 → 做空
      （backtrader 版细化：高开日只做向上突破/低开日只做向下突破，
        即顺着跳空方向做，见 CSDN 实现 https://blog.csdn.net/qq_26948675/article/details/120711501）
出场：反向突破反手 / 尾盘强平不隔夜
止损：原版未给出参数化止损——「来源未给出，需自行补全」
```

**有效性证据**：
- 经管之家/backtrader 系列帖对各期货品种做了参数优化，帖内说明「日内策略普适性不高，很难多品种同时盈利，只有部分品种表现较好」——**这本身是重要的负面证据**：该策略品种敏感度高。
- 一篇交易员复盘博客（[CSDN《为什么"空中花园"策略现在不好用了》](https://blog.csdn.net/weixin_33721344/article/details/85885474)）记录该策略 2018 年后在期货上失效加剧：「信号减少、突破后迅速反转」。主观复盘，非规范回测，但方向一致。
- BigQuant 中证1000 股指版页面只有规则与代码，无绩效表。

**T+1 底仓改造**：
- 天然契合 A股：A股个股跳空频繁，「高开≥1% 且突破首根K线高点 → 买入腿/持有底仓不动」；「低开≥1% 且跌破首根K线低点 → 卖出腿（卖底仓，尾盘回补）」。
- 改造点：首根K线通道在 09:31 即确定，是全市场最早的入场信号之一，与我们现有 09:30-11:30 早盘窗口匹配。
- 注意：个股 09:30 第一分钟成交拥挤、滑点大，建议用 5min 首根K线（09:35 确定通道）降低噪音——代价是入场更晚。

**数据可行性**：✅ 完全可行。昨收、今日开盘、首根 1min/5min K线高低点。

**成本可行性**：跳空日的日内延续幅度通常 1.5-4%，单笔价差预期 1-2.5%，频率约 3-6 天一次（取决于股票池跳空频率）。**成本维度良好。**

**实验优先级：P1**。理由：规则完整、与我们早盘窗口天然匹配、A股跳空频率高；但期货圈已有失效记录，且与我们现有「早盘预警」因子可能有重叠/冲突，建议二轮作为「跳空日子策略」专项实验（只在跳空日启用，与主策略并行而非替换）。

## 方案卡 5：可转债日内 T0「主升波段」策略（雪球量化实盘分享）

**来源**：社区 —— [雪球《量化可转债之最活跃转债的日内T0策略，主升路上的高抛低吸！》](https://xueqiu.com/5969301828/398397419)（2026-07，作者自称原创实盘策略、效果良好，**未给出任何绩效数字**）。

**完整规则（尽量还原，缺项标注）**：
```
选债池：近三日成交额最高的前 2 只转债；剔除盘子过大的权重债；
        剔除当日涨幅 ≥19%（转债 20% 涨停，无日内空间）；
        黑白名单机制（黑名单：连续两日多次止损的债；白名单：主升路上量价齐升的债）
买入：趋势确认（均线+斜率+成交热度）+ 动量反转（主升段小波段筹码买入集中/反转信号）
      + 成交额支撑（下单时成交额足够大以控制滑点）——基于 TICK 逐笔快照计算
卖出：止盈 = 价格偏离均线超阈值且出现筹码流出；止损 = 跌破建仓时阶段低点（破位严格止损）
时段：09:33–14:55，日内清仓不隔夜
```
缺失项：均线周期、斜率阈值、偏离阈值、筹码集中度的精确定义——**来源未给出，需自行补全**，且作者明示不会公开逻辑与代码，属引流性质分享。

**有效性证据**：**仅作者方法论声称，无任何数字**。

**T+1 底仓改造**：思路可迁移为股票版：「趋势确认+放量」作为买入腿过滤、「偏离均线+缩量流出」作为止盈、「跌破入场点阶段低点」作为止损。这三条与我们现有 MACD/Renko 模块是同族工具，改造价值在**组合方式**而非新因子。

**数据可行性**：❌ **不可行（关键短板）**。原策略明确基于逐笔快照（tick 级筹码集中/流出），我们只有 1min K线，「筹码买入集中/流出痕迹」无法精确复现。可用 1min 成交量放大/萎缩近似，但已不是原策略。

**成本可行性**：转债日内高频小波段单笔价差目标通常 0.3-1%（作者未给数字，此为转债 T0 社区一般量级描述）；叠加转债无印花税、佣金极低才成立。**迁移到 A股 0.136% 双边成本下，小波段目标贴成本线，判负期望风险高**；若把目标价差放大到 1%+ 则不再是原策略。

**实验优先级：P2（观望）**。理由：数据不可复现 + 无绩效证据 + 引流性质。仅「跌破建仓点阶段低点即止损」这条出场纪律值得吸收为通用模块。

## 方案卡 6：可转债网格 / 底仓网格做T

**来源**：社区 —— [雪球《可转债网格交易详细策略》](https://xueqiu.com/6840395225/224739509)（2022，文中明确提到「有底仓的股票也可以用网格做T，另有专用于做股票T+0的策略」）、[雪球《可转债网格策略实验记录》](https://xueqiu.com/8773710158/317698214)（2024，个人实验记录，无系统绩效）。

**完整规则（通用参数化形式，来源给出框架、参数需自补）**：
```
区间：选定锚定价 P0（如区间中位/近N日均价），网格间距 g%（转债常用 0.5-2%）
底仓：区间中位建底仓（与我们现有底仓天然对应）
卖出腿：价格每上行一格（P0*(1+k*g)）卖出一格仓位（用底仓）
买入腿：价格每下行一格买入一格仓位
破网：向上突破区间上限 → 清仓或停止卖腿；向下破下限 → 停止买腿/止损
过滤：选无明显暴雷风险、区间内震荡的标的
缺失：格数、每格仓位比例、区间再定位规则——来源未给出统一标准，需自行补全
```

**有效性证据**：**仅社区实验记录与方法论声称，无规范回测数字**。

**T+1 底仓改造**：这是所有候选里**与「底仓+回转」模式天然同构**的方案——底仓网格做T在 A股就是标准玩法，无需改造，只需补全参数（网格间距、格数、区间锚定与再定位规则）。与现有系统的差异：网格是「被动挂单式」做T，不预测方向；现有系统是「信号触发式」。两者可叠加（网格管震荡日、信号管趋势日）。

**数据可行性**：✅ 完全可行（只需价格，定时轮询即可）。无未来函数。

**成本可行性**：网格间距 g 必须 > 0.136%×2（来回成本）+ 滑点，即 **g ≥ 0.5% 才有正期望**；A股中大盘日波动 2-5% 时 0.5-1% 网格每天可成交 1-3 格。频率高、单笔价差小但高于成本线，**是成本约束下恰好合格的下限方案**——正期望薄，靠频率累积，对滑点极敏感。

**实验优先级：P1**。理由：与底仓模式零摩擦、可常驻所有持仓作为「震荡日兜底收益」；但正期望薄，必须与信号策略做收益归因隔离（否则回测分不清谁赚的钱）。建议作为 baseline 对照组常驻。

## 方案卡 7（顺带收获）：VWAP 分时均价突破

**来源**：[掘金量化《10种经典日内交易策略模型思路》](https://bbs.myquant.cn/thread/1835) 第 9 条「分时均价突破」。

**规则**：当日分时均价（VWAP，累计成交额/累计成交量）为唯一轨道；价格上穿均价 → 买入开仓；下穿 → 卖出/做空；收盘平仓。无参数、无过滤、无止损——「来源未给出，需自行补全」。

**有效性证据**：仅方法论声称。但文中指出一个关键逻辑：**分时均价是所有行情软件默认展示的线，自我实现效应在全市场最强**——这对 A股个股尤其成立。

**T+1 底仓改造**：上穿 VWAP → 买入腿；下穿 VWAP → 卖出腿（底仓）。或作为过滤器叠加到其他方案：只在 VWAP 上方执行买入腿、下方执行卖出腿（顺势过滤）。

**数据可行性**：✅ 1min K线的成交额/成交量即可累计计算 VWAP，无未来函数（用 ≤t 的累计值）。

**成本可行性**：VWAP 穿越信号在震荡日极频繁（一天可 5-10 次），单笔价差常 <0.5%——**裸用判负期望**；作为过滤器使用则零成本。

**实验优先级：P2（裸用）/ P0（作为过滤模块）**。建议立即作为过滤条件叠加到 Dual Thrust / R-Breaker 实验里：突破上轨且价格在 VWAP 上方才做买入腿。

## 跨方案对比与迁移总结

| 方案 | 规则完整度 | 证据强度 | 数据可行 | 成本可行 | 优先级 |
|---|---|---|---|---|---|
| Dual Thrust | ✅ 全参数 | 弱（2周期货回测+杂志传闻） | ✅ | ✅ 低频高价差 | **P0** |
| R-Breaker | ✅ 全参数（两变体） | 弱-中（6周原油回测+排名转述） | ✅ | ✅/⚠️ 反转腿频率需实测 | **P0**（先迁移反转腿做出场模块） |
| 菲阿里四价 | ⚠️ 缺止损/过滤 | 仅方法论声称 | ✅ | ✅ | P1（最简基线） |
| 空中花园 | ⚠️ 缺止损 | 弱（多品种优化帖+失效复盘） | ✅ | ✅ 跳空日高价差 | P1（跳空日专项） |
| 转债日内T0 | ❌ 核心定义缺失+tick依赖 | 仅作者声称 | ❌ 无逐笔 | ⚠️ 贴成本线 | P2 |
| 底仓网格 | ⚠️ 参数需自补 | 仅社区记录 | ✅ | ✅/⚠️ 期望薄 | P1（baseline 常驻） |
| VWAP 突破 | ❌ 缺出场止损 | 仅方法论声称 | ✅ | ❌ 裸用负期望 | P2 裸用 / P0 作过滤 |

**三个最重要发现**：
1. **R-Breaker 的反转腿就是我们要找的「高卖出场」**：「日内冲高超过观察卖出价 sSetup 后回落跌破反转卖出价 sEnter → 卖出」直接替代现有「+0.5% 固定止盈」，且完全由昨日 H/L/C 参数化计算、无未来函数。这是本方向对现有系统增量最大的一条。
2. **所有经典框架的轨道都只用「昨日日线+今日开盘」计算**——我们的数据全覆盖，迁移没有任何数据障碍；真正的风险不在数据而在 T+1 改造后的损益归因（卖出腿用底仓后当日必须回补，回补价决定盈亏，回测框架要重写归因逻辑）。
3. **证据普遍薄弱**：公开回测窗口都很短（2-6 周）、单品种单参数；「Futures Truth 前十」「半年 11 倍」均为转述或含主观成分。所有方案的有效性必须以我们自己的 A股回测为准，公开证据只够支撑「值得进实验」，不够支撑「直接上实盘」。

**证据空白项（诚实清单）**：
- 菲阿里四价、空中花园、转债网格、VWAP 突破：未找到带胜率/盈亏比/年化的规范公开回测。
- R-Breaker 的「Futures Truth 连续十年前十」与 S&P 排名表（年收益 37.1%）：均为中文社区转引，未见原始杂志来源。
- Dual Thrust 天勤回测仅 2 周窗口；信易 R-Breaker 原油回测仅 6 周。
- 未找到任何上述策略在 **A股个股**（非股指期货）分钟级上的公开规范回测——T+1 底仓改造后的表现完全是未知领域，这正是本次实验要回答的问题。
- 雪球转债 T0 策略作者拒绝公开核心参数，其声称的实盘有效性无法核验。

**给实验设计的建议**：
- P0 实验一：Dual Thrust（N=4，K1=K2∈{0.2,0.5}）替换入场，出场仍用现有规则 → 隔离入场因子的贡献。
- P0 实验二：R-Breaker 反转腿（变体A与变体B并行）替换「+0.5% 固定止盈」 → 隔离出场因子的贡献。
- 两个实验不要同时上，先做因子归因清晰的单变量替换，再做组合。
- 网格（方案卡 6）作为 baseline 常驻对照组，所有信号策略的超额必须跑赢网格才算真本事。
