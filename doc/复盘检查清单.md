## 第一步：地基审计（10 分钟）

在动手改任何参数之前，先回答四个问题：

### 1.1 今天的成交记录完整吗？

```python
import json
vt = json.load(open("t_io/virtual_trades.json"))
for code, actions in vt.get("trades", {}).items():
    sells = actions.get("SELL_HIGH", [])
    buys = actions.get("BUY_LOW", [])
    # 检查：每条记录是否有 price 字段？是否 price=0？
    missing_price = [t for t in sells + buys if not t.get("price")]
    if missing_price:
        print(f"⚠️ {code}: {len(missing_price)} 条记录缺 price 字段")
    # 检查：配对是否合理？
    total_sold = sum(t["qty"] for t in sells)
    total_bought = sum(t["qty"] for t in buys)
    print(f"{code}: 卖{total_sold}/买{total_bought}")
```

✅ 如果任一条记录缺 price → 今天的收益数据**不可信**，先标记后进入第四步修复。
✅ 如果 `total_bought == 0 and total_sold > 0` → 标记为"只卖不买日"。

## 第二步：逐股票深度 trace（最重要，20 分钟）

### 2.1 对每只股票，用脚本从决策轨迹中提取完整数据：

```python
import json
from collections import defaultdict

# 读取决策轨迹
records = []
with open(f"t_io/traces/decision_trace_{today}.jsonl") as f:
    for line in f:
        if line.strip():
            records.append(json.loads(line))

# 按股票分组
by_stock = defaultdict(list)
for r in records:
    by_stock[r["code"]].append(r)

for code, recs in by_stock.items():
    max_buy = max(r["buy_score"] for r in recs)
    max_sell = max(r["sell_score"] for r in recs)
    buy_over_threshold = sum(1 for r in recs if r["buy_score"] >= r.get("buy_threshold", 42))
    sell_over_threshold = sum(1 for r in recs if r["sell_score"] >= r.get("sell_threshold", 42))
    print(f"{code}: max_buy={max_buy:.0f} max_sell={max_sell:.0f} "
          f"buy_over={buy_over_threshold}/{len(recs)} sell_over={sell_over_threshold}/{len(recs)}")
```

## 关键原则

1. **先看原始数据，再看摘要** — 日志摘要是被过滤的结果，不能用来诊断过滤问题
2. **用脚本算，不用直觉猜** — 每一句"买分太低"都要有数字支撑
3. **追完整链路** — 信号→风控→阈值→仲裁→推送→执行→记账，不能停在任何一层
4. **写反事实** — 不是说"如果 X 会更好"，而是用脚本模拟"改 X 后的实际效果"
