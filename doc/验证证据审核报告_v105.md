## 1. R1 信号事件化 —— 真修复（本轮最大进展）

- **通知阈值**：harness 实现个股覆盖优先，复算实测阈值分布与 config STOCK_PARAMS 逐一吻合 ✓。两处与实盘偏差：① 恐慌阈值 60 分支（10:00 前且 today_ret<−4%）未实现——harness 的 daily_ctx 不带 daily_day_ret；② 早盘卖出分支实盘先查个股覆盖（main.py:1332），harness 只用全局 75。
- **段去重**：同方向且间隔 <5 分钟合并、保留段首——无 settle 择优、无前视选择偏差 ✓。相邻间隔=1 分钟占比 **92.7% → 0.0%**，N 虚增问题消除。
- **冷却**：record_signal 接入，cooldown_minutes=30、买卖分别冷却，与实盘同语义 ✓。
- **复算**：98 信号 / 胜率 48.96%，与声称（98 / 49.0%）完全一致。
- **新暴露的问题（比胜率更重要）**：密度 **0.82 个/股/日**（59/120 股日有信号），远低于方案 3-8 健康区间。含义：**事件化口径下评分体系很少触及通知阈值——这套系统"几乎不报警"**。对手动做T的用户，一个一天给不出 1 个信号的系统辅助价值有限。这是 P3 之前必须面对的结构性问题（方向：阈值体系 per-stock 校准，或信号分级推送——高分报警+低分记录）。

## 2. 五档降三档 —— 代码修复真实，但删除依据与 87.5% 声称不实

- **代码层核验 ✓**：trend_regime 不再产生 STRONG（枚举保留无产出路径），门控统一 BEAR 买×0.6/+6、BULL 卖×0.6/+6，signal_engine 应用点同步，decision_trace 证实门控实际生效（BEAR 559 次 / BULL 470 次）。遗留：signal_engine:1176-1212 STRONG 分支成死代码（无风险但应清理）；trend_regime.py:7/13 注释仍是五档描述。
- **"STRONG 准确率 2-4%"作废**：该值来自 `timeline[i+6]`——时间线条目是**非等间隔状态转移记录**，"第 6 次转移后"≠"30 分钟后"，口径无意义。我第一轮按方案口径（STRONG 时点后 30 分钟**价格**方向）的补算是 **50.0%/54.3%（≈抛硬币）**。删档决策方向尚可接受，但引用的证据应作废。
- **一致率 75.0% vs 87.5%**：v104 与 v105 的趋势时间线 **108 天逐字节相同**，HEAD 代码同口径复算 = **75.0%，精确复现 v104**；87.5% 对应"每日最后一个非 NEUTRAL 状态"口径（前视更重），**HEAD 代码跑不出 87.5%——该数字不可复现，声称不实**。另：多天状态段 1-1 平局时众数取谁靠集合迭代顺序，75% 本身对平局规则敏感；前视问题（全天众数）未修；23 个反转日只计数、切换正确性仍不评估。

## 3. R4 T 闭环 —— 引擎可复现，但 +15584.51 不是"做T收益"

- 声称的 21 对 / +15584.51 / 分股（600176 +14586.91、603667 +953.81、588170 +43.79）我按 harness 口径**精确复现** ✓，抽查 2 对费用逐分手核正确 ✓。
- **三处偏离方案 §1.2**：① 跨日 FIFO 配对（方案明确"同一 code 当日配对"）；② 反T 印花税记在买回腿（应在卖出腿）；③ qty 恒缺省 100 股（动态份数未进入 PnL，与 commit 声称不符）。
- **+15584.51 的构成**：600176 贡献 93.6%，其中约 84% 来自——3 对**跨 15-16 天**的反T（07-01 卖 @73.2/71.5/69.6 → 07-16/17 接回 @45.6-49.9，期间股价 −32%）+ 3 对**跨 4 天**的正T（06-22 买 @54.4-54.9 → 06-26 卖 @71.4-72.5，+33%）。这是分钟级信号被跨日配对后**吃下整段趋势行情**（行情 beta + 口径产物），不是日内做T闭环收益。
- **按方案当日 FIFO 口径重算：全样本仅 11 对 / +323.26 元**（600176 +262.93）。数字小了 48 倍——但这才是"做T成功率"该回答的问题。

## 4. P2 评审前置条件未满足（本轮最关键缺口）

- **baseline 未用 v1.0.5 harness 重跑**：validation 下只有旧 p2_baseline（每 tick 口径 6308 信号）。v105 的 98 信号 vs 旧 6308 是**两种口径的对比，P2 四条闸门全部无法评审**。
- 逆势拦截率仍不可计算（门控是降分非拦截，"被拦未发"的信号无记录；v105 中逆势发出仅 4 条）。
- 切换滞后仍未测量。07-08 场景日三档化后：`09:55 BEAR → 13:00 BULL → 13:35 NEUTRAL → 13:45 BEAR`——10:10 反包后仍迟至 13:00 转多（**约 34 根 5分钟K线**，远超 ≤3 根闸门）。
- 样本仍 23-24 交易日 < 方案最低 30 日。

## 5. 回归与新增观察

- **确定性 ✓**：07-02（非平凡 3 信号日）连跑两次字节级一致；归档 v105 信号与今日复跑逐字段一致。
- **000988/600481 不再零信号**（13 条 / 9 条）✓。分股胜率：588170 59.1% / 600481 50.0% / 603667 50.0% / 000988 46.2% / 600176 41.4%。
- **警示信号**：000988 全部 13 条为 BUY_LOW，期间股价 167→109（−35%），而 trend_state **几乎全程 BULL**——三档趋势层在月度阴跌中持续判多，与"P1 一致率 87.5%"的观感直接矛盾。趋势层对"日内方向"或许有效，对"持续阴跌环境"的多头假设可能成为系统性诱导买入的来源，P3 前需专门评估。
