# 每周 Review · 加仓 & 建仓质量

> **版本**：V2.1（2026-08-13）
> **定位**：每周唯一允许"改参数/改条件/上线"的时点。输入=本周每日 Review 的候选登记 + 两张滚动前瞻表；输出=下周生产配置 + 观察项维护。
> **时间**：周六，约 2~3 小时。
> **铁律**：所有变更走验证管线（离线筛查 → 全管线决赛 → 预注册闸门 → 上线 → 观察期）；**预注册闸门在执行前写入当周复盘章节，破闸即放弃回退，不强行上线**。

## §3 建仓质量周评（主轴 ②，~40 分钟）

- [ ] confirmed 建仓股逐只过堂：继续持有 / 止损候选 / 伪信号归因
- [ ] 输出：建仓优化候选（条件增删/权重/阈值/股数口径），注明证据行数

## §4 候选排序与验证管线（~60 分钟）

- [ ] 候选总表排序：预期收益 × 证据强度 × 实施成本；**每周最多 2 个进管线**，其余留档
- [ ] 每个入选候选执行：
  1. **离线筛查**：历史数据重跑，粗看收益/胜率方向
  2. **全管线决赛**：harness_backtest 对照（生产口径 vs 候选口径）
  3. **预注册闸门**：执行前写下量化验收线（密度/胜率/假阳性/无回归），过闸才上线
  4. **上线 + 观察期**：默认观察 2 周，每日 Review 跟踪
- [ ] 破闸处理：记录参数面与证据，回退生产配置，候选归档（**不强行上线**）

### §4.1 已排队议题（2026-08-27 建仓因子挖掘实验登记）

> 证据：`doc/experiment/建仓因子挖掘与分批建仓实验_2026-08-27.md`（127 万股票-日 + 34 万 range 股票-日）
> 脚本可复跑：`t_io/experiment/build_factor_mining_20260827.py`、`range_gate_research_20260827.py`

1. **分批建仓梯级补全**（优先级高）：首笔已是 1/3（`compute_position` W33 A3 分3次节奏），缺第 2/3 笔触发机制——深回撤时追强门控不再出信号，梯级走不完。待决：梯级参数（-3%/-6%/-9% vs -5%/-8%/-12%）、"仅 1/3 成交后反弹"是否允许右侧补第二笔。依据：分批使胜率 +3.4pp、尾部 p5 -2.2pp、满仓成交亏损 -1.9%→-1.1%。
2. **trend_dn 抄底梯级设计**（优先级高）：现行抄底是全表最强信号（w10=66.5% / w20=72.4%）但尾部 p5=-20.4%，适合 -10%/-15%/-20% 梯级摊低（数据：该档 w10=67.9%）。
3. **MACD 金叉加分去留**：因子挖掘显示无边际贡献（金叉 w5=47.6% vs 无金叉 48.3%），建议移除或降权，避免评分虚高。
4. **regime MA60 斜率细化**（仅线索，先验证再议）：[0.97,0.99)+MA60下行是毒区（w10=39.1%）；[1.0,1.005) 带子带有正 edge 但模式不单调。先跑样本外离线验证，过了才进管线。
5. **震荡市门控维持现状**（已裁决，无需动作）：深度研究结论——13 个 range 段落 6 向下 6 向上，段内入场期望≈0 且向下段落灾难级（r10 -2~-4%），**不开"震荡市小仓位首笔"**。每周仅需确认当前 range 段落（ep13，08-06 起）是否已出方向。
6. **已上线（本周观察）**：爆量/远离MA60 双否决因子（每日 Review §4 健康检查跟踪）；建仓数据失败路径修复（数据不足不再白送通过、指数断供有 trace 标记）。
