## 〇、总判定与六阶段总览表（沿用 manual §0）

> 每日报告开头必须先给阶段总览表再展开细节。auto 侧对应项并入 S2/S4。
> 🔴 阶段必须在正文给出：事实（trace/日志证据）→ 判断（归因）→ 动作（候选登记编号）。

| 阶段 | 时段 | 验收内容（合格线） | 数据来源 |
|------|------|--------------------|----------|
| S0 盘前 | ~09:25 | 竞价采集非空、preopen 焦点名单 | t_io/preopen/ |
| S1 早盘 | 09:30-10:00 | 大盘基调推送、信号通道正常 | decision_trace |
| S2 盘中 | 10:00-14:30 | manual：信号评估与拦截合规；**auto：策略进程/watcher 在线、heartbeat 刷新、KILL_SWITCH 不存在** | heartbeat.json / t_io/bridge/ |
| S3 尾盘 | 14:30-15:00 | 尾盘评分预判、pivot 复盘、闭环审计 | pivot_audit / closure_audit |
| S4 收盘后 | 15:00-15:15 | 建仓扫描产出；**auto：尾盘归位、模拟账户当日一致** | position_builder trace / events |
| S5 晚间 | 复盘时段 | 当日复盘报告产出、候选登记 | doc/review/日复盘/ |

## 一、盘前检查

- [ ] 公共：持仓 reconcile（晨间截图对账）、t_qty 铁律（t_qty≤qty）、日历事项
- [ ] **auto 分区**：策略进程/watcher 在线；heartbeat 刷新（heartbeat.json mtime 当日）；KILL_SWITCH 文件不存在；模拟账户隔夜持仓/现金一致（原掘金清单 P-1~P-6）
- [ ] **manual 分区**：竞价采集非空（auction_{date}.json）；preopen 焦点名单生成（S0）；heartbeat_manual.json 刷新（判活）

## 二、收盘复盘主清单

### A. 公共节

- [ ] **A-1 当日盈亏分解**：三栏归因口径（做T差价/风控损益/基线调整/止盈兑现），auto+manual 各一行 + 合计。
      数据源：manual=`t_io/logs/daily_pnl.jsonl`+`closure_audit.jsonl`；auto=事件桥 fill + heartbeat 持仓推
- [ ] **A-2 一致性**：模拟 vs 回测对照；双侧同池标的 verdict 抽查（P3 parity 机制日检，
      数据源：manual_signals_{date}.jsonl vs t_io/bridge/events_{date}.jsonl）
- [ ] **A-3 异常三分类处置**（移植自 auto 清单）：①执行 bug 随时修 ②结构问题进 backlog ③数值只记录——逐条落分类

### B. auto 分区（执行质量与风控）

- [ ] **B-1 执行质量**：拒单=0 且逐条归因（非 0 必须条条有解释）；信号→委托延迟；滑点；尾盘归位；费用口径（原 C1）
- [ ] **B-2 事件桥对账**：events 与飞书通知逐类对账；backtrace 落盘连续；推送留痕（pushes_{date}.jsonl 双侧）（原 C1-5/C1-6 + pushes 留痕）
- [ ] **B-3 信号与通道**：通道分布；no_signal 可解释性抽查；建仓闸 verdict 分布（原 C2；双通道观察项随 P4-6 接线改为时机门口径）
- [ ] **B-4 风控状态**：仓位峰值/现金水位/止损/熔断/地板/绞肉机/MA5破位纪律（原 C3）

### C. manual 分区（信号质量演化）

- [ ] **C-1 加仓质量跟踪** + 前瞻表滚动结算（原日清单 §3）
- [ ] **C-2 建仓质量跟踪** + 前瞻表 + 实现健康检查三项：否决因子触发记录 / 数据不足路径 / timing_gate 故障（原 §4）
- [ ] **C-3 做T**：系统指引 vs 用户操作落差记录 + Renko 逐笔验证（对照回测预期，renko_t trace + renko_t_daily_review.py）（原 §4.5/§4.6）
- [ ] **C-4 持续质量层（跨日滚动）**：新鲜度闸 / 质量水位线 / 转化漏斗（原 §8——前瞻表停摆 10 天无人发现的教训层）

## 三、候选登记（只登记不改参）

- 当日现象只登记候选编号，**周六统一处置**；红线沿用：单日现象不改阈值、单笔不驱动变更。

## 四、每日输出

- [ ] 飞书简报一屏（双侧合并版式：auto 执行/风控一行 + manual 信号质量一行 + 异常逐条）
- [ ] 本地存档：`doc/review/日复盘/YYYY-MM-DD_复盘.md`（含 auto 证据五件套与 manual 数据段）
