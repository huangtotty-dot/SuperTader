## 三个方案对比

### 方案 A：通达信接口（推荐 ⭐⭐⭐）

**优点**：
- ✅ 已安装（pytdx）
- ✅ 支持实时行情、持仓、资金信息
- ✅ 无需登录凭证，直接连接通达信客户端
- ✅ 稳定，被广泛使用

**缺点**：
- ❌ 需要用户在本机安装通达信客户端
- ❌ 仅支持通达信接入的券商

**适配券商**：
- 国泰君安、光大证券、华泰证券 等通达信系券商

**集成方式**：
```python
from pytdx.client import TdxClient

client = TdxClient()
client.connect('127.0.0.1', 7709)  # 本地通达信

# 获取资金余额
# 获取持仓列表
# 获取成交记录
```

**工作量**：⭐ 低（1-2 天）

---

### 方案 B：对接 API（灵活但复杂 ⭐⭐）

不同券商有自己的 API：

| 券商 | API | 认证方式 | 难度 |
|-----|------|--------|------|
| **华泰证券** | 华泰金融终端 API | 账号密码 | ★★★ |
| **国泰君安** | 君弘 API | 账号密码 | ★★★ |
| **申万宏源** | 量化交易系统 | IP 白名单 | ★★★★ |
| **东方财富** | 量化接口 | Token | ★★★ |

**集成方式**（以华泰为例）：
```python
class BrokerIntegrator:
    def __init__(self, broker, account, password):
        self.broker = broker
        self.login(account, password)
    
    def get_holdings(self):
        """从服务器获取持仓"""
        return self.api.get_positions()
    
    def get_balance(self):
        """获取账户余额"""
        return self.api.get_account_info()
```

**工作量**：⭐⭐ 中（3-5 天/每个券商）

## 实施步骤

### Phase 1：通达信接口集成（推荐先做）

**时间**：1-2 天

```python
# 新文件：broker_adapters/pytdx_adapter.py
from pytdx.client import TdxClient

class TdxAdapter:
    def __init__(self, host='127.0.0.1', port=7709):
        self.client = TdxClient()
        self.client.connect(host, port)
    
    def get_account_list(self):
        """获取登录的账户列表"""
        # 通达信客户端登录的账户
        return self.client.get_account_info()
    
    def get_holdings(self, account=None):
        """获取持仓"""
        positions = self.client.get_position()
        # 转换为标准格式
        return self._normalize(positions)
    
    def get_balance(self):
        """获取资金"""
        return self.client.get_fund()
    
    def _normalize(self, raw_data):
        """转换为统一格式"""
        result = []
        for item in raw_data:
            result.append({
                "code": item['stock_code'],
                "name": item['stock_name'],
                "qty": item['volume'],
                "cost": item['price'],
                "type": "etf" if item['code'].startswith(('51', '58')) else "stock"
            })
        return result
```

## 安全考虑

### 认证信息存储

**❌ 不要**明文存储密码：
```python
# 坏做法
self.accounts["账户A"] = {
    "password": "your_password"  # 危险！
}
```

**✅ 应该**：
```python
import keyring
import cryptography

# 存储在系统密钥环
keyring.set_password("supertrader", "account_a", password)

# 或使用加密存储
from cryptography.fernet import Fernet
cipher = Fernet(key)
encrypted_pwd = cipher.encrypt(password.encode())
```

### 权限最小化

```python
# 仅请求必要的权限
adapter = BrokerAPI(
    permissions=['view_positions', 'view_balance'],
    deny=['place_order', 'cancel_order']  # 禁止下单
)
```
