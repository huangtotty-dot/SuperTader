### 1. Q-20260914-1 pre_close 回滚（内存整写覆盖磁盘）

**根因**：`main.py:1790-1795` 尾部归账 `save_held_merged(HOLDINGS)` 把进程内存 dict 整写回磁盘——内存里 pre_close 停在启动时的周五值；而 14:59 eod_pre_close（main.py:1489-1497）只改局部副本 `_hdata` 写盘、**从不同步内存 HOLDINGS**。周五无回滚是因当天尾部无成交没触发写盘，bug 一直潜伏。同款隐患还在主审计 `main.py:1696`。

**改法**（两处）：

a. 主修复——tail 归账改"磁盘为基 + 仅补丁 virtual_qty"（符合 F-3 口径）：

```python
# main.py:1790-1795
# before:  save_held_merged(HOLDINGS)
# after:
            from src.holdings_repo import load_full, save_held_merged
            _disk = load_full()
            _patch = {}
            for _c in _by:
                if _c in (HOLDINGS or {}) and _c in _disk:
                    _e = dict(_disk[_c])                            # 磁盘新值全保留
                    _e["virtual_qty"] = HOLDINGS[_c].get("virtual_qty")  # 唯一允许写的字段
                    _patch[_c] = _e
            save_held_merged(_patch, actor="main", reason="tail_reconcile")
```

b. 防御补强（一行级）——eod_pre_close 同步内存，消除"磁盘新内存旧"源头：

```python

                            HOLDINGS[code]["pre_close"] = _cp
```
