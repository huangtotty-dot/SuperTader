### picks schema（W2 → 执行器契约）

```json
{
  "date": "2026-10-12",
  "sells": [{"symbol": "600481", "qty": 1200, "reason": "rank_exit r=9>M8"}],
  "buys":  [{"symbol": "300456", "target_weight": 0.25, "reason": "rank_enter r=1"}],
  "holds": [{"symbol": "688008"}],
  "meta":  {"n_slots": 4, "buffer_m": 8, "min_hold": 1, "tp_arm": "A", "score": "score_eq"}
}
```

- `symbol` 兼容 `600481` / `SHSE.600481` / `600481.SH`；`holds` 条目可为纯字符串。
- **硬校验（任一不过 → PicksError → 当日不下单）**：文件存在、`date` 与当日一致（防陈旧 picks）、buys.target_weight>0、sells.qty>0。
- buys 列表序 = rank 序（现金截断按此顺序）；target_weight 相对账户净值估计。

## 3. 执行语义

1. **取价**：picks 涉及票 + 全部持仓票，`current()` 快照取当日开盘价（fallback：history_n 60s 当日首根）；取价失败=停牌 → 买单顺延（`no_price`）、卖单顺延，次日 picks 重评。
2. **净值估计**：equity_est = 可用现金 + Σ 持仓 qty×开盘价（无价回退成本价）。
3. **先卖**：picks.sells ∪ 清仓计划（非 buys∪holds 名单的持仓全卖）。
   - T+1：`qty_place = min(qty, available)`，差额记 `t1_blocked`；整清（place≥持仓）放行零碎股，否则 floor 到 100。
   - 卖单异常重试 `s1_sell_retries` 次；`submitted/partial` 轮询 `s1_order_poll_rounds`×`s1_order_poll_sleep_sec`。
4. **后买**：预算 = 期初现金 + Σ（**未拒**卖单 qty×开盘价×`s1_proceeds_haircut`=0.999）。
   - **被拒/异常卖单的回款不入预算**（不透支；若柜台实际放了款，次日自然体现）。
   - 逐 rank：`qty = (target_weight×equity_est − 已持市值)/开盘价` floor 100；现金不足截断（`truncated`），截断到 0 记 `cash_insufficient` 顺延；被拒买单预算自动让给后续 rank。
5. **下单方式**：默认市价单（沿用 gm_main 既有风格，GM 自带涨跌停保护价）；`s1_limit_slippage_bp>0` 时改限价 开盘价±bp（默认 0=市价）。
6. **留痕**（幂等覆盖）：
   - `t_io/state/s1_book/fills_{date}.json`（逐单真源：qty_request/qty_placed/t1_blocked/status/filled_qty/filled_price/fee_est/reason/source）
   - `t_io/state/s1_book/exec_report_{date}.json`（摘要）
   - 事件桥：每单先 `write_order(order_type="S1")`（孤儿闸登记，6a96829c 前科），成交/拒单走既有 `on_order_status` → fill/reject 事件；`_mark_pending_recon` 轮询兜底与既有链路一致。

## 7. 口径假设与诚实披露

1. **开盘价折算**：买单量按「开盘价×haircut 后预算」预折算；市价单实际成交价偏离开盘价时，最终仓位与 target_weight 有偏差（研究回测同为开盘价成交假设，方向一致）。
2. **回款预占**：卖单 `submitted` 未决也按挂单价计入预算（×0.999）；若最终被拒，透支风险由柜台 NoEnoughCash 拒单兜底（fail-closed，与 OPEN_ALIGN 2026-09-28 口径同款），次日自愈。
3. **exec-time 净值为费前估计**：equity_s1_daily 首日版不含费用与基准，EOD 重估脚本为未决项 U2。
4. **W2 尚未产出 picks**（本施工时三路并行）：执行器按上述 schema mock 验证；若 W2 实际 schema 有出入，以 `load_picks` 校验报错为准对齐（fail-closed 不会错单）。
5. **旧引擎挂起超出裁决字面**：裁决点名挂起 align/tail；BASE 建仓/做T信号/卖出门链若继续运行必然重建镜像持仓、与 S1 打架，故一并挂起（`s1_legacy_engine_enabled` 独立开关，可单独恢复）。OGR 影子/滑点观测/心跳/writeback 确认不受影响。
6. **数据缺口**：研究面板止于 2026-09-17，picks 生成（W2）所需的近端行情由 W2 自行解决，执行器不感知。
