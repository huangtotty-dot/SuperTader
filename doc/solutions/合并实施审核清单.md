## 审核原则

1. **设计文档是唯一基准**：实施偏离方案 §5/§6 契约的，要么改实施、要么回改文档（需用户确认），不允许静默漂移。
2. **每阶段有验收闸**：证据驱动（测试输出/对照数据/日志），不接受"应该没问题"。
3. **不破生产**：合并期间 superTrader 人工链路（做T推送/建仓扫描/复盘）任何回归都视为破闸。
4. **代码级红线**（任一触碰即打回）：
   - 掘金 token 或飞书 webhook 明文进入版本库；
   - bridge jsonl 出现双写者（单文件单写者纪律）；
   - 修改 goldminer 现有事件 schema 字段（只允许扩展命名空间）；
   - 破坏 `t_qty 只减不增` 不变量（src/holdings_sync.py）；
   - 引擎 API 退化为隐式读取系统时钟（必须保持时间注入，保回测可重现）。
