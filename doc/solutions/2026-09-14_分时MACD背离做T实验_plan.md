# 分时 MACD 背离做T引擎 · 实验与替代方案 plan

> 触发：owner 2026-09-14 16:00 —— 现有 Renko 做T引擎效果有限（W37 周闭环胜率 54.5%、连续 5 日 <60%），提出新假设：日内第一/第二高点（低点）+ MACD 快线（DIF）背离判定相对高低点，做高抛/低吸。
> 目标：研究依据 → 数据实验 → 指标达标则实现新引擎替代 Renko 通道。

## 规则定义（owner 原话 + 经典口径对照）

- **顶背离高抛**：日内出现第二个显著高点 H2 ≥ H1（价格不弱于前高），但 H2 处 MACD 快线 DIF < H1 处 DIF → 判定为全天相对高点 → 高抛
- **底背离低吸（口径 A · owner 字面版）**：第二个低点 L2 处 DIF < L1 处 DIF → 低吸
- **底背离低吸（口径 B · 经典版）**：L2 < L1（价格新低）但 DIF2 > DIF1（动能抬高）→ 低吸
- 口径 A 与经典技术分析相反，**实验必须 A/B 双口径都跑**，让数据说话

## 阶段

### Stage 1 —— 方法依据调研（explore ×2，并行，与本实验无关耦合）

- R1 中文交易圈：分时 MACD 顶底背离做T 的现存方案（通达信/同花顺指标、雪球/淘股吧方法论）、规则细节（背离确认时机、失效条件）、已知缺陷
- R2 量化/学术视角：intraday MACD divergence 有效性研究、统计证据、适用市场环境（震荡 vs 单边）、A股 T+0 语境下的变体

### Stage 2 —— 数据实验（coder ×1）

- 数据：`t_io/minute_snapshots/20**/**/<code>_YYYY-MM-DD.json`（bars 字段，1 分钟K线）
- 主样本：近 12 个月（2025-09 ~ 2026-09）× 深覆盖 5 票（600176/600481/000988/002639/588170）；603667(111天)/300153(36天)/002451(29天) 作小样本参考；全历史（2023 起）作稳健性参照
- 实现：摆动点检测（窗口 k=5min 局部极值 + 最小间距）→ 背离判定（顶背离 / 底背离 A / 底背离 B）→ 确认触发（颈线/回落确认，避免未来函数）
- 指标（与 Renko 评审口径对齐，便于横向对比）：信号数/日、+30min 胜率与均收益、闭环胜率（当日反向平仓或尾盘了结）、闭环均收益（费后，卖出 0.00121 / 买入 0.00015）、假信号率（+30min 反向 >1%）、分环境分组（当日涨跌日/振幅档）
- 基线对照：Renko 本周实测（闭环 54.5% / +30min 49.1%）+ 随机入场参照
- 产出：实验报告 doc/experiment/ + 机读 JSON

### Stage 3 —— 达标判定（orchestrator 闸门，预注册）

达标线（全满足才进 Stage 4）：① 闭环胜率 ≥60% 且显著优于 Renko 基线 54.5%；② +30min 胜率 ≥55%；③ 假信号率 <20%；④ 信号密度可用（≥1 次/票/2 日）；⑤ 结论在 5 只深样本票中不过度集中（≥3 票成立）
不达标 → 报告呈现 + owner 决策（调参再试 or 放弃），**不强行实现**。

### Stage 4 —— 新引擎实现（达标后，coder）

- 新模块接入 manual 引擎（与 Renko 通道并行 shadow 运行 1 周再切换，遵循验证管线纪律）
- 飞书推送/台账/复盘口径沿用现有通道
- 上线前预注册闸门写入周复盘

## 纪律

- 实验为离线只读分析，不改任何生产代码/参数
- 未来函数零容忍：所有确认信号只能用触发时点之前的数据
- Stage 3 是硬闸：指标不达标不实现
