# 集合竞价信息辅助决策方案（V2 重构版）

> 调研日期：2026-08-26  
> 背景：用户对现有集合竞价推送强烈不满，要求系统性重构  
> 适用对象：A股做T（日内高抛低吸）实盘交易者

---

## 一、现状诊断：为什么现在的竞价推送让人不满意

### 1.1 数据层面的根本缺陷

| 问题 | 根因 | 影响 |
|------|------|------|
| `auction_vol_hand` 全为 0 | `qt.gtimg.cn` 字段[6]在 9:20-9:25 竞价时段返回的是全天累计成交量（此时为0），而非竞价累计量 | 所有量相关分析失效 |
| Top20 竞价额分析为空 | `stock_zh_a_spot_em` 在 9:20-9:25 返回的"成交额"是昨日全天成交额，不是竞价成交额 | `market_score` 固定 50 分，`market_bias="data_pending"` |
| 采集窗口设计不合理 | 09:20/09:22 两个 slot，但 09:22 数据与 09:20 几乎无变化 | 轨迹信息密度低，无法识别趋势形态 |

### 1.2 推送内容层面的空洞

**当前 09:20-09:25 monitor 推送：**
```
竞价观察中 09:22 第1/2次
```
→ 没有任何实质信息，用户看了等于没看。

**当前 preopen 总览推送（如果能发出来）：**
```
竞价额TOP6
  🟢xxx +1.2%
  🔴yyy -0.8%
涨3家/跌2家
bullish
```
→ 信息量极低，没有持仓级别的具体分析，没有可操作的决策建议。

### 1.3 分析维度层面的缺失

现有系统完全没有以下对做T交易者至关重要的维度：
- **竞价价格轨迹形态**（9:20→9:25 是阶梯上升/下降/V形/一字？）
- **持仓缺口与昨日走势联动**（昨日大涨+今日高开 = 高危；昨日大跌+今日低开 = 机会）
- **大盘指数竞价分析**（上证/科创50的竞价方向是当日情绪风向标）
- **缺口幅度分级与操作建议**（>+2% 先卖？<-1.5% 等反弹？）
- **板块/ETF 竞价联动**（588170 与 sh000688 科创50的竞价背离）

## 二、集合竞价对做T交易者的核心价值

> 做T的核心是"日内高抛低吸"，不是抓涨停。集合竞价的意义在于：**在开盘前 5 分钟预判当日开盘后 30 分钟的走势方向，从而决定开盘后的第一动作（先买/先卖/观望）**。

### 2.1 价值一：开盘缺口预警（最重要）

| 缺口类型 | 对做T的含义 | 典型应对 |
|---------|-----------|---------|
| 高开 > +2% | 大概率冲高回落，开盘价≈当日最高价 | **反T**：开盘先卖，等回落接回 |
| 高开 +0.5%~+2% | 强势开盘，但需防高开低走 | 观望 5 分钟，不急于动作 |
| 平开 ±0.5% | 无方向信号，按盘中信号执行 | 正常做T |
| 低开 -0.5%~-2% | 弱势开盘，但可能低开高走 | 观望，等确认方向 |
| 低开 < -2% | 大概率继续下探，可能恐慌杀 | **正T**：等深跌后低吸，或开盘直接止损 |

### 2.2 价值二：竞价趋势形态识别

通过 9:20→9:24:30 的价格轨迹，预判开盘后走势：

| 形态 | 特征 | 做T含义 |
|------|------|--------|
| **阶梯上升** | 价格逐分钟稳步抬高，无大幅回撤 | 多头主动，开盘后延续上涨概率高 → 持有等高抛 |
| **阶梯下降** | 价格逐分钟稳步走低 | 空头主导，开盘后继续下探 → 考虑先卖 |
| **V形/翘尾** | 9:20-9:23 低走，9:24 突然拉升 | 最后一分钟抢筹，主力意图明显 → 跟多 |
| **倒V形/砸尾** | 9:20-9:23 高走，9:24 突然下杀 | 最后一分钟出货 → 跟空 |
| **一字横盘** | 价格几乎不变 | 无方向，等开盘后再判断 |

### 2.3 价值三：大盘情绪风向标

- 上证/深证成指竞价高开 > +0.5% → 当日情绪偏多，个股低开是错杀机会
- 大盘高开但持仓低开 → 个股弱于大盘，警惕
- 大盘低开但持仓高开 → 个股强于大盘，关注
- 科创50（sh000688）与 588170 的竞价背离 → ETF 相对指数的强弱信号

### 2.4 价值四：量能异常（数据修复后）

| 量能信号 | 含义 |
|---------|------|
| 竞价量 / 昨日总量 > 5% | 异常放量，主力有动作，当天波动大概率加大 |
| 竞价量 / 昨日总量 1%~5% | 正常活跃 |
| 竞价量 / 昨日总量 < 0.5% | 极度冷清，当天可能窄幅震荡，做T机会少 |
| 竞价量比 > 3 | 集合竞价活跃度显著高于近期平均水平 |

## 三、数据源修复方案

### 3.1 短期：用已有数据做最大价值提取（1-2天可上线）

**现状可用的数据：**
- `qt.gtimg.cn` 快照：竞价价格（字段[3]虚拟匹配价）、昨收（字段[4]）、今开（字段[5]，9:25 后有效）
- `auction_{date}.json` 中已有 09:20/09:22 slot 的价格轨迹
- `preopen_{date}.json` 中已有 `code_snapshots`（open_gap, direction）

**立即可以做的分析（不依赖新数据源）：**
1. 持仓缺口幅度分级（<-2% / -2%~-0.5% / ±0.5% / +0.5%~+2% / >+2%）
2. 09:20→09:22 价格变化方向（如果采集到更多 slot，可做更精细的轨迹分析）
3. 缺口与昨日走势联动（需要接入 holdings 的昨日收盘价和涨跌幅）
4. 大盘指数竞价（需要拉取 sh000001 / sh000688 的竞价快照）

### 3.2 中期：接入东财分时逐笔数据（1-2周可上线）

**推荐接口：** `ak.stock_intraday_em(symbol="000001")`

```python
import akshare as ak
df = ak.stock_intraday_em(symbol="000001")
# 返回从 09:15:00 开始的逐笔数据，包含 09:15~09:25 集合竞价阶段
# 列：时间、成交价、手数、买卖盘性质
```

**采集策略：**
- 9:24:30 触发一次采集（留给接口响应时间）
- 只采集持仓标的 + 大盘指数（sh000001, sh000688, sz399001），而非全市场
- 4 只持仓 + 3 只指数 = 7 次请求，在 30 秒内可完成
- 落盘格式扩展：在 `auction_{date}.json` 中新增 `"intraday_em": {...}` 节点

**采集时机：**
- 当前系统在 9:20/9:22 采集两次，但 9:22 数据与 9:20 几乎无变化
- 建议改为：**9:20 / 9:24:30** 两个 slot
  - 9:20：基准快照（腾讯 qt.gtimg.cn，快）
  - 9:24:30：精细数据（东财 intraday_em，含最后 30 秒抢筹/砸盘）

### 3.3 长期：竞价专用数据通道（1-2月，可选）

- 接入通达信/同花顺 Level-2 行情（需付费），可获取逐笔委托、未匹配量等
- 自建 WebSocket 连接交易所行情网关（门槛高，不做优先推荐）

## 四、分析引擎重构方案

### 4.1 取消无意义的"竞价观察中"推送

**当前逻辑（preopen.py:521-549）：**
```python
def _send_preopen_monitor_feishu(...):
    # 9:20-9:25 每 2 分钟推一次"竞价观察中 XX:XX 第N/2次"
```

**改为：** 整个 9:20-9:25 期间**不推送任何消息**，仅在 9:24:45 推送一次完整的竞价分析报告。

理由：
- 做T交易者需要的是**结论**，不是"正在观察"的过程通知
- 9:20-9:24 的价格不可全信（9:20 后不可撤单但还在变化），过早推送容易误导
- 最后 30 秒（9:24:30-9:25）才是竞价最关键时段，此时推送最有价值

### 4.2 新增"持仓竞价诊断"模块

```python
class AuctionDiagnosis:
    """持仓级别竞价诊断"""
    
    def diagnose(self, code: str, slots: dict) -> dict:
        """
        输入：09:20, 09:22, 09:24:30 三个 slot 的数据

            "trend_shape": "阶梯上升"/"阶梯下降"/"V形翘尾"/"倒V砸尾"/"一字横盘",
            "vs_yesterday": "昨涨今高开(高危)"/"昨跌今低开(机会)"/"正常联动"/...,

            "confidence": "高"/"中"/"低"
        }
        """
```

### 4.3 缺口-昨日联动规则表（做T专用）

| 昨日走势 | 今日竞价 | 联动判断 | 做T建议 |
|---------|---------|---------|--------|
| 大涨 >+3% | 高开 >+1.5% | **高危：获利盘兑现** | 开盘先卖（反T），等回落 |
| 大涨 >+3% | 平开/低开 | 强势整理，不追 | 观望 |
| 小涨 +1~3% | 高开 >+1% | 惯性上冲 | 开盘后 5 分钟不创新高则卖 |
| 小涨 +1~3% | 低开 | 弱势，可能补跌 | 观望，等企稳 |
| 横盘 ±1% | 高开 >+1% | 突破信号 | 持有等高抛 |
| 横盘 ±1% | 低开 <-1% | 破位信号 | 等反弹减仓 |
| 小跌 -1~-3% | 高开 >+1% | 反弹信号 | 持有等高抛 |
| 小跌 -1~-3% | 低开 <-1% | 延续下跌 | 等深跌低吸或止损 |
| 大跌 <-3% | 低开 <-1% | **机会：恐慌释放** | 等开盘企稳后低吸（正T） |
| 大跌 <-3% | 高开 | 强势反包 | 持有，不急于卖 |

## 五、推送内容重构

### 5.1 推送时机

- **取消** 9:20/9:22 的"竞价观察中"推送
- **新增** 9:24:45 的"竞价诊断报告"推送（每日一次）
- **保留** 9:26 的"大盘基调+C20校验"推送（当前已有，逻辑不变）

### 5.2 推送卡片结构

```markdown
📊 竞价诊断报告 - 做T猎手预警
─────────────────────────────
🌐 大盘竞价
  上证 +0.45% | 科创50 +0.82% | 创业板 +0.31%
  情绪判断：偏多

  科创芯片ETF 588170  -2.89% [阶梯下降] 📉弱于科创50(-0.8%)
    └─ 建议：持有观望，等企稳信号
  
  红利ETF 515180  -0.69% [一字横盘]
    └─ 建议：正常做T，按盘中信号执行
```

### 5.3 置信度标注

每条建议标注置信度来源：
- **高**：缺口 >±2% + 形态明确 + 与昨日走势联动一致
- **中**：缺口 ±1~2% + 形态较明确
- **低**：缺口 <±1% + 形态不明确 + 与大盘背离

## 八、风险与降级策略

| 风险 | 降级方案 |
|------|---------|
| 东财 `intraday_em` 接口在竞价时段不可用 | 回退到腾讯快照，仅做价格分析，不做量能分析 |
| 指数快照获取失败 | 指数分析部分标为"数据缺失"，不影响持仓分析 |
| 某只持仓数据缺失 | 该持仓标为"数据缺失"，其他正常分析 |
| 9:24:45 推送失败 | 9:26 大盘基调推送时附带竞价摘要（兜底） |
| 节假日/非交易日误触发 | 保留现有的 weekday < 5 检查 |
