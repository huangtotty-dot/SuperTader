## 1. 定位与时间线

S1 终选策略 **N=4 槽 / M=8 调出缓冲 / min_hold=1 交易日 / TP 臂 A / score_eq 等权复合分**
（卫生宇宙：<2元 + 60日回撤>60% 剔除 + 上市≥120交易日 + AMOUNT20≥5000万 + 剔停牌 + 剔ST；
研究回测 +53.6%/年、Sharpe 1.05）的生产日频输出器。

规则真源 = `t_io/validation/factor_mining/s0_account/s1_sim.py` 的 `s1_run_sim`（只读 import，
**不重写规则**）。时间线与仿真完全一致：

```
T 日收盘后  : 评估信号（收盘价比成本、当日 rank）→ 生成 T+1 计划
T+1 日开盘  : 执行（先卖后买；卖出回款当日可用 proceeds_lag=0）
```

生产节奏（每晚一次，三个动作串行）：

```
① W1 刷新数据（pivots.pkl / scores.parquet / s1_hygiene_mask.pkl 到当日 T）
② python s1_daily.py --date <T+1交易日>      # 本器，T 晚间跑
③ W3 执行器消费 t_io/state/s1_book/picks/picks_<T+1>.json，T+1 开盘下单
```

## 2. 规则对齐清单（s1_daily.py ↔ s1_run_sim 行级对应）

| 规则 | s1_run_sim | s1_daily.py | 说明 |
|---|---|---|---|
| rank 预计算（值大 rank 小，NaN→inf，mergesort 保稳） | L57-69 | `rank_of_row()` | 逐行同构 |
| 开盘先卖后买、回款当日可用 | L94-117 | `apply_open()` 卖段 | proceeds=q·px·(1−fee)，当日入现金 |
| 买入股数 = int(min(target,cash)/(px·(1+fee))/100)·100 | L118-134 | `apply_open()` 买段 | 整百股向下取整，≤0 放弃 |
| 停牌/缺价订单作废、持仓保留 | L101-102, L120-121 | 同 | 顺延靠"当日收盘重新评估"实现（见 §5） |
| 收盘峰值 peak 更新 | L137-141 | `evaluate_close()` | 仅收盘价有限时 |
| 兜底止损 SL12（−12%，强制，不受 min_hold 约束） | L155-158 | 同 | |
| 止盈臂 A：+5% 卖1/3、+8% 再卖1/3、+10% 清仓；单日跨档连触；每档至少 100 股 | L160-172 | 同 | tiers 状态持久化在账本 |
| 排名调出 ROT：held≥min_hold 且 rank>M；已全仓止盈/止损跳过；部分止盈不挡 ROT 全出 | L191-198 | 同 | held 按**交易日序号**差（= sim 的 d−entry_d） |
| 换入：free_slots = N − 未全出持仓数；slot_target = nav/N；候选 rank≤N 排除已持、按 rank 升序取满 | L202-215 | 同 | nav = 现金+持仓收盘市值 |
| 卫生宇宙 | load_data 内 mask→NaN | 复用 `load_data()` | 分数置 NaN 即出宇宙，rank→inf 自然触发 ROT |

**费率口径**：replay 对拍用仿真口径 `FEE=0.000345`（双边）保证逐笔一致；
生产 `--date` 用 `core/cost_model.py` 股票口径（买 0.00954% / 卖 0.05954%）。
费率只影响股数与现金演化，**不影响换入/换出的日期与标的**（决策只依赖 rank/收盘价/成本）。

## 3. picks JSON schema（写死，W3 执行器按此消费）

路径：`t_io/state/s1_book/picks/picks_{date}.json`（UTF-8，indent=2）

```jsonc
{
  "schema_version": 1,
  "date": "2026-10-12",            // 计划执行的交易日（开盘成交）
  "eval_date": "2026-10-09",       // 信号收盘日（数据内最近一个 < date 的交易日）
  "generated_at": "2026-10-10T22:30:00",
  "status": "OK",                  // OK；fail-closed 时不写文件、退出码 2
  "sells": [{
    "symbol": "603113",            // 6 位代码
    "gm_symbol": "SHSE.603113",    // 掘金格式（6→SHSE，0/3→SZSE，4/8→BJSE）
    "qty": 49600,                  // 卖出股数（全部或止盈部分，开盘可成交假设）
    "reason": "ROT | TP_FIX | SL12",
    "ref_price": 5.03,             // 信号日收盘价（参考价；停牌为 null）
    "limit_risk": null             // "up"/"down"/null，启发式涨跌停风险（见 §5）
  }],
  "buys": [{
    "symbol": "000721", "gm_symbol": "SZSE.000721",
    "target_weight": 0.25,         // 等权槽位权重 = 1/N
    "target_value": 247599.0,      // 目标市值 = nav_estimate / N
    "qty_estimate": 12300,         // 以 ref_price 估算的整百股数，仅供预览
    "ref_price": 20.1,
    "reason": "ROT_IN",
    "rank": 1, "score": 0.5123,
    "limit_risk": null
  }],
  "holds": [{                      // 全部持仓（含当日要卖的，exiting=true）
    "symbol": "002742", "gm_symbol": "SZSE.002742",
    "qty": 59000, "entry_date": "2026-09-15", "cost": 4.23,
    "rank": 2036, "score": -1.23,  // rank 出宇宙为 null
    "unrealized_ret": -0.0426,     // 信号日收盘/成本 − 1
    "exiting": false
  }],
  "meta": {
    "nav_estimate": 990394.0,      // 信号日收盘口径净值估计
    "cash": 5524.0,
    "bootstrap": false,
    "params": {"n":4,"m":8,"min_hold":1,"tp_arm":"A","score":"score_eq"},
    "fee": {"buy": 0.0000954, "sell": 0.0005954, "source": "core/cost_model.py"},
    "slot_weight": 0.25,
    "data_last_date": "2026-10-09",
    "warnings": [],                // 停牌/标签不一致等报警
    "notes": ["...执行口径说明..."]
  }
}
```

**执行器必读（写死在 meta.notes 的口径）**：
1. 开盘成交，**先卖后买**，卖出回款当日可用于买入（与策略口径一致）。
2. `buys[].qty_estimate` 是用信号日收盘价估的，执行器**必须在开盘用实际开盘价重算**：
   `q = int(min(target_value, 可用现金) / (px·(1+0.0000954)) / 100) · 100`，q≤0 放弃。
3. 停牌（无开盘价）单自动作废：卖单未成交 → 持仓保留，次日收盘重新评估（自动顺延/撤销）；
   买单未成交 → 槽位空出，次日重评补候选。
4. `limit_risk` 是启发式（无涨跌停价数据，按板块幅度阈值：主板 9.8%、300/688 为 19.5%、4/8 为 29.5%
   的信号日涨跌幅估算）；**涨跌停权威判定在执行器**（GM 实时行情有涨跌停价），
   跌停卖不出/涨停买不进 → 不成交即可，次日自动重评，无需额外状态回写。

## 4. state.json schema（账本，`t_io/state/s1_book/state.json`）

```jsonc
{
  "version": 1,
  "params": {"n":4,"m":8,"min_hold":1,"tp_arm":"A","score":"score_eq"},
  "asof": "2026-10-09",            // 最近已评估收盘日
  "cash": 5524.289,
  "positions": {
    "603113": {"qty":49600, "cost":5.03, "entry_date":"2026-09-15",
               "tiers":0, "peak":5.21}   // peak=null 表示尚无有效收盘
  },
  "pending": {                     // 已生成、待 asof 后首个交易日开盘执行的计划
    "for_date": "2026-10-12",
    "sells": [{"code":"603113","qty":49600,"reason":"ROT"}],
    "buys":  [{"code":"000721","target":247599.0}]
  }
}
```

**记账口径（重要假设，已披露）**：T 晚间跑 `--date T+1` 时，T 日白天的真实成交已发生；
本器在追账时用**数据里的 T 日实际开盘价**记账成交（与仿真口径一致）。
真实成交若与开盘价记账有差异（部分成交/堵单/滑点），本器账本与真实持仓会出现偏差
——对账与偏差修正是执行器职责；本器每晚从最新数据重估信号，方向性差异次日自动收敛。

追账幂等性：
- `--date D` 重跑且 pending 已属于 D → 按账本 pending 原样重发 picks（不改账本）。
- 账本 asof ≥ 信号日且 pending 不属于 D → fail-closed 报状态不一致，人工核查。

## 5. 边界处理

| 场景 | 处理 |
|---|---|
| **停牌**（无开盘价/volume=0） | 与 s1_run_sim 相同：开盘执行时该单作废、持仓保留；当日收盘重评（停牌票无收盘价 → 不评止盈止损；rank=inf>8 → 若 held≥1 则再次 ROT，等于自动顺延）。picks 中 ref_price=null 并写 warnings |
| **跌停卖不出 / 涨停买不进** | 仿真无此机制；生产由执行器判定（GM 有涨跌停价）。堵单不成交 → 与停牌同理，次日自动重评顺延。picks 用 `limit_risk` 启发式预警 |
| **数据缺失日 fail-closed** | ① 信号日分数全 NaN（如 W1 未刷新）→ 不写 picks、stderr 报警、退出码 2；② 状态文件不存在且未 `--bootstrap` → 退出码 2；③ 账本/数据日期不一致 → 退出码 2。**宁可不出名单，不出错名单** |
| **pending 标签 ≠ 补账日** | 按"数据内 asof 后首个交易日"成交，warnings 记录（容忍 --date 给了非交易日等人为误差） |
| **首日 bootstrap** | 空仓位锚定信号日 → 收盘评估 → 直接买 rank Top-4，各 target=nav/4 |

比较 (date, code, side) 三元组集合 + 股数 + 价格。

| 窗口 | 交易日 | 基准 trades | 本机 trades | (date,code,side) 一致率 | 股数不符 | 最大相对价差 | 基准 final_nav | 本机 final_nav | 结论 |
|---|---|---|---|---|---|---|---|---|---|
| 2024-06-03~2026-09-17（注册窗口） | 560 | 2237 | 2237 | **100.0000%** | 0 | 0.00e+00 | 2,589,765.85 | 2,589,765.85 | **PASS** |
| 2024-03-05~2026-09-17（含 59 个全 NaN warmup 行） | 619 | 2237 | 2237 | **100.0000%** | 0 | 0.00e+00 | 2,589,765.85 | 2,589,765.85 | **PASS** |

基准 final_nav=2,589,765.85 与 `results/s1_r3_final.json` 注册值 `s1_eq_N4_M8_H1_A.fee_x1.final_nav`
逐分一致（锚定正确）。两窗口对拍报告：
`t_io/state/s1_book/replay_parity_2024-06-03_2026-09-17.json`、
`t_io/state/s1_book/replay_parity_2024-03-05_2026-09-17.json`。

**生产路径冒烟**（bootstrap → 次日追账 → 再次日）：
- `--date 2026-09-15 --bootstrap`：空仓买 Top-4（300007/688185/002742/603113，rank 1-4，各 target 25 万）；
  与 sim 当日 ROT_IN 名单中的 300007、688185 重合（sim 有既有持仓故名单不同，属预期）。
- `--date 2026-09-16`：追账以 09-15 实际开盘价成交 4 票（28.82/64.92/4.23/5.03，与 sim 同价），
  现金 6,299；09-15 收盘评估无调出（held=0<min_hold=1 不 ROT —— 注意 entry 当日 held=0）。
- `--date 2026-09-17`：09-16 收盘 300007/688185/002742 rank>8 且 held=1 → ROT×3，换入 rank2-4
  （002165/300546/600785，rank1 为已持仓 603113 自动排除）。
- `--date 2026-10-12`（数据止于 09-17）：信号日自动取 09-17，正常出名单。
- 幂等重发、全 NaN fail-closed（退出码 2）、`--show` 均已验证。
- 冒烟产物已清理，**state.json 未留残留**，周一实盘以 `--bootstrap` 全新起步。

## 7. CLI 参考

```bash
cd t_io/validation/factor_mining/s0_account

# 每日例行（T 晚间，W1 数据刷新后）：生成 T+1 开盘计划
python s1_daily.py --date 2026-10-13

python s1_daily.py --date 2026-10-12 --bootstrap --cash 1000000

python s1_daily.py --show

# 对拍自证（数据刷新后建议重跑一次回归）
python s1_daily.py --replay --start 2024-06-03 --end <数据最新日>
```

退出码：0 正常；1 参数错误；2 fail-closed（未出名单，已报警）；3 对拍不一致。

## 8. 诚实披露（口径假设与未决项）

1. **费率双口径**：对拍用仿真 FEE=0.000345 双边，生产用 cost_model 买 0.00954%/卖 0.05954%。
   研究 +53.6%/年 是在仿真口径下；更低成本只会让生产结果不差于回测（fee_x2 敏感性已注册）。
2. **账本记账 = 数据开盘价**，非真实成交价；真实偏差由执行器对账（见 §4）。
3. **limit_risk 为启发式**，无涨跌停价真值；权威判定在执行器。
4. **--date 必须晚于数据最新日或等于数据内某日之后**：信号日取"数据内最近一个 < date 的交易日"，
   若 W1 未刷新就用旧数据出名单（meta.data_last_date 可查，执行器应核对 eval_date 是否为上一交易日）。
5. **未决项（交接 W3）**：真实成交回写接口未定（当前账本自认开盘价成交）；若日后需要以真实成交
   重建账本，可加 `--apply-fills` 入口按执行器成交回报修正 positions/cash。
6. 数据缺口：当前 results 数据止于 2026-09-17，等 W1 刷新至 2026-10-09 后，
   周一前需 `--replay` 回归一次再 `--bootstrap`。
