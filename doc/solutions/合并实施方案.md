## 0. 全局约定

### 0.1 代码映射（codec）规范——所有代码必须先读本节

三套代码格式共存，**转换只允许通过 `core/market_data/codec.py` 的四个函数**，禁止在业务代码里再写 `startswith(("5","6"))` 判断：

| 格式 | 样例 | 用途 |
|------|------|------|
| 内部纯 6 位 | `600481` | superTrader 全部内部逻辑、缓存文件名 |
| 内部多账户后缀 | `600481_A` / `600481_B` | superTrader 多账户持仓（goldminer 无此概念） |
| GM 格式 | `SHSE.600481` / `SZSE.002639` | 掘金 SDK 入参/出参 |

```python
# core/market_data/codec.py 必须实现的四个函数
def to_gm(code: str) -> str:        # "600481"→"SHSE.600481"；"600481_A"→"SHSE.600481"（后缀剥离，映射日志记 warning）
def to_internal(gm_code: str) -> str:  # "SHSE.600481"→"600481"
def market_of(code: str) -> str:    # "600481"→"SH"；规则：5/6/9 开头=SH，其余=SZ
def strip_account(code: str) -> str:  # "600481_A"→"600481"；无后缀原样返回
```

### 0.2 数据契约（DataFrame schema，任何 provider 必须产出同样形态）

| 方法 | 签名 | 返回列（顺序、dtype） | 单位/口径 |
|------|------|----------------------|-----------|
| 日线 | `daily(code: str, days: int = 800) -> pd.DataFrame` | `date(str YYYY-MM-DD), open(f64), high(f64), low(f64), close(f64), volume(f64)` | **前复权**；volume 单位=**手** |
| 分钟线 | `minute(code: str, date: str) -> pd.DataFrame` | `time(str "HH:MM"), open, high, low, close, volume, amount(f64)` | 当日 1 分钟；volume 单位=**手**；amount 单位=元 |
| 实时快照 | `snapshot(codes: list[str]) -> dict[str, dict]` | `{code: {price, open, high, low, volume, ts_date}}` | volume=手；`ts_date`=快照时间戳日期（YYYY-MM-DD），用于新鲜度判断（08-28 摩恩电气事故教训） |
| 指数日线 | `index_daily(index: str = "sh000001", days: int = 800) -> pd.DataFrame` | `date, close`（至少这两列） | 前复权 |

**单位裁决（最终口径，替代方案文档中的模糊表述）**：内部统一用 **手**。GM SDK 返回的 volume 单位是**股**，`gm_provider` 内统一 ÷100 收敛；腾讯侧本来就是手，不转换。**任何 provider 外的地方出现 ×100/÷100 都视为 bug。**

### 0.3 工程纪律

- 分支策略：直接在 main 上小步提交（用户单兵项目），但每阶段一个里程碑 commit，commit message 前缀 `merge-pN:`；
- 任何阶段验收闸不过 → 回退该阶段改动，不得带债进入下一阶段；
- 运行时产物（缓存/日志/状态）不入库；`analysis/t_io/`、`execution/t_io/` 这类目录错位产物出现即说明有模块写盘路径写错，必须修；
- 缓存格式不变式：`t_io/cache/daily_kline/*.json` 现有格式（`{date, saved_at, rows:[{date,open,close,high,low,volume}]}`）保持不变，provider 写缓存必须兼容旧文件。

**验收闸**：仓库内 grep 不到 token；token 获取机制在终端重启后可自动恢复（实测：重启终端后不重配置仍能拉数）。

## 附：实施方常见歧义点答疑（先写死，免得来回问）

1. **"数据源同源"是指 manual 链路也切 gm 吗？** 是。P1 完成后 manual/auto 都走 `core/market_data`，腾讯只是 provider 内的降级兜底。竞价虚拟匹配价是唯一例外（gm 无此数据，保留腾讯，已收敛进 provider）。
2. **量能单位到底用什么？** 手。gm provider 内部 ÷100。其它地方出现换算系数即打回。
3. **goldminer 的建仓闸链（池闸/槽位闸等）算"建仓逻辑"吗？** 不算。它是执行侧风控，归 execution/auto/ 独立边界。公共建仓判定 = position_builder + timing_gate。
4. **可以顺手重构/美化无关代码吗？** 不可以。最小改动原则贯穿全程。
5. **遇到方案文档与现有代码冲突？** 停下来，在审核记录表登记，等裁决。不许自行取舍。
