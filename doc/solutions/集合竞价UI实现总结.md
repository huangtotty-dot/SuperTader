## 1. 后端分析引擎（auction_analyzer.py）

### 功能模块

#### A. 持仓缺口分级
```python
# 基于 9:20 竞价快照计算缺口幅度
gap_pct = (price_9_20 - pre_close) / pre_close * 100

# 自动分级
"大幅高开" (+2% 以上) / "小幅高开" (+0.5%~+2%) / 
"平开" (±0.5%) / "小幅低开" (-0.5%~-2%) / "大幅低开" (-2% 以下)
```

#### B. 昨日走势联动分析
使用**联动规则表**（方案 §4.3）判断：
- 高危信号：大涨+高开 → 获利盘兑现 → 建议开盘先卖
- 机会信号：大跌+低开 → 恐慌释放 → 建议等企稳后低吸
- 中性信号：其他组合 → 按盘中信号执行

#### C. 竞价形态识别
基于 9:20/9:22 价格轨迹识别：
- 阶梯上升（价格逐步拉高）→ 多头主动
- 阶梯下降（价格逐步走低）→ 空头主导
- V形翘尾（最后冲高）→ 最后一分钟抢筹
- 倒V砸尾（最后下杀）→ 最后一分钟出货
- 一字横盘（无变化）→ 无方向

#### D. 做T建议生成
根据缺口等级和昨日联动，输出**具体可操作建议**：
- "开盘先卖，等回落接回（反T）"
- "等深跌后低吸（正T）"
- "持有等高抛，9:45不创新高则减仓"
- 等等...

### 4.2 修改 t_gui.py
新增 API 方法供前端调用：
```python
def get_auction_diagnosis(self, date=None):
    """加载竞价诊断报告（auction_diagnosis_{date}.json）"""
    date = date or get_today_str()
    fp = PREOPEN_DIR / f"auction_diagnosis_{date}.json"
    if not fp.exists():
        return None
    try:
        return json.loads(fp.read_text(encoding="utf-8"))
    except Exception:
        return None
```
