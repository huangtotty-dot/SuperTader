# 30分钟线趋势判定方案

> 版本：v1.0 · 2026-10-04
> 定位：在既有「5min + 15min 共振买点」框架之上，新增 30min 维度的**趋势判定层（regime 层）**，服务两个用途：
> ① 做 T 信号过滤——单边下跌日禁正 T、趋势中不逆势；
> ② 仓位调节——趋势态放仓、震荡态收仓、异常态冻结。
> 本方案全部规则可程序化，可直接交工程师施工。

---

## 1. 结论先行：三层判定架构

**推荐架构：regime 闸门 → 方向判定 → 确认/退出，三层串联、逐层否决。**

```
第一层 Regime 闸门（该不该谈趋势）
    ADX(14) > 22 且 ADX 上行  →  通过，进入第二层
    ADX < 20 或波动率异常     →  直接判「震荡」，后面两层不执行

第二层 方向判定（趋势朝哪边）
    EMA20 vs EMA60 + 收盘价位置  →  输出 raw_direction ∈ {多, 空}

第三层 确认 / 退出（什么时候信、什么时候不信）
    状态机滞回 + 2 根 K 线确认 + Supertrend(10,2) 退出线
    →  输出最终状态 state ∈ {BULL, BEAR, RANGE}
```

**为什么这样分层，而不是单一指标或平铺投票：**

1. **职责正交**。ADX 是四类指标中唯一标准化的「趋势强度」度量，它回答「有没有趋势」但**不提供方向**；均线回答「方向朝哪」但在震荡市假信号密集；Supertrend 回答「何时离场」且只翻转不反复。三者各管一件事，分层串联时任何一层失效都不会污染其他层的结论。DMI(14) 的历史统计显示趋势市胜率约 78%、震荡市仅 42%——**先过滤掉震荡市，方向指标的期望值才成立**，这是闸门必须放在第一层的根本原因。
2. **ADX 是「过滤器不是触发器」**。用 ADX 直接做买卖点会滞后且频繁打脸；用它做总开关，则其滞后性无害（趋势初期少赚 1-2 根 bar，换来震荡市全程空仓）。
3. **确认层独立于判定层**。方向翻转是最高危操作（反手即逆势），必须付出「2 根 K 线 + 滞回阈值」的时间成本；而退出（趋势衰竭）可以快——Supertrend 破位即执行。判定慢、退出快，不对称设计匹配做 T 场景的风险结构。
4. **工程上可裁剪**。三层各自输出中间变量（`gate_ok`、`raw_direction`、`state`），做 T 过滤只读 `state`，仓位调节可读 `gate_ok + adx 值` 做更细粒度，互不耦合。

交叉验证（不作主链路，作旁路校验）：回归斜率 × R² 与 Kaufman ER 作为「第二意见」，与主组合结论冲突时降置信度、不直接否决（见 §3.4）。

## 2. 状态机完整定义

### 2.1 状态集合

| 状态 | 含义 | 做 T 含义 |
|---|---|---|
| `BULL` | 30min 上升趋势确认 | 允许正 T，禁反 T |
| `BEAR` | 30min 下降趋势确认 | 禁正 T，仅反 T 或停手 |
| `RANGE` | 震荡 / 无趋势 / 未确认 | 停手或仅区间内高抛低吸（默认停手） |

初始状态：`RANGE`。

### 2.2 中间变量（每根已收盘 30min bar 计算）

| 变量 | 定义 | 来源 |
|---|---|---|
| `adx`, `plus_di`, `minus_di` | ADX(14) Wilder 平滑 | 复用 `_ir_adx` |
| `adx_rising` | `adx[t] > adx[t-1]` 且 `adx[t] > adx[t-2]`（2 根上行，抗单根噪声） | 派生 |
| `gate_ok` | `adx > ADX_ON(22)` 且 `adx_rising` | 第一层输出 |
| `bull_dir` | `EMA20 > EMA60` 且 `close > EMA20` | 第二层 |
| `bear_dir` | `EMA20 < EMA60` 且 `close < EMA20` | 第二层 |
| `st_long_ok` | `close > Supertrend(10,2)` | 第三层退出线 |
| `vol_freeze` | `ATR(14) / mean(ATR(14), 20) > 2.0` | 波动率突变保护 |
| `vol_thin` | `ATR(14) / mean(ATR(14), 20) < 0.7` | 缩量保护 |
| `confirm_cnt` | 当前候选方向的连续确认根数（0/1/2） | 状态机内部 |

### 2.3 滞回阈值（防抖动核心）

| 参数 | 进入阈值 | 退出阈值 | 说明 |
|---|---|---|---|
| ADX 闸门 | `ADX_ON = 22` | `ADX_OFF = 18` | 进入严于退出，18~22 之间**保持原状态不变** |
| EMA 发散度 | 翻转要求 `(EMA20-EMA60)/EMA60` 变号且绝对值 > 0.1% | 回到 ±0.05% 以内视为粘合 | 粘合带内不触发翻转计数 |
| 确认根数 | 2 根连续同向已收盘 bar | 1 根反向破位即退出 | 进慢出快 |

滞回的本质：**状态翻转的代价必须高于状态维持**。ADX 18~22 的灰色地带、EMA 粘合带、2 根确认，三者叠加后，震荡市中状态机大部分时间停在 `RANGE`，这正是我们想要的行为。

### 2.4 状态转移表

| 当前状态 | 触发条件（全部满足） | 下一状态 | 备注 |
|---|---|---|---|
| RANGE | `gate_ok` 且 `bull_dir` 连续 2 根 | BULL | 确认根数从首根 `bull_dir` 起计 |
| RANGE | `gate_ok` 且 `bear_dir` 连续 2 根 | BEAR | 同上 |
| BULL | `gate_ok` 消失（`adx < ADX_OFF` 或 adx 拐头） | RANGE | **降为震荡而非直接翻空** |
| BULL | `bear_dir` 连续 2 根 且 `st_long_ok = False` | BEAR | 直接翻转需双确认 + Supertrend 破位 |
| BULL | `close < Supertrend` 单根成立 | RANGE（挂起） | 退出线破位先退回震荡，等重新定性 |
| BEAR | 对称于 BULL | — | 镜像规则 |
| 任意 | `vol_freeze = True` | 状态冻结 24 根 bar | 冻结期内不翻转，仅可退出到 RANGE |
| 任意 | 涨跌停 bar | 该根跳过，不计入确认根数 | 见 §4.3 |

**关键设计说明：**

- **趋势消失 → RANGE，而非直接反向**。`gate_ok` 消失只说明「趋势强度不够了」，不说明「反方向趋势成立」。BULL→BEAR 必须独立走一遍完整确认流程（`bear_dir` × 2 根 + Supertrend 破位）。这避免了 ADX 回落造成的多空间高频乒乓。
- **Supertrend 破位是快速出口**。它不等 2 根确认——止损性质的动作不允许等待。破位后回 RANGE 挂起，而不是直接判反。
- **波动率冻结期内只允许「退」不允许「进/翻」**。ATR 突增 2 倍以上通常对应消息面冲击，此时任何新方向判定都不可靠，但已有持仓的风险敞口必须允许收敛。

### 2.5 伪代码

```python
# 每根已收盘 30min bar 收盘后执行一次
def step(bar, ctx, sm):
    if bar.is_limit_locked:                      # 涨跌停 bar
        return sm                                # 跳过，不累计确认根数
    if bar.is_first_of_day or bar.is_last_of_day:
        bar.weight = 0.5                         # 降权：见 §4.1，仅参与指标计算，不参与确认计数

    update_indicators(ctx, bar)                  # ADX / EMA20,60 / Supertrend / ATR 系数

    if ctx.vol_freeze:
        sm.freeze_remaining -= 1
        if exit_line_broken(ctx, sm.state):      # 冻结期仍允许退出
            sm.state = RANGE
        return sm

    # 第一层：闸门
    gate_ok = ctx.adx > ADX_ON and ctx.adx_rising
    gate_off = ctx.adx < ADX_OFF or adx_turning_down(ctx)

    # 第二层：原始方向
    raw = BULL if ctx.bull_dir else BEAR if ctx.bear_dir else None

    # 第三层：确认计数与转移
    if sm.state == RANGE:
        if gate_ok and raw is not None:
            sm.confirm_cnt = sm.confirm_cnt + 1 if raw == sm.candidate else 1
            sm.candidate = raw
            if sm.confirm_cnt >= 2 and bar.weight == 1.0:
                sm.state = raw                   # 确认根必须是非降权 bar
                sm.confirm_cnt = 0
        else:
            sm.confirm_cnt = 0

    elif sm.state in (BULL, BEAR):
        if exit_line_broken(ctx, sm.state):      # Supertrend 反向破位
            sm.state = RANGE                     # 快速退出，挂起
            sm.confirm_cnt = 0
        elif gate_off:
            sm.state = RANGE                     # 闸门关闭 → 降震荡
            sm.confirm_cnt = 0
        elif raw == opposite(sm.state):
            sm.confirm_cnt += 1
            if sm.confirm_cnt >= 2:
                sm.state = opposite(sm.state)    # 完整双确认才翻转
                sm.confirm_cnt = 0
        else:
            sm.confirm_cnt = 0
    return sm
```

## 3. 指标规格（计算口径 / 参数 / 阈值 / 失效情形）

### 3.1 第一层：ADX(14) + DMI —— regime 闸门

- **计算口径**：Wilder 平滑。TR = max(high-low, |high-prev_close|, |low-prev_close|)；+DM/-DM 方向移动；DI = 100 × WilderMA(DM,14) / WilderMA(TR,14)；DX = 100×|+DI−-DI|/(+DI+-DI)；ADX = WilderMA(DX,14)。**直接复用 `analysis/index_regime.py::_ir_adx(df, 14)`**，个股 OHLC 与指数通用。
- **30min 参数**：n=14（约覆盖 7 个交易日的 30min bar，A 股个股低波动特性下不建议再降；降期数提高灵敏度的代价是震荡市误开闸，与本层「过滤器」职责冲突）。
- **阈值**：`ADX_ON=22` 开闸、`ADX_OFF=18` 关闸；`adx_rising` 要求连续 2 根上行。衰竭预警（不直接改状态，供仓位层使用）：ADX > 40 拐头向下且 ±DI 间距收窄。
- **失效情形**：①涨跌停 bar 的 TR 失真，跳过不计；②除权缺口会造成 DI 假交叉——必须前复权；③长期横盘后首根放量长阳，ADX 滞后 2-3 根才开闸——这是**有意为之的成本**，不优化。

### 3.2 第二层：EMA20 / EMA60 —— 方向判定（推荐，二选一论证）

**采用 EMA20/EMA60，弃用 MA8/MA21。论证：**

| 维度 | EMA20/60（30min） | MA8/MA21（30min，≈1日/2.5日） |
|---|---|---|
| 覆盖时长 | 约 2.5 日 / 7.5 日，与「今日多空基调」+「本周趋势」匹配 | 仅 1 日 / 2.5 日，偏短，翻转频繁（金叉死叉约 2-3 日一次看似适中，但对状态机而言抖动偏多） |
| 跳空抗性 | EMA 指数加权，对首根跳空降敏；SMA 等权，跳空污染持续 20 根 | SMA 口径，A 股跳空频发下劣势明显 |
| 与日线对齐 | EMA60(30min) ≈ 7.5 日，介于日线 MA5 与 MA10 之间，与日线 trend_bg 粒度衔接自然 | MA21(30min) ≈ 2.5 日，与日线层重叠过高，两层的区分度不足 |
| 状态机适配 | 配合发散度粘合带（±0.05%~0.1%）滞回，翻转频率可控 | 需额外加斜率过滤才能压住抖动，复杂度反而更高 |

- **计算口径**：EMA 标准递推，`EMA[t] = α·close[t] + (1-α)·EMA[t-1]`，α = 2/(n+1)；种子用前 n 根 SMA。
- **阈值**：`bull_dir = EMA20>EMA60 且 close>EMA20`；发散度 `(EMA20-EMA60)/EMA60` 绝对值 < 0.05% 判粘合（不计入任何方向确认）；翻转要求发散度变号且 > 0.1%。
- **失效情形**：①箱体震荡中 EMA20/60 反复缠绕——由第一层 ADX 闸门兜底，粘合带兜底；②V 型反转初期滞后 1-2 根——接受，做 T 场景不抢反转；③停牌复牌后 EMA 序列失真——复牌后前 3 根 bar 方向结果置无效。

### 3.3 第三层：Supertrend(10, 2) —— 退出/止损线

- **计算口径**：ATR(10)（复用 `_ir_atr_wilder`）；基本上轨 = (high+low)/2 + 2×ATR，下轨 = (high+low)/2 − 2×ATR；带方向递推（上轨只降不升、下轨只升不降，破位翻转）。
- **30min 参数**：(10, 2)。保守标准；不建议用激进 (10, 1.5)——做 T 的活动仓止损由 5min/15min 层负责，本层是「趋势还在不在」的裁判，宜钝不宜锐。
- **用法**：`state=BULL` 时 `close < Supertrend` 即退回 RANGE；不作为入场触发器。
- **失效情形**：①连续一字涨跌停时 ATR 压缩，Supertrend 贴脸——涨跌停 bar 跳过后自然缓解；②宽幅震荡市翻转频繁——此时 ADX 闸门已关闭，本层不会被触达。

### 3.4 旁路交叉验证（不参与状态机，输出置信度标签）

| 指标 | 口径与参数 | 判读 | 用途 |
|---|---|---|---|
| 回归斜率 × R² | 最近 N=20 根 30min 收盘价 OLS，归一化斜率 = slope/mean×100（复用 `_ir_linreg_slope_r2`） | R²>0.6 且斜率>0 → 趋势质量高；R²<0.4 → 即便 ADX 开闸也存疑 | 主状态为 BULL/BEAR 但 R² 不达标 → 输出 `confidence=low`，仓位映射降一档 |
| Kaufman ER | ER = \|close−close[n]\| / Σ\|Δclose\|，n=10 | ER>0.35 趋势市，<0.2 噪音市 | 与 ADX 闸门交叉：ADX 开闸但 ER<0.2 → 疑似单根脉冲，确认根数要求从 2 提升到 3 |
| Hurst（可选，离线） | 窗口≥100 根 | H>0.55 趋势持续 | 仅用于回测期参数校准，不进实时链路 |

## 4. A 股适配专章

### 4.1 每天仅 8 根 30min K 线的处理

单根异常污染权重 12.5%，必须结构性降权：

| Bar | 时段 | 处理 |
|---|---|---|
| 第 1 根 | 9:30–10:00 | 吃隔夜 + 竞价跳空，全天振幅最大。**参与指标计算（EMA/ATR 需要连续性），但不计入状态确认根数**；其跳空幅度单独记入缺口观察窗（§4.4） |
| 第 5 根 | 13:00–13:30 | 午休割裂后首根，可信度低。计入指标，确认计数权重减半（连续 2 根中若含此根，要求第 3 根补确认） |
| 第 8 根 | 14:30–15:00 | 尾盘成交占全天 20–25%，急拉急杀多为做价，是最常见假信号源。**不计入确认根数；本根产生的翻转候选顺延到次日第 2 根起重新计数** |

通用铁律：**只用已收盘 K 线判定，禁用未完成 bar**；信号触发后要求下一根收盘确认（状态机的 2 根确认已含此约束）。

### 4.2 时间纪律：14:30 只确认不开仓

- 14:30 之后：状态机照常运行（状态翻转照常记录，供次日盘前读取），但**做 T 层禁止新开仓**；正 T 买入必须在 14:30 前完成（T+1 下当日无法卖出的买入等同于隔夜仓，性质变了）。
- 尾盘翻转信号（第 8 根）延迟到次日验证，与 §4.1 一致。

### 4.3 涨跌停 bar 跳过

涨跌停 bar 不代表真实供需：该根**不参与 ADX/ATR 的增量更新（用前一根值顺延），不计入确认根数，不触发 Supertrend 翻转**。连续一字板期间状态冻结，开板后第 2 根恢复正常判定。

### 4.4 缺口 3 日观察窗

- 跳空缺口（今开 vs 昨收，|gap| > 0.5%）进入观察窗：**24 根 30min bar（3 个交易日）内不回补**才确认突破有效，期间缺口方向可作为 `confirm_cnt +1` 的加速项（即缺口方向确认只需再补 1 根）。
- 缺口 + 放量（vol ≥ 1.5×MA20vol）+ 与 EMA20/60 重合 = 强信号，可直接计入 1 根确认。
- 24 根内快速回补 = 假突破，**状态回滚**：若状态机曾因该缺口方向翻转，退回翻转前状态并清零确认计数。

### 4.5 前复权要求

全部 30min 与日线计算必须使用**前复权**数据。除权缺口会触发 EMA 假死叉、Supertrend 假破位、`close<EMA20` 假空头。数据链路 `fetch_freq_kline` 已走 tushare 前复权口径，集成时校验一次即可，不得混用不复权源。

### 4.6 「正 T 失败当日必须卖出」与趋势的联动

- 正 T 买入后若 30min 状态翻为 RANGE 或 BEAR，**当日尾盘前必须卖出活动仓，绝不转加仓、绝不转底仓**——状态翻转意味着买入依据已消失，持仓理由不成立。
- 联动规则：状态机 BULL→RANGE/BEAR 的转移事件要作为**硬告警**推送（飞书），而不只是内部变量。
- 反过来，BEAR 状态下的反 T 卖出，若尾盘状态翻回 BULL，允许次日开盘回补，但当日不追回（避免尾盘孤量诱多）。

## 5. 做 T 映射表：30min 状态 × 日线状态

日线状态取自 `src/data_fetcher.py::_build_daily_context_from_df` 的 `trend_bg` 七态（bull / uptrend / base / neutral / downtrend / weak_breakdown）。合并为三档：`日线多 = {bull, uptrend}`，`日线中 = {base, neutral}`，`日线空 = {downtrend, weak_breakdown}`。

| 30min \ 日线 | 日线多 | 日线中 | 日线空 |
|---|---|---|---|
| **BULL** | ✅ 正 T（缩量回踩 EMA20 低吸），禁反 T 防卖飞；仓位上限 100% | ✅ 正 T，仓位上限 70%；反 T 仅在冲高急拉时允许减半活动仓 | ⚠️ 原则上停手；若 R²>0.6 且 ER>0.35 可小仓正 T（≤30%），当日必须了结 |
| **RANGE** | 轻仓正 T（≤50%），只做回踩不做追涨 | ⛔ 停手为主；ATR 低于 20 日均值（vol_thin）坚决停手 | ⛔ 停手 |
| **BEAR** | ⚠️ 禁正 T；允许反 T（冲高卖出尾盘回补）；底仓不动 | ⛔ 禁正 T；反 T 允许；活动仓上限 30% | ⛔ 全面停手，只观察；正 T 绝对禁止（单边下跌日核心规则） |

附加规则：

- **均线粘合 + vol_thin（ATR 系数 < 0.7）**：无论组合如何，停止一切做 T 操作——缩量阴跌/横盘中做 T 是负期望。
- **尾盘急拉孤量**（第 8 根放量长阳但无第 2 根确认）：状态不翻转，次日低开概率高，禁止据此隔夜加仓。
- 映射表的输出供 `t_trader` 信号过滤层调用：每个 5min/15min 共振买点触发时，先查 `(state_30min, trend_bg_daily)` 对应的操作许可，禁则丢弃信号并记录。

- **同一决策时点**：方向变量只在 30min bar 收盘时刷新；`get_trade_permission` 内部按「最新已收盘 30min bar 时间戳 + 最新交易日日线」对齐，盘中 5min/15min 高频调用走缓存，绝不使用未完成 bar（防未来函数）。

## 7. 回测校准清单

以下参数**不得直接上线**，必须用 A 股个股 30min 历史数据（建议近 2 年、覆盖 2024 熊市 + 2025 震荡 + 2026 趋势三种 regime，样本 ≥ 50 只不同波动率标的）验证：

| # | 参数 | 默认值 | 验证方法 | 通过标准 |
|---|---|---|---|---|
| 1 | ADX_ON / ADX_OFF | 22 / 18 | 网格扫描 {20,22,25}×{16,18,20}，统计各组合下「趋势态占比」与「趋势态内 5min 正 T 信号胜率」 | 趋势态占比 15%~40%（过高说明闸门形同虚设，过低说明漏趋势）；胜率显著高于全样本基线 +5pct |
| 2 | 确认根数 | 2 | 对比 1/2/3 根确认下的翻转次数与翻转后 5 根收益 | 2 根确认的「翻转后方向正确率」≥ 60%，且翻转次数较 1 根下降 ≥ 40% |
| 3 | EMA 发散度粘合带 | 0.05% / 0.1% | 统计粘合带宽度与 EMA 假交叉次数关系 | 粘合带内日均翻转 ≤ 0.3 次 |
| 4 | Supertrend 乘数 | 2.0 | 对比 1.5/2.0/2.5 的「破位后 10 根内趋势确实终结」比例 | 乘数 2.0 的破位有效率 ≥ 65%；若 1.5 显著更优则下调，但需同时满足破位频率不翻倍 |
| 5 | 波动率冻结阈值 | 2.0 / 24 根 | 事件研究：ATR 系数 > 2.0 后 24 根内的信号质量 | 冻结期跳过信号的「事后看应跳过」比例 ≥ 70% |
| 6 | 回归 R² 阈值 | 0.6（N=20） | R² 分箱 vs 趋势延续概率 | R²>0.6 组的趋势 5 根延续率 ≥ 70% |
| 7 | 缺口观察窗 | 24 根 / 0.5% | 样本内全部缺口事件的回补时间分布 | 24 根窗口能覆盖 ≥ 80% 的「最终回补」事件 |
| 8 | 首根/尾盘降权规则 | weight=0.5 | A/B：剔除首根与第 8 根的确认资格后，翻转假信号率变化 | 假翻转率下降 ≥ 25%，且真翻转延迟 ≤ 1 根 |

**回测纪律：**

- 全程前复权、只用已收盘 bar、信号与成交之间隔 1 根（防前视）。
- 分 regime 报告（趋势年 / 震荡年分开看），不得只看混合样本——震荡年表现才是闸门价值的试金石。
- 任一参数调整后全清单重跑，防止过拟合单一年份。
- 上线前 paper trading 20 个交易日，对比状态机判定与人工判读的一致率 ≥ 80% 方可接入 `t_trader` 实盘过滤。
