## 🎯 清理原则

### 什么被删除？

只有满足以下条件的代码才被删除：

1. **集合竞价飞书推送专用** — 不被其他功能使用
2. **已完全禁用** — 相应推送函数返回 False
3. **无外部引用** — 没有第三方代码调用
4. **有明确替代方案** — UI 面板已覆盖该功能

### 什么被保留？

1. **核心数据结构** — `PREOPEN_CONTEXT`, `SESSION_CONTEXT` 等
2. **禁用函数的空实现** — 用于向后兼容
3. **跨功能的辅助函数** — `_feishu_card_header()` 等（支撑/压力位推送需要）
4. **系统基础设施** — 扫描、日志、缓存相关
