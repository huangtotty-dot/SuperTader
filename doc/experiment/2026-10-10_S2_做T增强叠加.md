## 1. 实验口径（预注册可对账）

- **α 基准**：S1 终选配置 N=4 / M=8 / min_hold=1 / TP=A，score_eq 等权，卫生宇宙（<2元 + 60日回撤>60% 剔除），回款当日可用，每边费 0.0345%。仿真逻辑逐行复刻 `s1_sim.s1_run_sim`（未改 s1_* 文件），窗口裁至分钟覆盖段 **2025-03-31 ~ 2026-09-17（360 交易日）**。
- **β 叠加层**：规则核 `core/open_gap_reversal.py` **原版判定**——`mkt_gap = 当日 981 缓存池 gap 中位数`（task 指定口径，**非**核内冻结的 L20 代理名单）、`mkt_gap<0` 且 `rel = gap_i − mkt_gap ≤ −1%`；09:30 bar open 买 → **10:00 bar close 卖**（预注册文档 §执行口径：与整点开盘价差 −0.0008pp，当等价）。
- **底仓约束**：仅 α 账户 open 成交后持仓、且 `entry_d < d`（T+1：当日新买槽位不开腿）；每票每日 ≤1 腿；腿资金 = 槽市值(open) × **25%**（参数化 `LEG_FRAC`）；腿费 stock 双边 0.069%；**腿与底仓分账**，β 不回灌 α 决策。
- **价格一致性**：pivots 日线为前复权、30min 缓存为未复权（2025-04-01 抽查差 8.8%，除权所致）。gap 与 prev_close 一律取**同一 30min 序列**（自洽），腿收益为日内比值，不受复权影响；α 仍用前复权日线，两账不混价。
- **切半**：2025-06-11（H1 = 04-01~06-10 共 46 天，H2 = 06-11~2026-09-17 共 313 天）。半窗指标由全窗单一路径**切片**计算（S1 分半为重新起跑，口径差异特此标注；影响可忽略）。

## 4. 关键诊断：规则没死，是「持仓子集」被逆向选择

| 检验 | 结果 |
|---|---|
| 981 全池面板复测（同窗同规则） | 22,225 腿，**+64.0bp/腿，t=31.3，胜率 56.6%** |
| 面板分半 | H1 +19.5bp（t=2.85）→ H2 **+68.4bp（t=32.0）**：规则在本窗口**没有衰减，反而走强**（2025-06 起月均 +7.9~+123bp 全正） |
| **同 16 个触发日**面板腿均值 | **+39.4bp** vs 持仓腿 −71.3bp ⇒ 持仓子集逆向选择约 **−110bp/腿** |
| 持仓腿 t 值 | −1.04（n=17，未达 5% 显著，但方向与经济量级一致） |

机制解读：α 账户持有的是 score 选出的**强动量票**；大盘低开日它们相对再跌 ≥1% 时，多为拥挤盘瓦解/动量崩裂的开端（2025-04-07 大盘 gap −6.8% 当日两腿合计 −910bp；2026-04-21、2026-07-13 各 −340/−457bp），低开反转的均值回复前提在强势股子集上系统性失效。门控分布也印证：17 腿中 trend30 状态 **RANGE 14 / BEAR 3 / BULL 0**。

**臂B（BULL 才开腿）= 0 交易**：触发条件（大盘 gap<0 + 个股 rel≤−1%）与个股 BULL 状态在持仓票上几乎互斥，trend30 门控对本策略是**总开关**而非质量过滤器，该臂不可评估（不是"过滤后变好/变差"，而是"永远不开腿"）。

## 5. 工程可行性附注

- **现金不足**：α 账户近满仓运行（open 后现金均值仅 3.3 万），17 腿中仅 3 腿现金可覆盖腿资金（中位覆盖比 0.08）。真实部署需预留专用做T现金袖珍仓（4 槽 × 25% ≈ 1 个槽位市值，约组合 20-25%），或在不开腿时提高仓位——本实验 β 按独立融资账核算（owner 分账要求），未回灌 α。
- 腿资金口径 25% 已参数化（`LEG_FRAC`），改值重跑 `s2_ogr_overlay.py` 单步 <10s。

## 6. 结论与后续建议

1. **叠加层当前为负边际**：在 S1 终选账户的持仓子集上，OGR 做T腿 −86bp/腿（n=17），β ann −0.8%，两臂均不提供正增强；trend30 门控臂 0 交易。**不建议以当前形态上线。**
2. **但规则本身在本窗口 Alive（面板 +64bp t=31）**：负边际来自"动量持仓 × 反转规则"的结构冲突，而非规则衰减——这对 S2③ 衰减归因是重要旁证：日级反转选股 alpha 的 2025-06 后衰减是**选股层**现象，不是反转效应整体的消亡。
3. 若继续做T增强，方向是**解耦标的选择**：腿不打在 α 持仓上，而打在独立反转候选池（981 面板 rel 最深 N 只），以独立现金袖珍仓承载——这样 α/β 仍天然分账，且 β 直接继承面板 +64bp 的统计基础（需另测容量：腿资金 vs 竞价成交额参与率约束，核内 `size_cap_by_auction` 已备）。
4. 覆盖率若要修复，需把 30min 缓存从 981 池扩到 α 账户实际轮动的全宇宙（606+ 只动态集合），否则任何"持仓叠加型"做T实验都会继续受 22% 覆盖的功效限制。
