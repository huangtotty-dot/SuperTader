## 四、结论

1. **出场截断假说成立但不足以翻案**：B1 的 +0.5% 止盈一致压低收益 0.02~0.24pp/笔；拆开之后，A1–A6 依然**低于随机基线 0.34~0.89pp**。**入场侧没有 skill**，round-1 结论加强。
2. **A7 正T 是 beta 不是 alpha**：beta 调整后选股超额 +0.19pp/笔 < 成本 0.136%。这是**第三条独立证据**指向同一结论（前两条：`5d8b66cb` 漂移≈成本、`8a590ba5` 缺口条件化不成立）。
3. **本轮最强线索是隔夜侧而非日内侧**：尾盘急拉 → 次日低开 **−0.67% ~ −1.66%**（低开率 62~75%），幅度**远超成本**。这是 B7，本轮的标定已产出阈值但**未实现**。
4. 倒T 侧再次为负（−0.39%），与标定先验、与 `927820d0` 的 0/8 一致 —— **不要做反T**。

## 五、诚实声明（口径偏差与未闭合项）

- **市场过滤的消融是 Wave 0 标定之后的动作**，属事后口径变更。已披露：Wave 0 表④（闸门归因 + beta 基准）是本轮进行中追加的诊断，不在最初预注册里。

- **A7 从未过密度闸门**，所有 A7 读数按预注册应标「样本不足」，本文列出仅为与消融对照。

## 六、追加：九转出场对照（2026-09-15 晚）

## 七、追加：出场时点右移（隔夜出场）

**动机**：至今**所有**出场规则都受同一个约束——14:55 必须平仓。而本轮标定里最强的效应（尾盘急拉→次日低开 −0.67~−1.66%）恰在 14:55 **之后**。故测 `B12_next_open`：持到**次日开盘**再平。

**设计**：9 入场 × {`B0_hold` 当日 14:55 平, `B12_next_open` 次日开盘平}。两格逐腿**入场价与成本完全相同**，故净均之差**精确等于隔夜那段的价格变动**。
代码 `run_experiment.py`（`B12_next_open` + `paired_b0_vs_b12` 配对检验）；结果 `results_2026-09-15_overnight.json`。

**9 格仅 2 格显著（p=0.017 / 0.011），且符号相反**；7 格与零不可区分。α=0.05 下 9 次检验的随机假阳性期望约 0.45 个 —— 出现 2 个只略高于随机，**且未做多重比较校正、方向互相矛盾** ⇒ **不能当作效应**。
> ⚠️ 本节初版据**点估计**称"隔夜那段有量级"，配对检验后**该说法由本人撤回**。

**符号先验亦被证伪**：预测"隔夜为负 ⇒ 空头持过夜受益"，实测 `A7_short_only` 隔夜 −0.075（空头**也亏**）。指数层 8 年的"隔夜为负"（t=−4.49）在这些入场日的**个股**上套不过来。

### 结果二：隔夜是 carry 不是 skill（这一条是稳的）

随机基线随入场**同步移动**：

| | 入场 B0→B12 | 随机基线 B0→B12 | Δvs随机的变化 |
|---|---|---|---|
| A4_dualthrust | +0.015 → +0.128（+0.113） | +0.728 → +0.835（+0.108） | −0.712 → −0.707（+0.005） |
| A7_long_only | −0.183 → −0.423（−0.240） | −0.339 → −0.580（−0.242） | +0.155 → +0.157（+0.002） |
| A1_noise | −0.082 → −0.034（+0.048） | +0.490 → +0.507（+0.017） | −0.572 → −0.541（+0.031） |

**9 格中 8 格的 Δvs随机 几乎不动**（最大变化 0.031pp）⇒ 右移出场改变的是**任何仓位都能拿到的收益**，不是入场相对于随机的超额。**它不回答"做T有没有 alpha"，只把账户暴露到隔夜这个风险因子上。**

`A4_dualthrust|B12_next_open` = **+0.128%** 是全项目最高的绝对值，但随机基线 +0.835% → **仍差 0.71pp**，且其中 ~93% 是 carry。

### 出场侧总结论

三种方向全部试过，**没有一种出场能改变可交易性**：

| 方向 | 结果 |
|---|---|
| 更早出场（+0.5%TP / 九转 / VWAP目标 / ATR / 时间 / 保本 / 移动） | 全部**劣于少动** |
| 同日出场的上限 | = 持到收盘（`B0_hold`） |
| 更晚出场（隔夜） | 抬绝对收益、**不抬超额**，且隔夜成分本身不显著 |

**「主动出场只会减分」是跨 9 个入场、3 类出场的一致结论。出场不是瓶颈。**
