# 预注册：开盘低开反转规则的样本外检验（2026-09-22 冻结）

> **本文件在任何样本外数据被拉取/查看之前写定。** 目的是消掉
> `doc/experiment/2026-09-22_日内做T成本重校与功效诊断.md` §4.5 那条规则的
> **研究者自由度**：该规则的阈值与条件都是在看到全样本分层表之后才定的。
> 因此**不得**在看完结果后修改本文件的任何一项。

## 1. 被检验的规则（原样冻结，不得改动）

对每个交易日 T、每只票 i：

```
mkt_gap(T)  = median_i( gap_i(T) )          # 当日全样本 gap 的中位数
gap_i(T)    = open_auc_i(T) / close_1500_i(T-1) − 1
rel_i(T)    = gap_i(T) − mkt_gap(T)
```

**开仓条件**：`mkt_gap(T) < 0` **且** `rel_i(T) ≤ −0.01`

**执行**：`T 日 09:30 集合竞价价买入` → `T 日 10:00 卖出`
- `open_auc` = 30min 序列中 `09:30` 那根 bar 的 `open`（= 集合竞价价，2026-09-22 实测确认为竞价）
- `10:00 价` = `10:00` 那根 bar 的 `close`（= 09:30–10:00 区间末价；Stage9 实测
  与 10:00 整点开盘价差 −0.0008pp，可当等价）

**成本**：`core/cost_model.py` 的 `stock`（往返 0.06908%，含印花税 0.05%）。
**不设其他过滤**（不加流动性、不加涨跌停、不加振幅、不加 regime）。

## 2. 数据

- 源：tushare `stk_mins`，`freq="30min"`，HTTP 接口（`t_io/validation/t0_bull/ts_http.py`）
- 标的：现有面板的**同一批 981 只**（`t_io/cache/tushare_mins/*_30min_d540.json` 的文件名）
- 期间：**2019-01-01 ~ 2025-03-28**（即现有面板 2025-03-31 起点**之前**的全部时段）
- 落盘：`t_io/validation/t0_bull/ts_oos/<code>.parquet`，只存日级归约
  `[date, prev_close, op_auc, cl_1000, cl_1500, amt]`

**已知偏差（必须写进结论）**：这 981 只是**按 2026 年的状态**确定的，
用于 2019–2024 存在**生存者/选样偏差**。本检验因此回答的是
「**同一批票在更早年份上，该规则是否仍成立**」，**不是**「历史上全市场该规则是否成立」。

## 3. 判据（事前冻结）

主指标 = **费后净均收益/腿**，标准误按**日聚类** `se = sqrt(Σ_day(Σ_{i∈day} x_i)²)/N`。

| 判定 | 条件 |
|---|---|
| **通过** | 净均 ≥ **+0.20%/腿** 且 \|t\| ≥ **2** |
| **否决** | 净均 < **0** 或 \|t\| < **1** |
| **存疑** | 其余区间（0 ≤ 净均 < 0.20% 且 t ≥ 1） |

- 若样本外腿数 < 500 或覆盖交易日 < 100 ⇒ 直接判 **功效不足**，不套用上表。
- **不因结果不理想而重调阈值、换条件、加过滤或换期间。**
- 次要输出（**仅供描述，不参与判定**）：逐月为正的比例、分时段（2019–2021 / 2022–2025）、
  以及 §4.6 已测过的「流动性≥中位」变体（作为稳健性展示，不替代主判据）。

## 4. 预期（诚实前置）

- 主样本（2025-03-31 起）测得 +0.6404%/腿（t=4.61），18/18 月为正，OOS 段更强。
- 因此**通过**是基准预期。若**否决**，则说明 §4.5 是全样本内选择偏差的产物，
  该规则应废弃，且应反过来质疑本项目其它「单期显著」的结论。
- **存疑**同样是有信息量的结果（说明效应量级被高估）。

## 5. 复现

```
export TUSHARE_TOKEN=<token>            # 刻意不硬编码
python t_io/validation/t0_bull/e0_stage10_fetch_oos.py     # 拉数（可续跑）
python t_io/validation/t0_bull/e0_stage11_oos_test.py      # 按本文件判据出结论
```

# 结果（2026-09-22，执行后追加；以上内容未改动）

## 仪器校验（先于看结果）

用**同一套归约代码**从 d540 缓存重算样本内：`n=22225`、`+0.6404%`、`t=4.61`、`胜率 0.566`
—— 与 §4.5 参考值**逐位相同** ⇒ 样本内外可比，链路可信。

## 数据覆盖

`ts_oos/` 973/981 只（8 只该期间无数据），1,251,311 个股票·日，2019-01-02 ~ 2025-03-28，
重复行 0。

## 主结果

| | n | 交易日 | 费后净均% | t | 胜率 |
|---|---|---|---|---|---|
| 样本内（2025-03-31 起，参考） | 22,225 | 184 | +0.6404 | 4.61 | 0.566 |
| **样本外（2019-01 ~ 2025-03）** | **61,403** | **662** | **+0.5245** | **+8.07** | 0.565 |
| ├ 2019–2021 | 24,292 | 268 | +0.5740 | +5.16 | 0.573 |
| └ 2022–2025 | 37,111 | 394 | +0.4920 | +6.21 | 0.559 |
| 全期间合并（2019-01 ~ 2026-09） | 83,628 | 846 | +0.5553 | +9.20 | 0.565 |

## 判定

判据：通过需 `净均 ≥ +0.20%` 且 `|t| ≥ 2`。

**⇒ ✅ 通过**（+0.5245%，t=+8.07；腿数 61,403 ≫ 500，天数 662 ≫ 100）。

- **样本外/样本内 = 0.82** —— 只缩水 18%，不是归零。这是与项目此前所有结论
  （[[intraday-drift-finding]] 的「后半段衰减到 1/3」、[[holdings-reconcile-split]] 之外的
  单期显著结论）最本质的区别。
- 逐月 **63/75 个月为正（84.0%）**；最差月 −0.4708%（2024-04），最好月 +2.2934%（2020-02）。
- 两个时段各自显著且同向 ⇒ 不是某一轮行情的产物。

## 次要描述（不参与判定）

| 变量 | n | 费后净均% | t |
|---|---|---|---|
| 流动性 ≥ 当日中位 | 45,950 | +0.5459 | +9.55 |
| 流动性 < 中位 | 15,453 | +0.4608 | +4.02 |

⇒ 与样本内一致：**高流动性更好**，两个分层都为正 ⇒ 不是小票/流动性补偿伪迹。

## 执行折价后的数字（把 Stage9 实测的「竞价→09:31」代价 −18.6bp 直接扣上）

| | 费后净均%/腿 |
|---|---|
| 样本外 | +0.3385 |
| ├ 2019–2021 | +0.3880 |
| └ 2022–2025 | +0.3060 |

单票口径粗估年化（命中率 0.051 次/票/日 × 243 日，未复利）：
**+6.9%（0 滑点）/ +4.6%（扣执行折价）**。

## 结论

**规则通过事前冻结的样本外检验**，跨 6.2 年、662 个交易日、61,403 腿、t=8.07。
这是本项目第一个**通过真样本外**的日内做T规则。

**仍存在的限制（未因通过而消失）**

1. **生存者/选样偏差（预注册时已声明）**：973 只是**按 2026 年状态**确定的票，
   用于 2019–2024 有偏差。本检验回答的是「同一批票在更早年份是否仍成立」，
   **不是**「历史上全市场该规则是否成立」。
2. **容量已估（Stage12），但竞价成交比例仍未验证**：约束是**集合竞价量**（占全日中位仅 1.30%），
   p=10% 参与下单腿上限样本内中位 **122 万**、样本外外推约 40 万；10 万/笔可覆盖样本内
   **95.4%** / 样本外外推 **78~87%** 的命中腿，100 万/笔只剩 14~24%。
   −18.6bp 的执行折价是**均值**，实际撮合若落 p90 尾部会显著恶化；
   **无逐笔数据 ⇒ 未建模冲击成本，也无法验证竞价挂单的实际成交比例**。
3. **未做参数扫描**：10:00 出场由 30min 粒度决定，09:45/10:15 未测（这是**保持**预注册纪律，
   不是为了回避）。
4. 全样本 multiple-comparison 的背景风险仍在（本轮试过多个 gap 阈值/条件），
   但**本检验是唯一一次在未见数据上、且判据事前冻结的检验**。

# 第二份预注册：独立股票池 + 生存者偏差检验（2026-09-22 冻结）

> ⚠️ **本节同样在任何新数据被拉取/查看之前写定。** 目的：检验上面那个「通过」是否只是
> 两个伪迹的产物 —— ① **981 只这个池子本身是被特意选的**；② **生存者偏差**
> （973 只全是活到 2026 年的票，2019 年的检验因此偏乐观）。

## 1. 池子定义（冻结）

源：`t_io/validation/xsection/panel/universe.parquet`（5,674 只，**含 `delisted_date`**）。

合格条件：`listed_date ≤ 2025-03-28` 且 `delisted_date ≥ 2019-01-01` 且 **不在** 现有 981 只内
⇒ **4,462 只**，其中 **256 只（5.7%）已退市**（2019–2026 分布均匀）。

**样本：随机抽 N = 400 只，种子 = 20260922（`np.random.default_rng(20260922)`）** —— 冻结，
不得更换。退市股按其在窗口内实际存在的交易日参与（数据已探针确认可取）。

## 2. 规则与判据（与第一份**完全相同**，不改任何参数）

- 期间：2019-01-02 ~ 2025-03-28
- `mkt_gap` = **本 400 只样本内**的当日 gap 中位数（注意：比 981 只的中位噪声更大）
- 条件：`mkt_gap < 0` 且 `rel ≤ −1%`；09:30 竞价买 → 10:00 卖；成本 = `stock` 0.06908%
- 判定：**通过**需 `净均 ≥ +0.20%/腿` 且 `|t| ≥ 2`；**否决**为 `净均 < 0` 或 `|t| < 1`；
  腿数 < 500 或天数 < 100 ⇒ 功效不足

## 3. 附加输出（次要，不参与判定）

- 样本的**退市股占比**，以及规则在**退市股子集**上的表现（生存者偏差的正面检验）
- 用 981 面板的 `mkt_gap`（更干净的市场代理）复算一遍，作为 §2 的市场代理敏感性
- 分时段（2019–2021 / 2022–2025）

## 4. 预期（诚实前置）

- 若第一份「通过」是 981 选样或生存者的产物 ⇒ 本检验会**否决**或大幅缩水。
- 若规则是真效应 ⇒ 应在 400 只上给出同号的、量级相近的结果（小池更薄，噪声更大，
  故允许更大的置信区间，但**符号与量级必须守住**）。
- **本检验仍有残余偏差**：池子来自项目自建面板（虽含退市股，但不是严格的历史全市场），
  故它比第一份强、但**仍不是**「全市场无偏」的最终答案。

# 第二份结果（2026-09-22，执行后追加；以上未改动）

## 样本与取数

合格池 **4,462** 只（与预注册一致），冻结样本 400 只（seed=20260922），
**与主面板 981 只交集 = 0**；含 21 只退市股。实际取到 399/400（1 只无数据），
含 20/21 退市股。期间 2019-01-02 ~ 2025-03-28，509,159 个股票·日。

## §A 主检验

| | n | 交易日 | 费后净均% | t |
|---|---|---|---|---|
| 主面板 981 只（第一份参考） | 22,225 | 184 | +0.6404 | 4.61 |
| 主面板 981 只（同期参考） | 61,403 | 662 | +0.5245 | +8.07 |
| **独立 400 只池** | **16,232** | **429** | **+0.5275** | **+6.04** |
| ├ 2019–2021 | 6,273 | 163 | +0.7841 | +4.87 |
| └ 2022–2025 | 9,959 | 266 | +0.3659 | +3.67 |

**判定：✅ 通过。独立池/主面板 净均比 = 1.01** —— 与主面板同期几乎**逐位相同**。

## §B 生存者偏差的正面检验（本节最关键的输出）

| 子集 | n | 交易日 | 费后净均% | t |
|---|---|---|---|---|
| **退市股**（窗口内仍存续、2019–2026 间退市） | **945** | 368 | **+0.7447** | **+5.44** |
| 在市股 | 15,287 | 429 | +0.5141 | +5.91 |

**退市股的效应更强（+0.7447% vs +0.5141%）** ⇒ 生存者偏差的方向与担忧**相反**：
把死掉的票排除掉是**保守**的，不是乐观的。这是本轮对生存者担忧最直接的正面回应。

## §C 市场代理敏感性

改用主面板 981 只的 `mkt_gap`（更干净的市场状态，共同交易日 1,511 天）：
n=19,103、**+0.4471%/腿、t=+6.20** ⇒ 结论对市场代理的取法稳健。

## §D 结论

**规则通过独立股票池 + 生存者偏差的双重检验。** 两个伪迹假设（981 选样特殊、
生存者偏差）**均被否决**：独立池复现到 101% 的量级，退市股子集更强。

**仍存的残余限制**：池子源自项目自建面板（虽含退市股，但不是严格的历史全市场名单），
故本检验比第一份强，但**仍不是**「全市场无偏」的最终答案；
**竞价成交比例**与**冲击成本**依旧无法从 bar 数据验证。
