## 一、因子清单与实现口径（全部手写 pandas/numpy，不依赖 ta-lib）

| 因子 | 定义 | t 日收盘后可得 |
|---|---|---|
| adx14 | Wilder ADX(14)；TR/+DM/-DM 经 `ewm(alpha=1/14, adjust=False)` 平滑（与经典 Wilder 递推仅初始值约定不同，14 期后差异可忽略）；ADX 为 DX 的同参数平滑 | ✓ |
| bbw | 布林带宽 (上轨-下轨)/中轨，(20, 2)，std 用 ddof=0 | ✓ |
| bbw_pct120 | bbw 的 120 日滚动分位（`rolling(120).rank(pct=True)`），低 = 带宽收缩 | ✓ |
| ma_bull_layers | 链式多头层数 0-3：L1=close>MA5，L2=L1&&MA5>MA10，L3=L2&&MA10>MA20 | ✓ |
| ma_bull_cont | (close-MA20)/ATR14 | ✓ |
| range_days | ADX<20 的连续天数 | ✓ |
| trend_up_confirm | 事件型 0/1：ADX 上穿 25 且 +DI>-DI | ✓ |
| dist_high20 | close/rolling_max(high,20)-1 ∈ [-1,0]，越负越"低位" | ✓ |

无未来函数验证：全序列 vs 截断 250 根重算，重叠区间 8 因子 + 标签逐位一致（测试 4）。前复权复跑后 24 项测试再次全过。

## 二、regime 打标规则（写死在 `label_regimes`，优先级自上而下）

| 优先级 | 标签 | 规则 |
|---|---|---|
| 1 | 单边上涨 | adx14 > 25 且 +DI > -DI 且 ma_bull_layers ≥ 2 |
| 2 | 单边下跌 | adx14 > 25 且 -DI > +DI 且 close < MA20 |
| 3 | 震荡末期 | adx14 < 20 且 bbw_pct120 ≤ 0.20（带宽收缩至 120 日最低 20% 分位 + 趋势低位） |
| 4 | 震荡 | adx14 < 20（未收缩到极致） |
| 5 | 混沌 | 其余（ADX 20~25 过渡带、ADX>25 但方向/均线不自洽） |

历史不足 140 根（MA20 + BBW 分位窗口）的行 label=NaN，不参与统计（前复权面板下占 8.1%）。
单点 API：`regime_label(date, symbol)`；批量用 `build_factor_panel()`。

## 四、因子体检（ic_layer 真实实现，`17e4500d`）

预注册口径：buy_open 主口径 = open(t+2)/open(t+1)-1（T+1 开盘买、持有 h 日开盘卖），close 口径参考；MC = 日期内洗牌零假设，pass = 真实 IC > null 95% 分位。
**主口径为最近 3 年窗口（2023-09 起，前复权 3,844,512 行，n_days=736）**。MC 只对 2 个核心因子跑（adx14、bbw_pct120，n=50）——与旧口径完全同口径，保证新旧可比。

**新旧对照结论：全部 8 因子 IC 方向不变、幅度漂移 ≤ 0.0013（dist_high20 由 -0.0002 微翻 +0.0011，仍≈0）；单调性方向全部不变；MC 闸门结果不变（两核心因子均不过闸，rank=0.00）。复权切换不改变体检任何定性结论。**
（trend_up_confirm 单调性由 NaN 变为 +0.175：旧口径下 decile 分组退化，新口径下 ic_layer 分位秩分组给出了弱正单调；事件型因子的 decile 本就非适用口径，不作解读。）

**体检解读（诚实声明，与旧版一致）**：

1. **全部因子作为「次日收益方向预测」均不过 MC 闸**。这是预期内的——regime 因子是**状态标签**，不是方向信号；它的价值不在 IC，而在条件波动结构（见第五节）。
2. 显著的非零负 IC（bbw、ma_bull_layers/cont、bbw_pct120）方向一致：**趋势越强/带宽越宽，次日（T+1 开盘买）收益越低**——A 股日频反转效应的又一佐证，与「低吸高抛」而非「追涨」的策略前提相容。
3. ma_bull_layers 的 decile 单调性 -0.903（新旧口径完全一致）很强，但是**负方向**：多头越满次日越差。用于「防卖飞/只加不减」的打标功能不受影响，但**不能**外推成「多头排列→追涨」。
4. trend_up_confirm 是 0/1 事件因子，decile 分组口径不适用，属口径限制而非数据问题。

## 五、场景价值验证（本包重点，前复权复跑）

问题：**「震荡末期 + 单边上涨」段的次日日内波动是否显著大于其他 regime？**（策略线② 的前提假设）

口径：对每个 (symbol, t) 的 regime 标签，统计 t+1 日三个口径（t→t+1 日历间隔 ≤5 天才计入，停牌跨越不算次日）：

- **amp** = (high-low)/open —— 振幅捕获空间
- **theo** = (high-low)/low —— 理论低吸高抛上限（low 买 high 卖，不可实现的乐观上界）
- **real** = close/open-1 —— 现实口径（open 买 close 卖）

蒙特卡洛（日期内洗牌 100 次，每日截面抽样上限 500 行，新旧口径参数完全一致）：obs_diff=+0.00231，**p=0.0099** < 0.05。

### 5.3 结论：**证实（带结构性修正）——前复权面板下三个关键结论全部确认**

- **证实**：目标组次日振幅显著大于其余 regime（+5.8%，MW p=1.9e-15，日期内洗牌 MC p=0.0099，双重检验均过；旧口径 +5.9%/p=1.3e-14/p=0.0099，几乎逐位一致）。策略线② 的波动前提在前复权面板下依然成立。
- **结论①确认——效应由单边上涨贡献**：单边上涨段 amp 5.24% 仍为五类最高（旧 5.27%）；目标组的超额波动几乎全部来自单边上涨段。
- **结论②确认——震荡末期振幅最低**：震荡末期 amp 3.09% 仍为五类最低（旧 3.10%）——这正是「带宽收缩」的物理含义，收缩期波动小是定义使然。震荡末期的价值不在「当下波动大」，而在其为**波动扩张的前夜**；本报告只验证了条件同期波动，「末期 → 随后 N 日波动扩张」的时序传导未验证，列为后续工作。
- **结论③确认——real 口径反向**：目标组 open→close 方向性收益显著低于其余（-40.1%，MW p=0.9954；旧 -39.6%）。振幅大 ≠ 方向性肉多——低吸高抛赚的是**振幅内的往返价差**，不是持有收益；策略实现必须真的低买高卖（挂单价差捕获），持有不动反而跑输。

## 七、局限与后续

1. **复权口径**：已切换前复权并复跑确认（本报告数字即前复权结果）；旧不复权产物保留对照。前复权口径下远端历史价格可能为负/失真（新股长历史分红累积），ADX/BBW 为比值类指标受影响有限，dist_high20 等比值因子同理，但极端个案未逐只排查。
2. **MC 覆盖**：体检 MC 只跑 2 个核心因子（n=50）；场景 MC n=100 且每日抽样 500 行（置换检验仍有效，检验力略降）。
3. **震荡末期的「传导」未验证**：需补「末期后 5/10 日波动扩张概率」的时序分析——这才是低吸高抛在末期的真正入场逻辑。
4. **amp 口径不含交易成本与冲击成本**；theo 是理论上限，现实捕获率需在叠加实验台（swing_t overlay_sim）上测。
5. trend_up_confirm 事件稀疏（约 5% 截面），decile 不适用；如需体检该因子应改事件研究口径。
6. 单边下跌段的 real 均值（+0.00187）高于单边上涨（+0.00113）——A 股日频均值回归的又一表现，值得单独立项（不属本包范围）。
