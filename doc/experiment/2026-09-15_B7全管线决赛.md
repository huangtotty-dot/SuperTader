## 1. 任务①：harness_backtest 策略接入方式 —— 结论：无法容纳 B7 隔夜腿

通读 `scripts/harness_backtest.py`（799 行）后确认，harness 的"策略接入"只有一条路：
`SignalEngine.evaluate`（Renko 决策核）逐分钟 tick，信号类型固定 `BUY_LOW/ADD_POS/SELL_HIGH`，
对外只暴露 `override_params` 参数注入与 `baseline/v102` A/B 开关，**无自定义策略插件口**。
且三处硬假设与 B7 隔夜腿结构性冲突：

| # | harness 口径 | 与 B7 的冲突 |
|---|---|---|
| 1 | `settle_signal`：信号后最多 **30 根当日** 1min K 线 ±0.5%/0.4% 触及判定（harness_backtest.py:395-414） | B7 的收益来自**隔夜跳空**，当日 30 根 K 线内根本不表达 |
| 2 | `compute_closed_loop`：**当日 FIFO 配对**（:321-392），跨日腿只进 `open_short` 挂账 | B7 的 14:55 卖腿永不闭环，闭环 PnL=0 —— 不是衰减，是**收益完全不可见** |
| 3 | 费用：卖 0.00065（佣金 0.00015+印花税 0.0005，:324-325） | 生产全成本 0.00121，harness 口径每笔系统性乐观 **+0.056pp** |

**冒烟实测补充证据**：`python scripts/harness_backtest.py --codes 000988 --start 2026-08-20 --end 2026-08-21`
直接崩溃——`SignalEngine()` 抛 `TypeError: 需显式注入 EngineContext（P2-1 已移除 exec 共享全局 fallback）`。
即 harness 与现行 `core/signal_engine.py` 接口已脱节，不改既有脚本连基线都跑不通。
按铁律（不改生产/既有文件）与任务预案，**放弃硬改 harness，改用「生产规则模拟器」**：
复刻 `execution/auto` 执行规则（费用/可用量/归位/回补门控）跑同一信号序列。本偏差在此声明。

## 2. 任务②：生产规则模拟器设计（复刻规则逐条可查出处）

| 规则 | 内容 | 出处 |
|---|---|---|
| R1 费用 | 卖 0.00121（佣金+印花税+过户费 GM 全成本）/ 买 0.00015 | main.py:417-422 |
| R2 底仓存在性 | base ≥ 100 股才允许卖（生产底仓读 holdings.json，只读） | 三段式框架 |
| R3 T+1 可用量 | sell_qty = min(base, available) − 在途卖单，100 股取整 | sell_channels.py:451-455 |
| R4 数量不变硬约束 | 尾盘 14:50+ 对「未平卖出且 pos < base_ref」**无条件市价回补** | sell_channels.py:262-329（owner 2026-09-14 裁决） |
| R5 回补价格记忆门控 | 卖出 arm 链 target=sell×0.998；premium>+1%→delayed 不接；0<premium≤+1%→downgrade 减半；target<price≤sell→not_target 等回踩；price≤target→正常接回；盘中未成交→14:50 强制回补；链 3 交易日过期 | t_engine_auto.py:652-731, 765-791 |
| R6 尾盘归位 TAIL | 14:50-15:00 超底仓部分强制卖出归位；B7 卖出后 pos=0 < base_ref → **不触发，无冲突** | sell_channels.py:444-500 |
| R7 信号口径 | tail30=close(14:55)/close(14:30)−1 > 1%，信号锁死 ≤14:55（无未来函数）；接回用次日数据属策略内生合法未来 | 与 E1 一致 |

**关键发现（R4）**：B7 14:55 卖出底仓后，下一分钟 bar 即满足 `_force_tail_buyback` 触发条件
（有未平卖出 + pos < base_ref）→ 生产现状会**当场把隔夜腿杀死**，认亏也买回。
这是 B7 与现行生产规则的根本冲突，必须量化。

**三个变体**：
- **V0_offline**：E1 离线口径复现（无条件次日开盘接回）—— 对照基准；
- **V1_prod_hard**：生产现状（R4 数量不变硬约束 → 14:56 当日强制回补）；
- **V2_prod_overnight**：B7 获隔夜豁免（R4 对该策略关闭）+ R5 回补门控全量生效
  （premium≤−0.2%→open 接回；not_target/delayed→盘中首个 low≤target 按 target 限价接回，
  全天未到→14:50 收盘价强平；downgrade→半仓 open + 半仓前逻辑）。

**声明的近似**：① V2 正常接回按次日 open 成交（生产还需 Renko 向下砖确认，未模拟砖触发）；
② 限价接回 low≤target 即视为按 target 成交（未做流动性/冲击校验）；
③ 底仓 intact 假设（当日 14:55 前无底仓卖出、无未平 T 腿占用可用量 → available=base）；
④ 588170 为 ETF（实际无印花税）仍按统一 0.00121 计（保守，与 E1 一致）。

## 4. 任务④：harness 口径 vs 离线口径（E1 0.638%）差异分析

### 4.1 harness 口径的差异（结构性，全部可解释）

| 差异源 | 方向与量级 |
|---|---|
| 成交口径：settle 为信号后 30 根 ±0.5% 触及判定 vs B7 真实分钟收盘价 | 不可比（不同语义），harness 胜率≠真实盈亏 |
| 闭环假设：当日 FIFO → B7 卖腿跨日挂 open_short | **收益完全不可见**（闭环 PnL=0），非衰减 |
| 费用：卖 0.00065 vs 生产 0.00121 | harness 每笔乐观 +0.056pp |
| 可用量：harness 簿记无 T+1 available 概念 | 卖出量无约束，偏乐观 |
| 接口现状：P2-1 后 harness 跑不通现行 SignalEngine | harness 口径当前**无法产出任何数字** |

结论：harness 口径 vs E1 离线口径的"差异"不是数值差异，而是 **harness 根本无法表达隔夜策略**。
差异已全部归因：当日闭合假设（成交口径）+ 费用口径（+0.056pp/笔）+ 无可用量校验。

### 4.2 生产规则模拟器 vs E1 离线 0.638%（同口径可比）

- **池子效应**：V0 在 prod5/harness5 为 +0.843/+0.803%，**高于** E1 的 39 票池 0.638%——
  小池且含 603667（+1.26%）、300054（+0.90%）等强势票；E1 报告已指出 39 票中 6 票为负摊薄。
  两池 V0 均优于各自随机基线（mc_rank 1.00/0.965），信号增量在 5 票池同样成立。
- **V1（生产现状）**：−0.110/−0.094%，≈ 纯双边费 −0.136% + 14:55→14:56 一分钟漂移（+0.02~0.04pp）。
  **数量不变硬约束把 B7 的 +0.8% 期望打成纯费用损耗**，胜率 12~16%，最长连亏 13~14 笔。
- **V2（豁免+回补门控）**：+0.980/+1.044%，**不降反升**（vs V0 +0.843/+0.803）。
  机理：高接门控（delayed/not_target/downgrade）拦掉了 V0 中最差的「高开硬接」笔——
  E1 分层显示高开≥1% 日（72/421）均亏 −2.94%，V2 对其中能回踩 target 的按限价接回（+0.064%/笔）、
  不能回踩的推迟到 14:50。胜率从 0.694/0.645 升至 0.816/0.806，最长连亏从 4 降至 1~2。
- **代价：新左尾**。2026-05-08 000988 信号（tail30 +1.10%），次日 05-11 高开 +2.58% 后单边逼空
  （open 139.98 → 14:50 收 147.25，全天未回踩 target 136.19），V2 强制回补单笔 **−8.04%**
  （V0 同笔仅 −2.72%）。数据已逐笔核验（05-08 c1430=134.98/c1455=136.46；05-11 数据如上）。
  生产「认亏也买回」在趋势逼空日会把损失放大 ~3 倍。V2 均值仍更高，但该尾部形态必须知情。

## 5. 判定：生产口径下 B7 是否保持正期望

**有条件 PASS —— 判定分两层：**

1. **现行生产规则（V1）：否。** 数量不变硬约束（owner 2026-09-14 裁决）与 B7 隔夜腿根本冲突，
   14:55 卖出后 14:56 即被强制回补，净期望 −0.11%/−0.09%（纯付双边费），mc_rank 0.39/0.27 不优于随机。
   **B7 若不打标豁免直接上线，必死。**
2. **B7 获隔夜豁免 + 生产回补门控（V2）：是。** 双池净均 +0.98%/+1.04%（≈7.2~7.7× 双边成本），
   胜率 0.816/0.806（≥55%），优于随机 +1.01/+0.96pp（mc_rank 1.00/0.965），
   OOS 不退化反增强（+1.24%/+1.42%，优于样本内），5/5 票全正。
   **生产口径下 B7 正期望保持，且回补门控本身贡献约 +0.14~+0.24pp 增量。**

**上线前提（工程改造清单，供 owner 决策）**：
① B7 卖出须打专用通道标（如 `B7_OVERNIGHT`），`_force_tail_buyback` 对该标跳过，
   且 `arm_awaiting_buyback` 的 expire/force 逻辑改为「次日 14:50 强制回补」而非「当日 14:50」；
② 回补触发可沿用 R5 门控（本实验已证其为正增量），但建议对「开盘 gap>+2% 且 10:00 前未回踩」
   加熔断改按 10:00 市价接回，截断 −8% 级逼空尾部；
③ 与三段式框架衔接：B7 卖的是**底仓**，隔夜期间底仓=0，与「底仓 intact 默认态」冲突，
   需 owner 裁决 B7 日是否视为「估值极端偏高」例外。

**样本量诚实声明**：5 票池 n=49/62，远低于 G1 的 n≥200，本实验**不能也无意重过五闸**；
它是口径对照——同一信号序列在三种执行口径下的期望迁移（+0.84 → −0.11 → +0.98）。
E1 的 39 票 n=421 闸门结论不受影响，V2 门控增量建议回 39 票池复验（留给 E4）。

## 6. 风险点

1. **V2 左尾**：强制回补在逼空日单笔可达 −8%（已实证 1 笔），36% 卖飞率下尾部比 V0 更厚；
2. **近似偏差**：限价接回未做流动性校验；正常接回未模拟 Renko 向下砖（可能偏乐观）；
3. **intact 假设**：若当日已有 T 腿占用可用量，14:55 可卖量 < base，实际每笔规模更小（期望/笔不变，账户贡献打折）；
4. **harness 失修**：P2-1 后 harness_backtest.py 无法运行，其历史基线数字的可信度需重新标定（另立任务）；
5. **588170 ETF 费用口径**偏保守（多计印花税 0.05%），harness5 数字略低估；
6. V2 门控增量（+0.14~0.24pp）来自 15/24 笔非 open 路径，小样本，需 39 票池复验确认。
