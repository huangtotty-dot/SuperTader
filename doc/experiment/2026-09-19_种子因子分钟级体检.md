## 一、口径预注册

**① 单票时序 IC 初筛**
- label = 未来 30 分钟收益 `close(t+30)/close(t) − 1`，**方向口径**（对齐设计文档 §3.3 候选二的 label 修正口径；不是捕获上限口径——「30 分钟内最高价」有不可成交的乐观偏差，终审才用真实出场臂裁决）。
- label **日内截断不跨日**：每日末 30 根 bar 的 label 为 NaN。这一刀同时解决了两个问题——30 分钟前瞻跨日会混入隔夜跳空；且 IS 段 label 物理上不可能触及 OOS 数据，IS/OOS 边界（2026-06-01）天然无泄漏。
- 逐只票算因子值 × label 的 Spearman 相关（秩复用 ic_layer 连续组实现，无 scipy），39 只汇总均值/中位/胜率（IC>0 票占比）/最差/最佳；IS、OOS 分别报告。
- 排名口径：按 **|IS 均值 IC|** 取前 5 进终审与 MC（GP 种子方向可调，绝对值代表预测力）。

**② eval_factor 交易式终审（TOP5）**：直接 import eval_factor 的 load_code / zscores / run_entries / legs_hold_fast / random_baseline / _aggregate，逐项对齐——过去 14 日同一 HH:MM z-score 穿越 ±1 入场、次根 bar 开盘成交、双边 0.136%（FEE_S+FEE_B=0.00136）、每日 ≤3 次、双向都测、hold/native 两臂、逐腿配对随机基线（k=20）、|净均−随机|<0.2% → DEAD 预注册闸门。种子适配方式：panel 日 bar 重拼连续分钟序列喂种子库（跨日窗口语义正确），再按日切回 {date: array}。另跑 `--leak 5` 前视自检（hold 臂）。

**③ MC 标签日块打乱（TOP5，n=100，seed=20260919，IS 段）**：label 按日块整体置换（保留日内形态、破坏可预测对齐，对齐设计文档 §六），重算票均时序 IC 得 null 分布；真实 IC ≤ null 95 分位 → SUSPECT。负 IC 因子按 IS 均值符号定向（单侧闸门，与 ic_layer 口径一致）。

## 五、结论：GP 初始化种群建议

**进种群（作为构建块/方向先验，非直接交易信号）：**
- **a054**（K 线实体波动+量价一致性反向）——IC 最强且票间一致性最高（95% 胜率 + MC 票通过率 67%），首选种子。
- **a002**（CLV 多空失衡变动）——IC 稳定、IS/OOS 符号一致、票通过率近半。
- **a070**（成交额波动率，反向用）——|IC| 最大且 OOS 加深，但它是状态/过滤变量，适合进 GP 当**条件门控原材料**（如「高 a070 时不交易」），不适合 z 穿越触发。
- 候补：**a001**（OOS 加强至 +0.0221、胜率 67%）、**a062**（OOS +0.0148 加强）、**a005/a085/a042**（符号一致且 OOS 不塌）可作多样性补充。

**直接淘汰：**
- **a034**——OOS 翻号 + MC 票通过率 5% + 终审 DEAD，三重否决。
- **a040**——终审 Δ 精确反对称 + leak 不塌缩，证伪为方向漂移暴露；且 MC 票通过率 13%。
- **a008、a076**——IS≈0 且 OOS 翻号为负。
- 符号不一致且 |OOS IC|<0.005 的平庸种子（a043/a020/a063/a003/a023/a105/a139/a011/a012 等）不进初代种群；GP 若需要可通过变异重新发现。

**对 GP 管线的两条预警（比种子名单更重要）：**
1. **IC 层与终审层存在系统性口径落差**：30 分钟方向预测力 |IC|≈0.02~0.03 真实存在（MC 全过闸），但 0.136% 双边成本 + 高密度触发下 TOP5 终审无一给出择时 Δ。若 GP 主适应度用纯时序 IC，必须预期终审大量 DEAD；适应度应内置触发率约束与成本惩罚（设计文档 §3.3 候选三抽检器必须真的跑）。
2. **hold 臂的 Δ 反对称签名**：「信号择时」与「方向暴露」在逐腿配对基线下可分离——凡双向 Δ 精确镜像且 leak 不塌缩者，是暴露不是择时。GP 终选时应把这条做成自动检查。

## 六、诚实声明

1. **票间异质性**：39 只池含 3 只 ETF（515120/515180/588170）与个股混排，波动率与流动性结构不同；IS 段 IC 的票间 std（0.016~0.030）与均值同量级，部分因子均值由个别票驱动（a034 最佳票 +0.0465/最差 −0.0188，票通过率仅 5%）。「票均 IC」等权口径对小票与高波动票不做调整。
2. **label 口径局限**：方向口径 `close(t+30)/close(t)−1` 不含成本、不含成交可行性、不含仓位约束；IC 名义值受分钟级时序自相关膨胀（已由日块打乱 MC 校准零假设，但 MC 只打乱 label，因子侧日内结构完整保留——若因子自带与日内形态共振的周期性，null 可能偏松）。n=100 的分位分辨率为 1%。
3. **两条数据管线的细微差异**：IC 初筛用 minute_data.merge_frames（同日两源取根数多者，全日历范围），终审用 eval_factor→v2.merge_days（快照只补 CSV 截止之后日期）；终审窗口 2025-09-14~2026-08-26（eval_factor.WIN_START）比 IC 窗口（2025-08-26 起）略窄。两管线结论方向一致，交叉对照不受此影响，但逐格数字不可跨管线直接相减。
4. **终审密度的口径代价**：a070/a040 终审 n 仅 ~1500-1600 腿（密度 0.17-0.19），因为 26 日窗口 warmup + 14 日 z-score 历史 + MIN_HIST_DAYS=5 叠加，前 ~40 个交易日无信号；这压缩了终审样本量，OOS 腿数仅 437-460，OOS 净均的置信度有限。
5. **leak 自检的适用范围**：本轮全部因子的择时 Δ≈0，leak=5「无塌缩」只能说明无泄漏迹象，不能反向证明因子有效——本轮它主要作为 a040 伪 KEEP 的鉴伪工具使用。
