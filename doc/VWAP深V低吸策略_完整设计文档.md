> 最后更新: 2026-07-24 | 基于 Optuna 五维参数寻优 + 279 天全量回测

## 一、策略哲学

### 1.1 为什么选择 VWAP 深V低吸

A股市场有两个结构性特征:

1. **散户追涨杀跌**: 早盘冲高后回落是常态，午后往往有二次拉升。正 T（先买后卖）比反 T（先卖后买）容错率更高。
2. **VWAP 是机构成本线**: 价格偏离 VWAP 超过 2% 时，有均值回归动力。深跌后买入，反弹到 VWAP 附近或微利即走。

本策略的核心逻辑：**只在价格大幅低于 VWAP 时买入，微利即走，不恋战。**

```
         价格
          ↑
    115  -|     🚫 不买（高于VWAP）
          |
    113  -|---- VWAP ────────────
          |
    111  -|     ✅ 买入区（低于VWAP 1.8%~2.2%）
          |
    109  -|     ✅ 加仓区（深V反弹信号确认）
          |
          +──────────────────────────→ 时间
          09:30        11:00        14:00
```

### 1.2 三大铁律

| 铁律 | 内容 | 实现方式 |
|------|------|----------|
| **绝不追高** | 价格高于 VWAP 时不买入 | `vwap_buy_deviation` < 0 |
| **微利即走** | 盈利 1.5%~2.1% 即止盈 | `take_profit_pct` |
| **早盘不卖** | 10:00 前禁止卖出 | `morning_no_sell_until = 1000` |

## 二、信号引擎架构

### 2.1 五层决策体系

```
Layer 1: FeatureExtractor  提取 60+ 特征
  ├── 分钟线: VWAP偏离、RSI、MACD、EMA、ATR
  ├── 15分钟线: 支撑位、多重底、动能衰竭
  ├── 5分钟线: 缩量止跌、大阳线反包
  └── 日线: MA均线、破位风险、过热检测

Layer 2: ScoringEngine     因子打分（权重化 sigmoid）
  ├── VWAP 因子 (20%)  → 偏离深度
  ├── RSI 因子  (12%)  → 超卖程度
  ├── MACD 因子 (8%)   → 动能拐头
  ├── 量能因子  (8%)   → 放量确认
  ├── 形态因子  (20%)  → K线形态组合
  ├── 大盘因子  (20%)  → 市场态势
  └── EMA 因子  (4%)   → 趋势改善

Layer 3: RiskManager       一票否决
  ├── 日线破位 → 禁止买入
  ├── 大盘单边下行 → 禁止买入
  ├── 开盘急跌无反包 → 禁止买入
  └── 强势上涨 → 禁止卖出（防卖飞）

Layer 4: 推送阈值过滤      信号质量控制
  ├── 买入信号 → score ≥ notify_buy_threshold 才推送
  └── 卖出信号 → score ≥ notify_sell_threshold 才推送

Layer 5: 执行层            资金管理 + 持仓追踪
  ├── 每笔固定 200 股
  ├── 每日最多 3 买 3 卖
  └── T+0 闭环配对（买→卖 = long_t）
```

### 2.2 核心参数说明

| 参数 | 含义 | 影响 |
|------|------|------|
| `vwap_buy_deviation` | 价格低于 VWAP 多少才触发买入 | 越小（越负）= 越深才买，错过机会；越大 = 更容易触发但可能抄在半山腰 |
| `take_profit_pct` | 持仓盈利多少时强推止盈 | 太小 = 覆盖不了滑点；太大 = 难以触发 |
| `buy_confirm_min_score` | 引擎内部买入最低分（满分100） | 越高 = 越严格，信号越少但质量越高 |
| `notify_buy_threshold` | 买入推送阈值（≥此分才推飞书+执行） | 实盘阀门，高于引擎内部阈值 |
| `notify_sell_threshold` | 卖出推送阈值（10:00后使用） | 同上 |

### 2.3 阈值设计逻辑

引擎内部阈值固定为 **42 分**（ATR+Sigmoid 自适应）。推送阈值叠加在引擎之上：

```
引擎 score ≥ 42  →  信号生成
       +
推送 score ≥ N   →  飞书推送 + 实际执行

N 由 optimizer 寻优得出，因股而异
```

## 三、参数寻优体系

### 3.1 寻优方法

采用 **Optuna TPE**（Tree-structured Parzen Estimator）贝叶斯优化：

- 搜索空间: 5 维（vwap, take_profit, min_score, sell_threshold, buy_threshold）
- 每次采样 100 trials
- 训练集: 2025-06-01 ~ 2026-03-31（217 天）
- 测试集: 2026-04-01 ~ 2026-07-20（79 天）
- 目标函数: `composite = (年化收益率 / |最大回撤|) × 胜率 × 交易频次惩罚`

### 3.2 目标函数公式

```
composite = (annualized_ret / abs(max_drawdown)) × (win_rate × 100) × trade_penalty

trade_penalty = log(min(annualized_trades, 60) + 1) / log(31)
```

- **Calmar 比率**（年化/回撤）：衡量风险调整收益
- **胜率加权**：防止靠单笔运气刷分
- **对数惩罚**：年化 30 笔 ≈ 1.0（无惩罚），年化 3 笔 ≈ 0.36（压降 64%）

### 3.3 各股票最优参数

| 股票 | vwap | take_profit | min_score | sell_TH | buy_TH | 训练得分 |
|------|------|-------------|-----------|---------|--------|----------|
| 600481 双良节能 | -1.61% | 1.48% | 24 | 62 | 43 | 1630 |
| 000988 华工科技 | -2.20% | 2.12% | 16 | 63 | 43 | 851 |
| 603667 五洲新春 | -2.76% | 2.00% | 19 | 64 | 40 | 498 |
| 600176 中国巨石 | -1.73% | 2.11% | 20 | 51 | 40 | 434 |
| 588170 科创ETF | -3.13% | 2.06% | 30 | 67 | 40 | 12 |

**共性规律**:
- `notify_buy_threshold` 全部收敛到 **40-43**（买入信号不要过度过滤）
- `take_profit_pct` 集中在 **1.5%~2.1%**（黄金止盈窗口）
- ETF（588170）得分极低，该策略不适用

## 五、闭环机制（V1.29 新增）

策略的核心不是单次交易，而是**买卖配对闭环**。引擎在两个方向上主动追踪：

### 5.1 卖出→接回（正向闭环）

```
触发: 任何 SELL_HIGH 信号被推送执行
     ↓
追踪: awaiting_buyback[code] = {卖出价, 数量, 目标接回价, TTL=120min}
     ↓
评估: 每次 evaluate() 检查:
     ├── 价格低于卖出价 >0.5% → buy_score +10 (积极接回)
     ├── 价格低于卖出价 >0.1% → buy_score +5  (微利接回)
     ├── 买入阈值 -5 (更容易触发)
     └── TTL 超时 → 自动清除追踪
     ↓
闭环: 累计买入量 ≥ 卖出量 → 清除追踪，完成闭环 ✅
```

### 5.2 买入→高抛（反向闭环）

```
触发: 任何 BUY_LOW 信号被推送执行
     ↓
追踪: pending_sells[code] = {买入价, 数量, 目标卖出价}
     ↓
评估: 每次 evaluate() 检查:
     └── 盈利 ≥ take_profit_pct → sell_score +15
     ↓
闭环: 累计卖出量 ≥ 买入量 → 清除追踪，完成闭环 ✅
```

### 5.3 止盈辅助

10:00 后持仓盈利 ≥ `take_profit_pct` → `sell_score +30`，确保止盈触发优先于其它信号。

## 六、风控体系

### 5.1 大盘联动

| 大盘状态 | 触发条件 | 动作 |
|----------|----------|------|
| 单边下行 (uni_down) | index_regime 判定 | 禁止所有买入 |
| 防御模式 (defensive_t) | 指数评分 ≤ -15 | 仅允许卖出，买入极度收紧 |
| 恐慌末端 (panic_capitulation) | 评分 ≤ -40 | 停止所有操作 |

### 5.2 个股风控

| 规则 | 实现 |
|------|------|
| 日线破位 | `daily_breakdown_risk = True` → 全天禁买 |
| 开盘急跌无反包 | 前 15 分钟跌超 1.5% 且无大阳线 → 禁买 |
| 早盘保护 | 10:00 前 `today_ret < 3%` → 禁卖 |
| 强势上涨 | `is_strong_uptrend = True` → 禁卖（防卖飞） |

### 5.3 早盘单边下行预警

基于近两年数据训练的 ML 模型，在 10:00 触发：

| 级别 | 条件（000988 为例） | 动作 |
|------|---------------------|------|
| Level 2 | 开盘30分钟跌 >1.79% 且无反弹 | 🚨 全天禁止买入 |
| Level 1 | 开盘30分钟跌 >1.00% | ⚠️ 买入阈值 +8，必须深V (>1.5%) |

各股票阈值不同，参见 `config.py` 中 `MORNING_ALERT_PARAMS`。

## 七、实战使用

### 6.1 训练新股票

```bash
# 下载数据（只需一次）
python optimizer.py --code 600xxx --method quick --trials 1 --start-train 2025-06-01 --end-train 2026-03-31 --no-validate

# 完整寻优（100 trials，约 3 小时）
python optimizer.py --code 600xxx --method optuna --trials 100 --step 5 \
  --start-train 2025-06-01 --end-train 2026-03-31 \
  --start-test 2026-04-01 --end-test 2026-07-20
```

### 6.2 回测验证

```bash
# 单只股票
python batch_backtest.py --code 000988

# 全部持仓
python batch_backtest.py
```

### 6.3 更新参数

将 optimizer 输出的最优参数写入 `config.py` 中对应股票的 `STOCK_PARAMS`：

```python
"600176": {
    "vwap_buy_deviation": -0.0173,
    "take_profit_pct": 0.0211,
    "buy_confirm_min_score": 20,
    "notify_sell_threshold": 51,
    "notify_buy_threshold": 40,
    ...
}
```

### 6.4 每日监控

- **09:26** 飞书推送盘前大盘态势
- **14:50** 买卖闭环审计（检查未接回/未卖出）
- **14:59** 每日收益汇总（各股盈亏 + T0实盈）
- 信号推送: 盘中实时，仅 score ≥ 个股推送阈值时触发
