# C20 · 竞价缺口纳入早盘基调 · 设计方案（周六评审材料）

> 来源：2026-08-18 / 08-19 连续两日 🔴——09:26 基调推送"单边上涨"（S=55.25 / S=52.36），实际两日均为大跌日。触发"任一阶段连续 2 日 🔴 → 周六强制议题"规则。
> 设计原则：**不改 regime 判定本身**（那是周六验证管线的对象），只在推送层叠加"竞价现实校验"——把系统里已存在但未被消费的竞价数据用起来。

---

## 1. 问题定义

`detect_index_regime(mode="morning")` 设计上**对齐到昨日收盘**（注释原文："保证评分基于昨日收盘，不受当日集合竞价 partial bar 影响"）。这个设计在平稳市合理，但在隔夜重大变化日（低开 -4~5%）会产生方向性错误的定调推送。

两日实证：

| 日期 | 09:26 推送 | 当日竞价实况（系统内已有） | 实际全天 |
|------|-----------|---------------------------|----------|
| 08-18 | 单边上涨 S=55.25 | 高开 +1.3~5.6%，09:31 宽度 1648/3404 转空 | 分化震荡，科创50 -1.84% |
| 08-19 | 单边上涨 S=52.36 | 低开 -4.25%/-4.89%，Top20 竞价 3涨17跌 strong_bearish | 崩盘，持仓收 -8.6%~-9.9% |

**心理锚效应**：错误的多头定调比没有定调更有害——用户在"单边上涨"预期下面对崩盘更容易犹豫（08-18 "不敢"）、更不容易执行"破线只卖"纪律。

## 2. 可用数据（09:26 推送时点已就绪）

| 数据 | 文件 | 字段 | 状态 |
|------|------|------|------|
| 持仓竞价缺口 | `t_io/preopen/auction_{date}.json` | `snapshots["09:22"].rows[code].pct_vs_preclose` | C17 修复后可靠（08-19 实测：-4.25%/-4.89% 真实） |
| Top20 竞价多空 | `t_io/preopen/preopen_{date}.json` | `auction_summary.top20_bias / top20_up / top20_down` | 09:25 后有效（08-19：strong_bearish 3/17） |
| 持仓多空计数 | 同上 | `holdings_bullish / holdings_bearish` | 同上（2/4） |
| 竞价比对窗口 | — | 推送窗口 09:26-09:31，数据最新 09:25:34 | 时序满足 |

注：竞价 amount/vol_ratio 在 09:25 撮合前结构性为 0（C24 另行处理），本方案**只用价格维度**，绕开该缺口。

## 3. 设计：竞价现实校验层（Realism Overlay）

### 3.1 插入点

`main.py::_maybe_push_index_regime_morning`（09:26-09:31 每日一次）：
`detect_index_regime(mode="morning")` 之后、`_build_index_regime_card` 之前，插入 `_auction_reality_check(today)`，返回校验结果对象；卡片组装时按其级别叠加展示。

### 3.2 校验规则（三级）

```
输入：holdings_gap = 持仓 pct_vs_preclose 中位数；top20_bias；regime_name
背离判定 = regime 偏多（单边上涨/强势/震荡偏多）且 现实偏空

Level 0 无背离      → 正常推送，卡片尾部加一行竞价实况（信息增强，非警示）
Level 1 轻度背离    → 条件：holdings_gap ≤ -1.0% 或 top20_bias ∈ (bearish, strong_bearish)
                      卡片追加 🟡 警示段："竞价实况与基调背离，今日定调参考权重下调"
Level 2 重度背离    → 条件：holdings_gap ≤ -2.5% 或（strong_bearish 且 holdings_bearish ≥ 半数）
                      卡片标题降级为"⚠️ 风险姿态"；正文首行改推纪律提醒：
                      "持仓竞价中位数 {gap}%，破线标的执行 只卖不买（C26 联动）"
反向背离（基调偏空/竞价偏多）→ 对称处理，仅 Level 1 提示，不降级标题
```

阈值 -1.0% / -2.5% 为初值，**周六走离线筛查**（历史 preopen/auction 文件回放近 60 日）再定稿，不拍脑袋上线。

### 3.3 卡片示例（08-19 若已上线）

```
⚠️ 早盘大盘基调 · 风险姿态
模型判定（基于昨日收盘）：单边上涨 S=52.36
━━━━━━━
🔴 竞价现实校验：重度背离
· 持仓竞价中位数 -4.3%（6/7 低开）
· 竞价额 Top20：3 涨 17 跌（strong_bearish）
· 纪律提醒：破 5 日线标的 只卖不买
决策提示：今日以竞价实况为准，模型定调权重下调
```

### 3.4 边界与降级

| 情形 | 行为 |
|------|------|
| auction 文件缺失/断档 | 跳过校验，卡片标注"竞价校验不可用"（不静默跳过——C17-3 的告警精神） |
| 持仓缺口与 Top20 矛盾 | 以持仓缺口为准（用户的钱在持仓上） |
| 非交易日 / 数据时间戳非今日 | 跳过 |
| mode="tail"（14:30 尾盘预判） | 本方案不覆盖；08-19 "横盘震荡 S=35.2" 失真另记观察项（tail 模式含当日 forming bar，问题性质不同，周六单独看） |

## 4. 验收标准

- 回放：用 08-18/08-19 两日数据离线跑校验层，均应判 Level 2/Level 1 背离
- 近 60 日离线筛查：Level 2 触发日次日/当日实际下跌占比显著高于基线（预注册闸门口径）
- 实盘：正常背离日卡片带校验段；无背离日仅多一行实况信息，不干扰

## 5. 与既有候选的关系

- **C20**（本方案）：推送层校验，不动判定
- **C26**（破五日线只卖不买系统化）：Level 2 卡片的纪律提醒文案与 C26 共用规则定义，周六一并评审
- **C24**（竞价量能维度）：本方案不依赖，独立推进
- 若周六管线最终改 regime 判定本身（纳入隔夜缺口因子），本校验层仍保留作为"推送层双保险"
