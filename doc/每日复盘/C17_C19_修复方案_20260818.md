## C17 竞价采集空壳（P0 · 数据缺失）

### 根因（已实锤，非猜测）

1. `t_io/preopen/auction_collector.py:22` —— `BASE = Path(r"E:\06_T")` **旧目录硬编码残留**。项目迁移后该路径不存在。
2. 09:20 / 09:22 两个采集 slot 子进程均在 `load_pool()` 崩溃：`FileNotFoundError: E:\06_T\holdings.json`（证据：`t_io/preopen/logs/auction_collector_2026-08-18.log` 尾部 traceback）。
3. 断档显式化机制**按设计工作了**：09:26 日志有 `⚠️ 竞价采集断档: 缺 slot ['09:20','09:22']`——但只写日志不上飞书，无人感知。
4. 09:37 竞价分析拿不到 slot 数据，以 `change_pct=0 / amount_wan=0 / vol_ratio=1.0` 的空壳照常推送，7 只持仓全判"正常"——**假正常推送比不推送更有害**（给了"盘前一切正常"的错误心理锚）。

### 附带发现：同类残留路径（一并清扫）

| 文件 | 位置 | 说明 |
|------|------|------|
| auction_collector.py | :22 | 本次事故直接责任 |
| daily_sentiment.py | :97 / :131 | 独立模式加载 index_regime / config.json 的 E:\06_T 兜底 |
| index_regime.py | :345 | state_dir 默认值兜底 E:\06_T |
| （正面参照）position_builder.py:39 / t_gui.py:32 | — | 已改为 `Path(__file__)` 自解析，照此办理 |

### 修复项

| # | 修复 | 位置 | 要点 |
|---|------|------|------|
| C17-1 | 路径自解析 | auction_collector.py:22 | `BASE = Path(__file__).resolve().parents[2]`（t_io/preopen/ → 项目根）；同批清扫 daily_sentiment.py、index_regime.py 的 06_T 兜底（保留环境变量 override） |
| C17-2 | 空壳推送闸门 | 竞价分析推送组装处 | 推送前校验：两个 slot 均缺失 或 全部持仓 amount=0 → 改推"⚠️ 竞价数据缺失，今日竞价分析不可用"，**禁止以默认值输出"正常"** |
| C17-3 | 断档告警上飞书 | main.py 09:26 断档检查点 | 现有 warning 同步发一条飞书运营告警，数据缺失当场可见 |
| C17-4 | 回填今日数据 | 命令行 | 修复后跑 `python t_io/preopen/auction_collector.py --backfill`（09:25 口径），验证字段非空 |

### 验收标准

- 次日 09:20/09:22 两个 slot 文件正常落盘；09:26 无断档告警
- 09:37 竞价卡片 amount_wan / vol_ratio 为真实采集值（非 0 / 1.0）
- 人为制造 slot 缺失时：09:26 飞书收到断档告警 + 09:37 推送"数据缺失"而非"正常"

## C19 分钟快照文件锁 WinError 5（P1 · 数据完整性，连续 2 日）

### 根因分析

- 案发点：`utils.py:245-248` `_snapshot_write` —— tmp 与目标同目录，`os.replace(tmp, path)` **无重试**。
- 案发规律：08-17 14:06（000988）、08-18 14:37（600176）——**午后高发、标的不固定（迁移性）**，典型杀软/Windows 索引器定时扫描锁文件特征。
- **次生伤害（比丢快照更严重）**：写盘异常上抛 → main.py 当轮扫描整体记"扫描异常"跳过——**记账性写盘中断了信号主流程**，优先级倒挂。
- 同模式分布：`index_regime.py:535`、`t_gui.py` 多处（:424/:577/:2790/:2806/:2839）。

### 修复项

| # | 修复 | 位置 | 要点 |
|---|------|------|------|
| C19-1 | os.replace 重试退避 | utils.py `_snapshot_write` | 5 次指数退避（0.2/0.4/0.8/1.6/3.2s），覆盖 AV 秒级锁窗 |
| C19-2 | 唯一 tmp 名 | 同上 | `tmp = f"{path}.{pid}.{ts_ms}.tmp"`，避免孤儿 tmp 互相覆盖；重试耗尽后**保留 tmp 并 warning**（数据不丢、可人工恢复），并计数孤儿文件 |
| C19-3 | 故障隔离 | 同上 + index_regime.py:535 | 快照写异常自吞（log.warning 后 return），**不再打断当轮信号扫描**；主流程与记账写盘解耦 |
| C19-4 | 环境层根除（需用户操作） | Windows 设置 | 把 `E:\superTrader\t_io` 加入 Defender 排除项（设置 → 病毒和威胁防护 → 排除项）；脚本启动时检测打印一次提示 |

### 验收标准

- 连续 3 个交易日无 WinError 5 日志
- 构造性测试（人为占用目标文件）下：重试生效、最终失败时 tmp 保留、**当轮信号扫描不中断**
