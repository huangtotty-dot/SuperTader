## 1. W1 核验 —— A/B 首次同口径，但暴露出三个 commit 没说的事实

### 1.1 数字复现 ✓

baseline 47 信号 / 52.17%；v102 98 信号 / 48.96%；v106 信号集合与 v105 完全相同（仅多 qty 字段）。确定性回归通过（信号级两跑字节级一致）。

### 1.2 构成混杂（A/B 纯度的保留项）

- **baseline 47 条信号全部是 SELL_HIGH，零买入**——去掉趋势因子后买分全天过不了个股阈值（40-43）。A/B 胜率差 −3.2pp 混杂了**方向构成差异**（B 组 77 买 21 卖 vs A 组 47 全卖），不是纯粹的"趋势层效果"。
- 两组信号**仅 9 条重合**：趋势层实际是"新增 89 条（胜率 50.6%）+ 消灭 38 条（胜率 56.8%）"的 churn，净 +51 掩盖了结构。
- **苹果对苹果的分层**：卖出侧 baseline 52.2%（24/46）vs v102 38.1%（8/21）——趋势层筛选后的卖出信号反而差 14pp；v102 买入侧 52.0%≈抛硬币。
- 000988/600481 在 baseline 下仍零信号，分股 A/B 依旧不可比。

### 1.3 显著性判定

Fisher 精确检验 p=**0.858**——远不显著。明确结论：**现有证据既不能证明趋势层有害也不能证明有益**；但点估计持续为负（总量 −3.2pp、卖出侧 −14pp、被拦信号多数是好信号），方向令人担忧。N 太小，下任何结论前必须扩样本。

## 2. W2/W3 核验

### 2.1 闭环修正 ✓（两处保留）

- 当日 FIFO / 印花税两腿均在卖出侧 / qty 入信号记录——代码与方案 §1.2 一致。
- v102 组 **11 对 / +382.65**（复现 ✓，调用 harness 实际函数交叉验证一致）；**baseline 组 0 对 / +0.00**（全卖无买，4700 股开放空仓挂账）——commit 没提，P2③ 的"B≥A"实际是 +382 vs 0 的退化比较。
- +382 构成：588170 五对 +272.76（71%，其中两对各约 +100 元来自 ETF 单日 2.2-2.5% 大波动）、600176 +74.35、603667 +35.55——仍是少数大波动主导，但已全是当日闭环，口径成立。
- 保留项：① **77/98 信号 qty=0**——动态份数拒绝了近八成信号（实盘 qty=0 不推送不成交），11 对中 3 对是 qty=0 幽灵对（pnl=0），真实经济闭环 8 对；② baseline 证据生成于 W2 加 qty 之前，信号无 qty 字段，证据链版本不一致（因 0 对无实际影响）。

### 2.2 P1 口径 —— NEUTRAL 诚实 ✓；一致率不稳定；三项未做

- **NEUTRAL 9.68%**（3408/35208 分钟）复算一致，真实时长口径落实，团队如实承认低于 20% 闸门 ✓。
- **一致率 78.1% 不稳定（本轮最重要发现之一）**：午盘前众数（11:30 截止）已实现，但 **108 天中 45 天 AM 状态 1-1 平局**，`max(set(...), key=count)` 依赖字符串集合迭代顺序，而 Python 跨进程 str hash 随机化——用 harness 实际函数连测 3 次：**0.781 / 0.812 / 0.781**（bull 0.923↔0.538、bear 0.684↔1.000 整体翻转）。**78.1% 只是随机分布的一次抽样**。这同时解开了上轮悬案：**v105 的 87.5% 极可能就是同一代码另一次 hash seed 下的平局变体**；也意味着"同输入字节级一致"的 P0 确定性对 summary 指标在全样本下不成立（单日无平局时成立，本轮 07-02 两跑验证 ✓）。两个模态都 ≥65%，闸门本身不受影响，但指标必须确定化后才可存档。
- 未做：反转日切换评估（23 个反转日仍只计数）、切换滞后测量（无 lag 字段；07-08 案例约 34 根）、偏差比改测系统判定日数比（仍是客观日型构成比 0.684）。

### 2.3 回归与遗留

- 000988 阴跌判多未处理：v106 中其信号 trend_state 仍 11 BULL / 2 NEUTRAL（股价 167→109）。
- 样本：**25 交易日**（更正前两轮的"24"），仍 <30 日下限。
- 密度：v102 0.78 / baseline 0.38 个/股/日，均远低于 3-8 健康区间。
- classify_day_type 注释（pre_close）与实现（开盘价）仍未对齐。

## 4. 关于 §3.5 降级路径的正式评估（用户决策项）

**方案字面触发条件**（"两轮后一致率仍 <60%"）未达成——一致率 ≥65%。**但实质证据已在累积**：

| 证据 | 方向 |
|---|---|
| P2① 总量胜率 −3.2pp | 负 |
| 卖出侧分层 −14pp（52.2% vs 38.1%） | 负 |
| 被拦信号中 56.8% 是好信号 | 负 |
| 趋势层新增 89 条信号胜率 50.6% | 中性 |
| v102 买入侧 52.0% | 中性（≈抛硬币） |
| NEUTRAL 仅 9.7%（趋势层几乎不休眠但增量未证实） | 负 |

"趋势层无增量"已从第二轮的"无法排除"变为"**点估计持续为负**"。值得注意的是：**本轮 baseline 的形态（趋势因子权重=0、保留门控关闭）恰好就是 §3.5 降级形态，而它 52.2% 且构成更简单**。

**审核建议**：开启降级路径讨论，但在 25 日样本、Fisher p=0.86 的功效下不构成降级决策的充分依据。**先把样本扩到 ≥30（目标 90）交易日重跑 A/B，若点估计仍为负，执行降级**（factor_weight_5m_trend=0、仅保留 RSI trigger 加分、权重还给 1分钟体系），将 P3 寻优空间转向 1分钟体系校准与信号密度问题。
