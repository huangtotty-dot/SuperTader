## §1 做T信号：净EV 为负的诚实结论（本轮最重要）

**背景**：本周对做T信号做了一轮系统性实验（35候选 × 1~2年、tushare 1分钟数据、无未来函数、+0.5%/-0.4% 先触胜率口径）。过程中发现并修复了两处**未来函数(lookahead)**：
- 15分钟MACD确认（macd15_bb5）用了未收盘的15分钟K线 → 修正后基线 44.4%，比现状 45.9% 还差，**已回退**
- 指数过滤回测取了未收盘的指数5分钟K线 → 修正后指数MA5方向过滤真实增益仅 +4.4pp（此前虚报 +20pp）

**修正后结论**：

| 方案 | 样本内命中率 | 样本外 |
|---|---|---|
| 现状信号（5分bb+RSI6） | 45.9% | 42.5% |
| + 高抛放量确认（已实施） | 51.9%（+6.0pp） | 48.8%（+6.4pp）✅ |
| + 指数MA5方向过滤 | 49.6%（+4.4pp） | 稳健 |

**关键：结算参数网格（目标0.3/0.5/0.8% × 止损0.3/0.4/0.6% × 窗口15/30/60min）27 组全部净EV为负**：
- 毛优势仅 +0.02%~+0.05% 每笔，被 0.15%~0.25% 交易成本完全吃掉
- 即使最低佣金(万2.5)估算，净EV仍为负

**结论**：做T信号机械执行在扣成本后是净亏损的。问题不在命中率，而在**"小目标 + 高成本"结构性不匹配**。已实施的改进（高抛放量确认 + 指数MA5过滤）是真实但温和的改善，改变不了净EV为负的本质。

**个股分层线索**：做T命中率个股差异巨大（300666 55.6% / 002261 53.2% / 688102 52.1% vs 600547 33.8% / 515180 30.0%）。

## §2 方向转向：建仓/加仓时机判定（本周起重点）

**用户判断**：如果进场时机合适（多头 + 风险已释放），可增大收益；其他时间应尽量降低交易频率。当前建仓（W33 双通道）与加仓（sizing）逻辑偏"拍脑袋"，需要实验支撑。

**实验目标**：找出"何时建仓/加仓"的判定条件——用历史数据验证"多头 + 风险释放 + 回踩"等时机特征对**前向收益（1/3/5日）**的预测力，形成 go/no-go 规则：条件成立才进场，否则降频。

**遗留观察**：
- 做T：维持现状信号 + 高抛放量 + 指数MA5，但降低做T交易频率预期（机械做T不赚钱）
- 需重新定位做T目的：是"解放T+1锁仓/降成本"（评估口径=持仓成本改善）而非单笔alpha

## §3 建仓/加仓时机实验（本周执行，8960行×1年）

**方法**：逐候选股日线计算时机特征（大势代理/个股多头结构/回撤/RSI/金叉/缩量）+ 前向1/3/5日收益。

**样本内结果（2025-08~2026-08）**：
- 个股多头结构（价>MA20&MA60）：fwd5 2.48% vs 空头 1.06% → 多头进场更好
- MACD金叉近5日：fwd5 2.75% vs 1.47% → 金叉后进场更好
- **回撤幅度与直觉相反**：深回撤<-10% fwd5 0.80%（最差），接近新高/浅回撤 3~5%（最好）→ 是**动量效应**（追强），不是"风险释放抄底"
- GO规则（多头+浅回撤+金叉）：n=351，fwd5 **5.67%**（基线1.71%）

**样本外（2024-08~2025-08）——证伪/数据受限**：
- GO规则 fwd5 仅 1.41%（<基线2.08%），且"空头+深回撤"反超（2.78%）→ 规则反转
- ⚠️ **但日线缓存仅365天（2025-02~2026-08），所谓样本外只覆盖窗口尾部，与样本内重叠，非真样本外**
- 两个时期上证均为牛市（+27.4%/+6.2%），非牛熊差异，规则反转主因是过拟合或数据污染

**结论**：**静态入场规则不稳健**——样本内看似强（5.67%）的动量规则无法在干净样本外验证。建仓/加仓时机判定需要**市场状态条件化**（不同 regime 用不同规则）或**明确降频**（用户直觉被数据支持：条件不明时少做）。

**硬性前提（下一步实验所需）**：拉取 2 年以上日线历史（tushare daily），才能做真样本外验证；否则任何入场规则都无法确认稳健。

## §4 真样本外 + Regime 条件化（日线扩到 800 天后的验证）

**数据升级**：日线历史从 365 天扩到 800 天（腾讯 qfq 支持，`position_builder.fetch_daily_kline` 已改），真样本外（2024-08~2025-08）得以完整覆盖。

**真样本外结果（8903 行）**：静态动量 GO 规则（多头+浅回撤+金叉）fwd5 1.31%，再次低于基线 1.78% → **静态规则确认不稳健**（两时段均反转）。

**Regime 条件化（合并两时段 17863 行，指数 vs MA60 分层）**——方向一致、可实施：

| 市场regime | 最佳入场规则 | fwd5 | 该regime基线 |
|---|---|---|---|
| 多头趋势（指数>MA60） | 追强：多头结构+浅回撤(≥-3%)+MACD金叉 | **3.24%**（n=691） | 1.19% |
| 空头趋势（指数<MA60） | 抄底超跌：深回撤<-10% | **3.37%**（n=1461） | 2.93% |

- 多头趋势内：追强>抄底，两个时段方向一致（样本内5.89% vs 0；样本外1.53% vs 0.56%）
- 空头趋势内：抄底>追强（3.37% vs -0.54%）
- 验证了用户判断："多头 + 风险已释放"进场可增收益，但"风险释放"定义须按regime切换（多头=浅回撤，空头=深回撤）

**实施方向（待进一步验证后）**：建仓/加仓时机 = regime 条件化——指数站上MA60用追强规则，跌破用抄底规则；条件不明确（震荡）或规则不满足时**降频**。

## §5 实施落地（2026-08-15）

**新模块 `timing_gate.py`**：`timing_verdict(code, date)` 实现 regime 条件化判定（多头追强/空头抄底/震荡降频），配置 `ENTRY_TIMING_PARAMS` 门控，CLI 可验。

**建仓侧接入**（position_builder.scan_stock）：NO-GO 时 signal→approaching、approaching→weak（降频）；配置 enabled 控制。
**加仓侧接入**（position_sizer.calc_buy_qty）：NO-GO 时阻断加仓/接回买入；`apply_to_add` + `add_block_rebuild` 配置。已验证：震荡NO-GO阻断、门控关放行。

**数据升级**：日线历史 365→800 天（腾讯qfq），解锁真样本外验证（W34 §4 的结果即基于此）。

**实盘生效**：需重启 main.py 后，建仓扫描与加仓买入将按时机门控降频。

## §6 实战化回测（当前水平 + 优化落地）

**成本修正（2026-08-15）**：`commission_rate` 0.1% → **万2.5（0.00025）**，A股散户实际佣金。回测实证：做T在真实成本下净EV≈-0.01%（接近盈亏平衡），0.1%假设高估亏损。

**当前实战水平（每笔扣0.10%往返成本）**：
| 进场策略 | 样本内5日净 | 样本外5日净 | 胜率 |
|---|---|---|---|
| 无门控 | 1.61% | 1.68% | ~54% |
| **仅GO日（时机门控）** | **3.13%** | **2.21%** | **~58%** |

**持有期（fwd7/fwd10 验证后）**：GO规则净收益与胜率随持有期单调上升，两时段一致——
| 持有期 | 样本内净收益/胜率 | 样本外净收益/胜率 |
|---|---|---|
| 3日 | 1.5% / 56% | 1.5% / 55% |
| 5日 | 2.8% / 58% | 2.2% / 58% |
| 7日 | 4.1% / 60% | 3.3% / 61% |
| **10日** | **6.1% / 64%** | **5.0% / 65%** |
→ **建仓/加仓后应持有 7-10 日（多日动量延续），而非 3-5 日快进快出**。

**增强过滤（金叉+RSI40-70）**：样本内6.24%但样本外仅2.41% → 过拟合，不采用，保持基础GO规则。

## §7 建仓信号重构为方案A（2026-08-15 用户拍板）

**问题证实**：回放230交易日，旧冰点双通道全过仅 13 次（28/35 只为0）——条件几乎永不触发，观察股可能永远不满足。

**方案A**：建仓信号 = 时机门控 GO（多头追强/空头抄底/震荡降频）替代冰点双通道。
- 触发率：平均 **19.1%** 交易日（旧冰点 0~0.4%），彻底解决"永不触发"
- GO 日 fwd5 净收益 2.2-3.1%（已验证两时段稳健）
- 新条件 4 键（与 GUI 显示一致）：市场有方向 / 多头结构 / 回撤到位 / MACD金叉(加分)
- GUI：建仓表判定=GO/NO-GO、条件圆点=新时机条件、加仓观察显示时机徽章

**GUI 链接（2026-08-15）**：

建仓/加仓时机门控已通过 GUI 可视化：
- **建仓扫描表**：每行新增时机门控徽章（多头·GO/空头·NO-GO/震荡·NO-GO，hover 见原因），数据经 position_builder trace → t_gui → web
