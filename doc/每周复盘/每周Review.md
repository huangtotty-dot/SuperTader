# 每周 Review · 加仓 & 建仓质量

> **版本**：V2.1（2026-08-13）
> **定位**：每周唯一允许"改参数/改条件/上线"的时点。输入=本周每日 Review 的候选登记 + 两张滚动前瞻表；输出=下周生产配置 + 观察项维护。
> **时间**：周六，约 2~3 小时。
> **铁律**：所有变更走验证管线（离线筛查 → 全管线决赛 → 预注册闸门 → 上线 → 观察期）；**预注册闸门在执行前写入当周复盘章节，破闸即放弃回退，不强行上线**。

## §2 加仓质量周评（主轴 ①，~40 分钟）

- [ ] 聚合每日「加仓滚动前瞻表」：
  - 接回类：笔数、次日浮盈均值/中位、3 日浮盈、劣于 VWAP 买入占比
  - 首加类：同上 + 建议股数 vs 用户实操股数偏差分布
  - 仓位水位：加仓后超配/欠配分布（对照仓位管理器目标比例）
- [ ] 判定：哪类加仓在赚钱、哪类在亏钱？亏钱的共性是什么（时段/日型/个股/价格位置）？
- [ ] 输出：加仓优化候选（接回比例/首加比例/支撑位条件/仓位约束），注明证据行数

## §3 建仓质量周评（主轴 ②，~40 分钟）

- [ ] 聚合每日「建仓滚动前瞻表」：
  - signal 密度：本周次数（对照闸门 8~30 次/月）
  - 3 日 / 5 日胜率、假阳性率（对照闸门 ≥55% / <40%）
  - 通道分布：冰点 vs 突破（W33 重构后）
  - approaching 缺口条件 TOP 榜：哪个条件最常卡住（→ 阈值是否过严的直接证据）
- [ ] confirmed 建仓股逐只过堂：继续持有 / 止损候选 / 伪信号归因
- [ ] 输出：建仓优化候选（条件增删/权重/阈值/股数口径），注明证据行数

## §4 候选排序与验证管线（~60 分钟）

- [ ] 候选总表排序：预期收益 × 证据强度 × 实施成本；**每周最多 2 个进管线**，其余留档
- [ ] 每个入选候选执行：
  1. **离线筛查**：历史数据重跑，粗看收益/胜率方向
  2. **全管线决赛**：harness_backtest 对照（生产口径 vs 候选口径）
  3. **预注册闸门**：执行前写下量化验收线（密度/胜率/假阳性/无回归），过闸才上线
  4. **上线 + 观察期**：默认观察 2 周，每日 Review 跟踪
- [ ] 破闸处理：记录参数面与证据，回退生产配置，候选归档（**不强行上线**）

## §5 观察项维护（~15 分钟）

- [ ] 逐条核对在跟踪观察项：升级（触发升级规则）/ 降级 / 关闭（证据充分）
