# 多券商账户集成使用指南

## 快速开始

### 1. 前置条件

**你需要在电脑上安装通达信客户端并登录**：
- 下载地址：http://www.tdx.com.cn/
- 安装后启动客户端，用你的券商账号登录
- 通达信会在本地启动 API 服务（默认监听 127.0.0.1:7709）

### 2. 在 GUI 中添加账户

1. 打开 superTrader GUI
2. 切换到"📊 多券商账户管理"标签页
3. 点击"+ 添加新账户"
4. 填写：
   - **账户名称**: 如 "账户A" （便于识别）
   - **券商**: 选择 "东方财富 (通达信)" / "国盛证券 (通达信)" / "东莞证券 (通达信)"
   - **自动同步**: 勾选则盘中每 5 分钟自动同步一次
5. 点击"确认添加"

### 3. 同步持仓

两种方式：

**方式 A：手动同步**
```
点击 "🔄 同步所有账户" 按钮
```

**方式 B：自动同步**
```
勾选"自动同步"后，盘中会每 5 分钟自动同步一次
```

### 4. 查看融合后的持仓

同步完成后，`holdings.json` 会自动更新：
- 包含三个账户的所有持仓
- 相同股票代码会自动合并
- 显示每只股票在各个账户中的分布

## 工作原理

### 数据流

```
通达信客户端（本地）
  ↓ (TCP 7709)
TdxAdapter
  ↓
AccountManager
  ↓
融合持仓
  ↓
holdings.json （更新）
  ↓
建仓扫描、复盘等系统使用最新持仓数据
```

### 账户存储

账户配置存储在：
```
~/.supertrader/accounts.json
```

**安全说明**：
- 认证信息使用 Fernet 加密存储
- 加密密钥存储在 `~/.supertrader/.key`（仅所有者可读）
- 如需重置，删除这两个文件即可

## 常见问题

### Q1: 添加账户时提示"无法连接到通达信"

**解决方案**：
1. 确保通达信客户端已安装并运行
2. 确保已用对应的券商账号登录（不是通达信账号）
3. 检查防火墙是否阻止了本地 7709 端口
4. 尝试重启通达信客户端

### Q2: 持仓金额和通达信客户端不一致

**可能原因**：
- 通达信客户端行情延迟（非实时）
- GUI 获取的是上一次同步的数据（不是实时）
- 建议：以通达信客户端为准，GUI 只用于查看持仓分布

### Q3: 可以添加超过 3 个账户吗？

**可以**。系统支持任意数量的账户，只要它们都支持通达信接入。

### Q4: 如何修改已添加的账户？

当前版本不支持修改，需要：
1. 删除旧账户
2. 重新添加新账户

### Q5: 同步失败怎么办？

检查：
1. 通达信客户端是否在线
2. 网络连接是否正常
3. 查看 `~/.supertrader/` 目录下的日志文件（如有）
4. 尝试手动点击"测试连接"按钮诊断

## 工作流程示例

### 日常使用

```
08:30 - 开盘前
  ├─ 打开 GUI
  ├─ 自动同步所有账户（已配置自动同步）
  ├─ 查看融合后的持仓
  └─ 建仓扫描基于最新持仓

09:30 - 盘中
  ├─ 每 5 分钟自动同步一次
  ├─ 建仓信号更新
  └─ 冲高防御实时监控

14:30 - 收盘
  ├─ 最后一次自动同步
  ├─ 保存当日快照
  └─ 生成日复盘报告
```

### 做T操作后

```
交易完成后
  ↓
通达信客户端自动更新持仓
  ↓
下一个 5 分钟同步周期
  ↓
GUI 中的持仓数据更新
  ↓
建仓扫描使用最新持仓
```

## 高级配置

### 修改同步频率

编辑 `~/.supertrader/accounts.json`，找到你要修改的账户：

```json
{
  "账户A_东方财富": {
    "broker": "通达信",
    "sync_interval": 300,  // 秒（默认 300 = 5 分钟）
    "auto_sync": true
  }
}
```

### 手动同步单个账户

在 GUI 中（未来版本）：
```
点击账户行的"🔄 同步"按钮
```

或在终端中：
```python
from broker_integration import get_broker_api
api = get_broker_api()
result = api.sync_account("账户A_东方财富")
print(result)
```

### 导出持仓汇总

```python
from broker_integration import get_broker_api
api = get_broker_api()
data = api.get_merged_holdings()
print(f"总持仓价值: {data['total_market_value']:,.0f} 元")
print(f"总持仓成本: {data['total_cost']:,.0f} 元")
```

| 东莞证券 | 通达信 | ✅ 已支持 |

| 国盛证券 | 官方 API | ⏳ 计划中 |
| 东莞证券 | 官方 API | ⏳ 计划中 |

### 数据更新流程

```python
# 每 N 分钟执行
def sync_cycle():
    accounts_info = manager.sync_all_accounts()
    merged = merger.merge(accounts_info)
    merger.update_holdings_json(merged)
    
    # 触发建仓扫描使用新数据
    trigger_position_builder_refresh()
```
