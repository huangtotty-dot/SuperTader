## 🚀 立即可用

### 调用示例

```python
from t_gui import Api

api = Api()
result = api.load_entry_verdict('2026-08-25')

# 查看所有候选股
for stock in result['stocks']:
    print(f"{stock['code']} {stock['name']}: {stock['action']}")

# 查看统计
print(result['summary'])
# 输出: {"total": 39, "ready": 0, "wait_resonance": 1, "waiting": 36, "avoid": 1}
```

### 快速查询

```bash
# 只看最优机会
curl http://localhost:5000/api/entry_verdict?date=2026-08-25 | jq '.stocks[] | select(.verdict=="wait_resonance")'

# 看避免的
curl http://localhost:5000/api/entry_verdict?date=2026-08-25 | jq '.stocks[] | select(.verdict=="avoid_chase")'
```
