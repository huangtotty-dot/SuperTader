## 分三个阶段推进

### 阶段1：L1重构（大盘多周期判定）

**问题：** 当前的MA60×0.97/1.005太死板，你已验证这不符合实际

**改进方向：** 从机械刻度 → 动态底部形成检测

```
旧逻辑（死板）:
  close > MA60×1.005 → trend_up
  close < MA60×0.97 → trend_dn
  else → range
  
新逻辑（多周期+底背离）:
  1. 日线支撑（最低点）的多次试探（确认底部）
  2. 60分钟线是否有连续反弹（确认反转）
  3. 30分钟线是否站上某个关键均线（确认趋势）
  4. 这三个同向 → 趋势确认
```

**验证方案：**
- 用过去6个月的指数数据（180天）
- 对比新旧逻辑的"趋势判定准确率"
- 测指标：进场后5天的平均收益率

**输出：** 
- L1 新判定逻辑 + 参数值
- 与旧逻辑的对比表格
- 准确率统计

### 阶段2：L2/L3参数实证（股票维度）

**问题：** 
- L2的"0.8x缩量"是怎么来的？
- L3的"1.2x放量+EMA8"是怎么来的？
- 这些参数对不同股票是否有差异？

**改进方向：** 用历史回测确定最优参数

**具体做法：**

1. **选择测试样本**
   ```
   条件：
   - watchlist中 status=signal 或有历史成功的买入点
   - 过去3-6个月内有明确的"放量→缩量→上涨"的完整周期
   - 至少15-20只股票（统计有效性）
   
   样本股票（待确认）：
   可能包括: 002536 飞龙, 688143 长盈通, 601318 平安, ...
   ```

2. **定义"理想买点"**
   ```
   标准：
   - 从这个点买入
   - 持仓5天后收益率 ≥ 3%
   → 这就是我们要找参数的目标
   ```

3. **参数扫描**
   ```
   L2参数空间:
     缩量比: 0.5x ~ 1.0x (步长0.1)
     支撑容错: ±0.5% ~ ±3% (步长0.5%)
     趋势判定: 连续N天递减 (N=2,3,4,5)
   
   L3参数空间:
     EMA周期: 5日 ~ 10日
     放量倍数: 1.0x ~ 1.5x
     VWAP容错: ±0.5% ~ ±2%
   
   穷举所有组合，统计：
   - 命中率（有多少次预测成功）
   - 精准度（误报率）
   - 平均收益
   ```

4. **输出最优参数**
   ```
   例如结果可能是：
   L2最优: 缩量<0.7x + 支撑容错±1% + 3天递减
   L3最优: EMA8 + 放量>1.1x + VWAP±0.5%
   
   带上：
   - 命中率: XX%
   - 误报率: XX%
   - 平均fwd5收益: XX%
   ```

**时间成本：** 
- 数据准备: 2-3小时
- 参数扫描: 1-2小时（可并行）
- 结果分析: 2小时
- 总计: 一个工作日

**具体改进：**

   ```

   ```

3. **显示如果通过会发生什么**

